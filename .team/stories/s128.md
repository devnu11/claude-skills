    environment: cli
  - id: AC2
    text: "At a sprint end, after the boundary check passes, the runner re-pins itself to the team branch head it just checked: it releases `runner.pid`, runs `pin-runner.sh <head>` and then `config check` under the new pin; if both pass, it re-executes itself from the new pin (`os.execv` into `start --resume`), so the unattended job never sees an exit. The old pin is kept as `.team/run/runner-pin.prev`. If the new pin fails `config check` or its first start, the runner rolls back to the old pin, carries on, and tells the human. A `runner-repin` event records the old and new commit, and the dashboard header shows the pinned commit."
    environment: cli

    environment: cli
