# s68: The implement gate runs the suite once

**Delivery:** cli (the agile-team runner's gates, `gates.py`).

## User story

As the human running the team, I want the implement-to-quality gate to run the
coverage command only, so that one gate costs one test run, not two.

## Why

One full test run takes about 4 minutes. The implement gate now takes 7 to 9
minutes because `tests_green_and_covered` runs the `test` command and then the
`coverage` command. Evidence: `.team/run/liaison/reports/2026-10-12-time-spent.md`
and `2026-10-12-test-time-questions.md`.

## Acceptance criteria

1. At implement to quality, the gate runs the coverage command once. A green
   run with enough coverage passes; that one run proves green and gives the
   coverage figure.
2. The bounce reasons are unchanged: a failing suite and a coverage shortfall
   each bounce with the same text as today. A test pins each.
3. The gate's recorded stage time shows one command run, not two.
4. `reference/protocol.md` states the gate runs the suite once, in the same
   story.
5. Coverage 95%+; ruff check and format clean.

## Origin

Human message t2, item 1 (cycle time is the top priority).
