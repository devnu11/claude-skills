# s74: The dashboard pill fixes left open by s44 (N1 and the yellow stopped pill)

**Delivery:** dashboard (`agile-team/runner/agile_team/dashboard/index.html`).

## User story

As the human watching the dashboard, I want the fallback step pill to read
`▶ role on story · ago` and a gracefully stopped run to show a plain
`● stopped` pill, so that the pill says what the design says.

## Why

s44 was accepted with two known defects open. Three roles flagged the first
and nobody fixed it. See `.team/reviews/s44.md` (N1) and the human's message
t3.

## Acceptance criteria

1. **N1.** With `heartbeat == null` and an open `step-start`, `pillText` gives
   `▶ <role> on <story> · <ago>`, with a space after `▶`. A node UI test pins
   it. The unit-tester writes the test first and sees it fail; the developer
   then fixes `pillText`.
2. **Resting pill.** After a graceful `agile-team stop` (R15, `halt_kind`
   unset, level `idle`), the pill reads plain `● stopped` and is not yellow
   (no amber or red class, no `⚠`). A node UI test pins the text and the
   class. The unit-tester writes it first; the developer then fixes the
   styling.
3. A halt that is not graceful (stop --now, limit, crash, dead runner) is
   still red. An existing or new test keeps that pinned.
4. Docs move with behaviour if any wording changes (`reference/protocol.md`).
5. Coverage 95%+; ruff check and format clean.
