Scope: the agile-team runner's PO tools and state.

## User story

As the PO, I want a tool to set an existing story's delivery, so a wrong
delivery is fixed in one call and not by hand-editing state.json.

## Why

s59 (and s61 before it) reached the Customer Proxy with a prose delivery. s64
now rejects bad names at `open_story`, but nothing can correct a story that
already exists: `open_story` refuses an existing id. The human had to edit
state.json by hand (m85).
