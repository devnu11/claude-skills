# s90: A PO tool to set a story's delivery

**Delivery:** cli (the agile-team runner's PO tools and state).

## User story

As the PO, I want a tool to set an existing story's delivery, so a wrong
delivery is fixed in one call and not by hand-editing state.json.

## Why

s59 (and s61 before it) reached the Customer Proxy with a prose delivery. s64
now rejects bad names at `open_story`, but nothing can correct a story that
already exists: `open_story` refuses an existing id. The human had to edit
state.json by hand (m85).

## Acceptance criteria

1. A PO tool sets the delivery of an existing, unfinished story.
2. The name goes through the same check as `open_story` (s64,
   `Config.delivery_refusal`); a bad name is refused with the same reason and
   nothing changes.
3. An unknown story id, or a done story, is refused with a clear reason.
4. A successful change records one event and saves the state.
5. Docs (`SKILL.md`, `reference/protocol.md`) list the tool.
