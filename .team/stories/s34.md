## User story

As the human, I want to answer the team's questions and send the PO messages
from the dashboard, so that I don't need the liaison to relay everything, and a
new request doesn't need a stop and resume.

## Notes

Human: "I should be able to answer questions from the web interface." Depends
on s4 (the server). It touches the first writes the dashboard has ever had, so
the token matters. s15 (Markdown in questions) shares the Questions tab; do s15
first or together.
