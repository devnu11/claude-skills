**User story.** As the human, I want the names in our code to follow our naming rules from the design onwards, so a rule is never quietly waived because a name was already chosen.

**Why (2026-10-18).** s159 added 31 `# house-rules: allow verb-name` or `query-property` comments in `agile-team/runner/agile_team/`, with reasons such as "name fixed by the s159 tests" or "name fixed by the design". The names include `result`, `at`, `done`, `moved`, `works`, `news` and `idle`.
- **Who named them (fact, Fable's check):** the s159 design (`docs/design/s159.md`, lines 716–1112) named every one of them. The tests used the design's names, as the unit tester's role file says (`roles/unit-tester.md:65-66`). The developer then suppressed the rule rather than sending the names back.
- **What's missing:** house-rules reads only Python, so nothing holds a design's names to the rules.
- **The human:** "tester doesn't get to name things, the architect does." In the code, the architect did name them; the names broke the rules, and the rules were waived. This story fixes the names and stops the waiver. Planning item A25.

**Where they are** (on the team branch: `git grep '# house-rules: allow' -- '*.py' | grep 'fixed by the'`):
- upstream.py (5), workspaces.py (4) and router.py (3);
- two each in system.py, story_rebase.py, story_branches.py, po_desk.py and config.py;
- one each in switchover.py, story_ci.py, scheduler.py, run_writer.py, rewrite.py, kept_sessions.py, dispatch.py, ci.py and budget_reserve.py.

None of them is a CLI, event or file-format name, so the renames stay inside the package. `sha_checks` is a Protocol method with two implementations. `docs/design/s159.md` and `docs/architecture.md` name most of them, and those docs change with them.

**Acceptance environment:** AC2 changes `house-rules/runner`. The `cli` environment installs only `agile-team/runner`, so AC2's acceptance needs either a `house-rules` `[[environment]]`, as `unattended` has, or a copy of `house-rules/runner` in the presentation workspace, as s157 did. DevOps decides which at ops-review.

**Placement:** the human (2026-10-18): "that could also go in this sprint". It goes in sprint 50, after the CI-fix story.

ACs written by the liaison and cross-checked by Fable ([review](../reports/2026-10-18-sprint50-stories-review.md)). The human approved the idea and the placement, not the AC text.
