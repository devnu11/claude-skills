# s48: Route lint/format-only fixes in test files to the unit-tester

**Status: folded into s92** (human, t28). Do not schedule. s92 AC1–AC6 cover this case (ruff finding in tests/ at implement goes to the unit-tester, no round).

**Delivery:** agile-team runner (gates and routing).

## User story

As the PO, I want a lint or format violation that sits only in test files to go to the unit-tester by itself, so the developer does not block on a file it cannot edit and I do not need a Manager ruling each time.

## Acceptance criteria

1. When the implement gate fails only on ruff check or ruff format findings in files outside the developer's write scope, the runner sends the story to the unit-tester with the findings in the brief.
2. The unit-tester may change formatting and import order only. It may not change what a test asserts. The gate checks that the test bodies' assertions are unchanged.
3. The route costs no round, like a free dispute, and the story returns to implement afterwards.
4. The developer-blocked hand-over for this case is no longer raised.
5. The story reuses the dispute or fault routing tables, not new branching (house rules).
6. SKILL.md and protocol.md are updated.
