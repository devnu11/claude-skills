# s77: The fake repo, runtime and close of the seam (s71 phase P3)

**Delivery:** cli (the agile-team runner: `system.py` P3 rows, `router`, `po_tools`, `cli`, `preflight`, the remaining unit tests, ruff config).

## User story

As the human running the team, I want the last OS calls behind the seam, the
migration table deleted and the rule enforced by ruff, so that no unit test can
touch the real OS again.

## Why

Third of three phases of the s71 split. Scope, functions, migrations and e2e
rows are the **P3 row of "Phases", "Ruff config (DevOps, P3)" and the P3
checklists in `agile-team/docs/design/s71.md`**. Do not restate them.

## Acceptance criteria

1. The P3 `system` functions exist and `router`, `po_tools` (drop `sleep`),
   `cli` (drops `browse`, `cmd_stop`'s `kill`; `--home` default) and
   `preflight` (drops `which`, `environ`) call them.
2. Every test file still in `os_guard.LEGACY` migrates to the fake or to
   `tests/e2e/`; then `LEGACY` and its world row are deleted. No test is
   weakened, skipped or deleted.
3. `tests/e2e/test_system_e2e.py` covers each P3 function on the real OS.
4. **DevOps step (the PO runs it storyless after the implement gate):** ruff
   `TID251` banned-api in `agile-team/runner/pyproject.toml` as in the design's
   "Ruff config" section. The developer's scope excludes `pyproject.toml`.
5. Docs move with behaviour; coverage 95%+; ruff check and format clean.
