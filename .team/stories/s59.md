# s59: The sprint-boundary sync rebases the team branch onto main

**Delivery:** agile-team runner (boundary sync).

## User story

As the human, I want the sprint-start sync to rebase the team branch onto origin/main, so a rebase-merge to main does not stop every sprint with a hundred false conflicts.

## Rule (human, 2026-10-11)

Rebase, never merge, at the sprint boundary. Hashes only matter within a sprint; at the boundary the branch is about to be rebased for the push anyway.

## Acceptance criteria

1. The boundary sync rebases the team branch onto origin/main. Git drops commits whose content is already upstream, so rebased copies on main cause no conflict.
2. After the rebase it checks that the tree is as expected (no content lost), and rewrites the commit hashes the runner records (`state.json` story commits) from old to new.
3. A real conflict (the same lines changed differently by new commits on main) still aborts the rebase, leaves the branch unchanged and raises the existing `sync_conflict` hand-over, listing the conflicting files grouped by directory with a count.
4. The push after the rebase uses `--force-with-lease`, and only for review branches the team owns.
5. No `-s ours` merge and no `-X ours`. The merge approach is dropped.
6. Tests on a scratch repo cover: all commits already on main as rebased copies, rebased copies plus new content, a real conflict, and the hash rewrite in `state.json`. Never touch the real home directory.
7. Docs move with behaviour (`agile-team/SKILL.md`, `agile-team/reference/protocol.md`). Coverage stays at 95%+; ruff check and ruff format clean.

## Origin

2026-10-11, m54: sprint 18's sync reported about 100 false conflicts, because main holds rebased copies of the branch's own commits. The story-commit hashes in `state.json` were rewritten by hand. Old hashes quoted in reviews and stories are historical text; the old commits stay reachable through origin/feat/agile-team-dashboard until it is force-pushed. Related to s29. Priority: backlog; before the next sprint start if possible.
