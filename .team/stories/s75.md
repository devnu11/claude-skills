# s75: DevOps scopes its test runs to what proves its change

Delivery: cli (runner prompts; no runtime change)

## User story

As the human, I want the DevOps role file to say that DevOps runs only what
proves its change, so that DevOps stays exempt from the full-suite and
coverage deny (s69 S8) without running the full suite.

## Context

Human reply t4 to m63: DevOps stays exempt from the full-suite and coverage
deny, but scopes its runs; normally a single test is all that is needed. The
runner's gate (not DevOps) produces suite and coverage evidence.

## Acceptance criteria

- AC1: `devops.md` states the rule: run only what proves the change, normally
  one named test; never the full suite or a coverage run; the gate does those.
- AC2: A prompt test pins the sentence in the DevOps role file, in the style of
  the existing role-file tests.
- AC3: `agile-team/SKILL.md` or `reference/protocol.md` mentions the rule where
  the DevOps exemption is described (docs move with behaviour).
