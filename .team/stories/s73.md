Scope: the agile-team runner's boundary checks, `fullcheck.py`.

## User story

As the human running the team, I want the sprint-boundary full check to run
the coverage command only, so that the boundary costs one test run, not two.

## Why

s68 made the implement gate run the suite once. The architect found that
`fullcheck.py` still runs the `test` command and then the `coverage` command
at the sprint boundary. One full run takes about 4 minutes, so the boundary
pays for a run it does not need.
