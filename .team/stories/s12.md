---
id: s12
title: Customer Proxy cannot leave its sandbox through cd, ~, $VAR or option-glued paths
delivery: cli
acceptance:
  - id: AC1
    text: >-
      The Proxy's Bash cwd stays its sandbox: `cd`, `pushd` and `popd` (with any
      argument or none) are denied, or the hook pins every command to the sandbox
      cwd. The architect chooses; the choice is recorded in an ADR.
  - id: AC2
    text: >-
      Words that expand outside the hook's view are denied for the Proxy when they
      could name the repo: `~`, `$VAR`, `${…}`, `$(…)` and backticks. Wildcard
      absolute paths into the repo (e.g. `/Users/*/code/claude-skills/agile-team/runner/*`)
      are checked like relative ones.
  - id: AC3
    text: >-
      Words are split on `=`, `<` and `>` before the forbidden-root check, so
      `cat --x=agile-team/runner/agile_team/cli.py` and
      `cat <agile-team/runner/agile_team/cli.py` are denied (review P2).
  - id: AC4
    text: >-
      Absolute-path comparison against the repo is case-insensitive on
      case-insensitive filesystems (macOS APFS default) (review P4).
  - id: AC4b
    text: >-
      For every role, the git-commit check sees through command prefixes:
      `X=1 git commit`, `env git commit`, `command git commit` and similar are
      denied. `_check_git` has checked only the first word since 625c6be, before s7.
  - id: AC5
    text: >-
      The Proxy can still run the delivered CLI, read the customer docs with the Read
      tool and work in its sandbox. Every allowed row of s7's W-rule table still
      passes.
  - id: AC6
    text: >-
      `reference/protocol.md` Enforcement is updated. Tests cover every denied form
      above and the allowed forms. Coverage stays at or above 95%, and ruff check and
      ruff format are clean.
---

## User story

As the human, I want the Customer Proxy to be truly walled off from source and
tests, not only for the word forms s7 checks, so that acceptance reflects what
a customer can see.

the architect's s7 redesign note: `$VAR`/`$(…)`/`~`, wildcard absolute repo

the token check. D4 (comment plus backslash-newline) is fixed in s7, per the human's decision
