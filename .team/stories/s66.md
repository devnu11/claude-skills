Scope: the agile-team runner's process-group code and Bash guard.

## User story

As the human running the team, I want the process-group safety code covered by
tests and hardened against bad input, and role Bash denied from signalling its
own parent, so that a role can never kill the agent CLI that runs it.

## Why

The s41 design review (round 2) found the code matches G1–G6 and K1–K5 and
listed three follow-ups outside s41's ACs. See
`agile-team/docs/design/s41.md` § "Design review (round 2)".
