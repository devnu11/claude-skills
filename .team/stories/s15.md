  - id: AC1
    text: >-
      One renderer turns Markdown into HTML for the dashboard: headings, paragraphs,
      lists, emphasis, inline code, fenced code, tables and links.
  - id: AC2
    text: >-
      It's safe: raw HTML in the input shows as text and never runs; links get
      `rel="noopener"` and only `http(s)` targets; a `<script>` or `onerror` payload
      renders inert (a test feeds one).
  - id: AC3
    text: >-
      The Questions tab (question and answer text) and the timeline's handoff
      summaries use it. One function, no copies.
  - id: AC4
    text: >-
      A browser library is pinned and loaded like Mermaid (one pinned URL, no build
      step), with readable plain text when it can't load. The ADR records the choice.

## User story

As the human, I want questions, handoffs and story files on the dashboard shown
with their formatting, so long text is readable.
