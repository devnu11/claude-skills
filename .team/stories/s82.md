# s82: Trial leaves the dashboard port in use on Linux (red CI on PR #14)

**Delivery:** cli (the runner's customer-proxy trial: `presentation.Trial` starts, probes and stops a service delivery).

**Priority:** high bug. CI on PR #14 is red; under t12 it goes first in the current sprint.

## User story

As the team, I want the trial's stop to end the whole service and free its port
before it returns, so that CI is green on Linux and the next trial can start.

## Bug report (human, via the liaison, t13)

After s79 (commit `d8ffab6` on PR #14's review branch) three of the four CI
failures are gone. One is left, on Linux only (ubuntu, Python 3.12 and 3.13;
run 38306808203):

`tests/e2e/test_service_presentation_e2e.py::test_trial_starts_the_real_dashboard_probes_it_and_stops_it`
fails at `assert not port_in_use("127.0.0.1", port)`. After
`presentation.Trial(config).liveness(story)` passes, the dashboard's port is
still in use.

## Acceptance criteria

1. **Find the cause first, and say which it is** in the design:
   - a real Linux bug: the stop does not end the whole service (for example the
     `uv run` child outliving the signal), or the stop returns before the
     process exits; or
   - a test that checks too early.
2. **Fix the cause, not the test.** If it is a race, the stop itself waits, with
   a deadline, until the port is free; the test is not given a sleep to hide it.
   If the whole process group is not ended, the stop ends it (through the
   sandbox's one signalling module, ADR-0031).
3. If the port is still busy at the deadline, the stop reports it (names the
   port), never hangs and never kills a group the runner did not create.
4. The e2e test keeps asserting the port is free right after the stop. It passes
   on macOS and on Linux; CI on Linux is the proof.
5. Unit tests (fake world, 1 s) pin the wait: port frees in time, port never
   frees at the deadline.
6. Docs move with behaviour if the stop contract changes (`reference/protocol.md`
   service lifecycle); coverage 95%+; ruff check and format clean.
