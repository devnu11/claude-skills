## Per function

### `shares.py`

- **`Share.from_json`** (C4, AC2): runs `_loaded` (JSON → object → fields), then `_decoded`, then the hash, so the first problem wins. Correct, and it never raises: `float(raw["at"])` is safe because `at` is already a non-bool int or float. An `at` of `NaN` or `Infinity` parses through `json.loads` and loads; the design doesn't cover it, so no finding. Tests: every problem text, table order, extra keys and int `at`. Good.
- **`BadRequest`, `Request`, `bad_request`**: plain data plus the reason format. Exact text tested.
- **`_field_problem`**: missing field, then the type check, with bool refused. `type(value) is not bool` also refuses a bool for `STRING`, which `isinstance` already does, so there is no gap. All six wrong types plus every missing field are tested.
- **`_loaded`**: catches `JSONDecodeError` only. `json.loads` on a `str` raises nothing else (a `RecursionError` on very deep nesting is far-fetched). Tested.
- **`_decoded`**: strict base64. Tested.
- **`_as_written`, `Where.resolve`**: the lexical default, so `with_entry` stays I/O-free (C3). Tested through `test_with_entry_stays_lexical…`.
- **`resolved_path`**: matches C1. **F1** (NUL raises). The `None` branch outside the repo is tested (`../../../../etc/x`, `/etc/passwd`). Real links: **F2**.
- **`_path_problem`**: implements C1 (resolved == written, and the parent is the design folder). `design_dir` keeps its trailing `/`, and `PurePosixPath` strips it, which is correct. A trailing-slash path or `./` resolves differently from how it is written, so it is refused. Non-string, nested, absolute-into-the-folder, `..` and the passing case are tested.
- **`_item_problem`**: same order as before (path, sha, duplicate). Covered.
- **`Brief`, `brief_section`** (C6, AC3): the story comes from the caller, and `_story_of` is gone (grep confirms no other code derives a story from a file name). Tested, including s7 against an s1 file name.
- **`listed_of`**: wires `functools.partial(resolved_path, config.repo)`. Covered. Inherits **F1**.

### `sharing.py`
