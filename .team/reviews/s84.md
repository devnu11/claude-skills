## Findings

- **m1 (minor, page).** `threadEntryHtml` wraps `md(t.text)` in another
  `<div class="md">`. `md()` already returns its own `.md` / `.md plain`
  wrapper (s15 M2), so the markup nests `.md` twice. Nothing breaks: the
  inner wrapper keeps `plain` and the margins reset. Fix: drop the outer
  div. It doesn't block shipping.
- **m2 (minor, consistency).** `_is_reply` accepts a bool `at`, while
  `_well_formed` rejects one. The runner never writes a bool, so this can't
  happen in practice. Fix by sharing the number check.

## Copy/paste search

- `_lines`/`_object` copy `snapshot.read_jsonl` on purpose (the design asks
  for a local copy, because the runner never imports `dashboard`).
- `threads._append` repeats `relay._append` (make dirs and append a JSON
  line). It's small, and relay's version is private. Worth folding into one
  `system`-level helper some day; not a defect.
- `_entries` serves both JSONL readers, so `liaison_posts`/`liaison_replies`
  don't repeat code. No other repeated blocks were found in the diff.
- The snapshot reads the thread files twice per build (`_thread` and
  `_events`). It's cheap; noted only.
