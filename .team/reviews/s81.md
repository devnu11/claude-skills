  no s81 test. `test_ci_git_e2e.py` is s79's and never touches `gh`. AC7 asks

  `gh` on PATH"). Without it, the real `command_runner` → `system.run` → `gh`

  `run view --job J --log-failed`) runs only on the fake. Add
  `tests/e2e/test_s81_ci_e2e.py` as the design's e2e item describes. Use a stub
  in `tmp_path/bin`, put it first on `PATH` with `monkeypatch.setenv`, have it
  record its argv to a file, and run
  `CiWatch(GhPrs(command_runner(tmp_path)), 30).results([entry])`. It must give
  RED with the `FAILED tests/x.py::test_y` line, and the test checks the recorded
  argv. Do not set `HOME` to the real home.
- **D4 (state reload): half fixed.** `test_a_saved_entry_ci_loads_back_as_a_ci_result`

  `RunState()` with an **empty** stack, so its loop that pops `"ci"` from each
  entry never runs. The legacy entry case (a stack entry with no `ci` key) is
