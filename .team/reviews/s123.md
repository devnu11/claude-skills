## Notes (non-blocking)

1. `test_start_reports_the_bad_hold_once`, line 201:
   `boundary is None or load_faults == []` is a weak disjunction. If the
   resumed run clears the boundary, the "list emptied after start" half is
   never checked. The one-fault assertion above it, together with the unit
   test of `report_load_faults`, already pins the behaviour, so I am not
   blocking on this. A tester could tighten it to `load_faults == []` alone.
2. AC1 "handled the way any step's triggers are": the router's
   `_step` → `Pass` path is unchanged (H3), and no new test checks that the PO
   receives the fix's handover. The design accepts this, since that path is
   existing behaviour.
