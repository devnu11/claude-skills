## Defects

**D1 (developer-gui): the running head's label does not ellipsize, so it can wrap.** TL2 says the head's first span "gets the same ellipsis CSS, so the time never wraps", and AC2 asks for one line. In TL1, `white-space: nowrap` was put on `.fc-t-tool`, not on `.fc-toollabel`. The running head is `.fc-toolhead.fc-t-toolRun`, so it never gets `nowrap`. Without `nowrap`, `text-overflow: ellipsis` does nothing, and a long head wraps to two lines inside a 196–216 px box. One example is `▶ pytest: new test files · first re-run` beside `1m 23s`. Fix: add `white-space: nowrap` to `.fc-toollabel`, or to `.fc-toolhead > .fc-toollabel`, and pin it in `test_s127_page`.
