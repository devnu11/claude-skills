## Blocking defects

### N11b. The landing's full checks still empty the shared report folder (s159/AC6.2, AC2.4; REQ-153, REQ-137)
`Landing.check` (landing.py:361–366) runs `fullcheck.full_checks(config)` in a thread.
`full_checks` (fullcheck.py:163–165) builds its `Reporting` on `config.run_dir / "reports"`,
and `at_worktree` keeps `run_dir` at the main checkout. `test_reports.run` calls `_emptied`,
which calls `remove_tree` on that folder. The story gates' folders `reports/<story>` are now
**inside** it. Landing runs while other stories keep stepping (C3, C8). So a landing's
coverage run deletes the reports of every gate that is running at that moment, and those
gates hold or bounce with "the test command wrote no report". The same goes for the main
runtime's own pipeline, which still writes `reports/` directly.

Fix: give each user its own sibling folder that nothing else contains. For example,
`reports/story/<id>` for the gates and `reports/landing` for the landing. Don't nest one
user's folder inside another's. Then test that emptying one folder leaves the other alone.

## Should fix

- **N14. After a shielded cancel, the push is skipped and a settle error is lost**
  (s159/AC11.2, AC8.1; REQ-161, REQ-158). `_settle_uncut` waits for the task with
  `gather(task, return_exceptions=True)` and then re-raises `CancelledError`.
  - If `_settle_tail` raised, the exception is swallowed. `_run_planned` sees only the
    cancel, so `_step_failed` never runs and the error is not logged or saved. Log the
    task's exception before re-raising, or re-raise it.
  - `apply_settled` doesn't run, so the step's commit is not pushed and its draft PR is not
    opened. The next step's push picks it up, since `_can_push` compares heads. But if the
    story stops here (a cancel or a hold), the branch on the remote stays behind its state.
    At minimum, note this in the docstring.
  - A second `cancel()` while `gather` is pending cancels `gather`, and `gather` cancels
    `task`. That lands mid-settle, which is the exact case N12 closes. Await
    `asyncio.shield(task)` in a loop, or wait for it without `gather`.
- **N15. `Runtime.at` mutates the shared pipeline when `pipeline_for` is unset** (s159/AC6.2,
  REQ-153). The default `_get_pipeline` returns `self.pipeline` itself. So `at()` rewrites the
  parent runtime's `checks.reporting` (and `checks.stages`, as before). Each further `at()`
  call nests one more level: `reports/s1/s2/…`. Production passes `make_pipeline`, so only
  tests and any caller without `pipeline_for` hit this. Copy `checks` (`replace`/`copy.copy`)
  before setting fields on it.
- **N8** and **T1**, as above.
