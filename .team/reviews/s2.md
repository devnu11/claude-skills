## Findings

- **F1 (minor; s2/AC2, REQ-124): the name differs from the design.** The design's § Renames
  table pins `unexplained_error` → `build_bad_handoff` and says "the tests must follow it".
  The code names it `build_unexplained_error` (`requirement_changes.py:209`,
  `dispatch.py:242`). The new name also starts with a verb and behaves exactly as designed,
  so no rule is broken. Code and design still disagree. Fix it either way in a later fixup:
  rename the function or amend the design table. It does not block.
- **F2 (minor, DRY; s2/AC2, REQ-124): copy/paste.** `StopChecks._check_requirements`
  (`stop_checks.py:318-322`) repeats `Runtime._sort_requirements` (`dispatch.py`):
  `folder_of` → `select_candidates(audit.in_scope, …)` → `find_changes` → `sort_changes`.
  One helper in `requirement_changes`, e.g. `sort_step(git, StepAudit(...))`, would serve
  both, so the stop check and the hold-back cannot drift apart. It does not block.
