## Defects

- **D1 (blocking, tester): the node-harness tests are missing.**
  `tests/test_s104_flow_page.py` doesn't exist, and no test refers to
  `mermaidConfig`, `idleClassDef`, `statsText` or `used !== false`. Story
  AC4 ("A test under the node harness pins…, fails on today's code") and
  AC5 ("A test pins that an unused built-in role has no box…") explicitly
  require tests. Write every node-harness item in the design checklist: AC4
  cause (FL1 in Story scope with an `idle` class line, and in Sprint scope),
  AC4 hidden-then-shown with a fake `mermaidModule`, AC3 size plus the
  Python CSS check, AC2 `· idle` with no `$0.00`, AC5 on `ringRoles`/`flowSource`,
  and s96 labels kept. The FL7 corner cases are also open: a pipeline step
  not in `STEP_ROLES`, and a pipeline without `implement`, which adds no
  developer.
- **D2 (minor, developer): a stray JSDoc.** `idleClassDef` was inserted
  between `flowSource`'s doc comment (`/** The Mermaid text for the
  information-flow chart … */`) and `flowSource`. That leaves two stacked
  doc blocks above `idleClassDef` and none on `flowSource`. Move
  `idleClassDef` (with its own doc) above the old comment.
- **D3 (blocking, docs; architect per the design's "Docs" section):** the
  charter's "docs move with behaviour" rule isn't met.
  `reference/protocol.md` has no `roles[].used`, and its Flow paragraph
  doesn't cover used roles, recoloured dimming, `idle` or sideways scrolling.
  `docs/customer/dashboard.md`'s Flow entry is unchanged. Only
  `docs/architecture.md` got a row.
