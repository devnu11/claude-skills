## Changed functions in 42efc747

### `GhPrs.checks` (upstream.py:345)
Runs the checks, decodes them, and on a decode failure raises `UpstreamError` naming the
argv that ran, its real exit code, any HTTP status, and the trimmed output. Correct for
s175/AC1 and s175/AC3 (REQ-204, REQ-206). **Not tested**: see T8.

### `GhPrs._run_checks` (upstream.py:353)
Runs `gh pr checks --required`. If gh says no checks are required, it runs again without
`--required` and returns that argv and result. Correct, and it has a docstring. **Not
tested**: the fallback branch's argv is exactly what D13 was about. See T8.
