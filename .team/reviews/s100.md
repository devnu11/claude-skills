## New minor findings (do not block)

- **m4: `storyGroup` lost its doc.** The `sleepIntervals` helper was inserted *between* `storyGroup`'s doc (`/** A story's group: rows, bars, … (TL4-TL12). */`) and the function. Now two docs sit stacked above `sleepIntervals`, and `storyGroup` has none. The fix is to move one line, so do it the next time index.html is touched.
- **m5: duplicate SVG ids across open timelines.** The ids `tl-<group>-clip`, `-sleep` and `-arrow` are unique within one SVG. They repeat when two expanded rows draw the same group, for example s3 and s4 both in Sprint scope. Browsers resolve `url(#…)` to the first match. The duplicates have identical content, so nothing renders wrong, but the HTML is invalid. Round 1 already had this for `-sleep` and `-arrow`; the clip id adds a third. Prefixing with the expanded story's id would fix it. Low priority.
