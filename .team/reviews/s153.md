## Blocking finding

### B1: s151's unit tests deleted outside the design (s153/AC7, REQ-096; engineering rule "never delete a test")

Commit `943330b7` (unit-tester, message: "Renamed the s153 tests …") also:

- deletes all of `tests/test_s151_conflict.py` (417 lines, about 30 `test_ac6_*` tests);
- deletes `test_s151_end.py::test_ac3_1_a_rebase_conflict_goes_to_devops_not_a_hold`;
- deletes the `sync_conflict` row (s151's new handover text) from `BOUNDARY_ROWS` in
  `test_boundary_wiring.py`;
- reverses s151's assertions in `test_s59_sync.py::test_a_conflict_reports_files_commit_and_subject_and_wakes_devops`
  (renamed `..._and_holds`). It now asserts the old behaviour, which duplicates
  `test_p1_a_sprint_end_conflict_still_holds_sync_conflict`.

Why this is a defect:

- s153's design moves only the **e2e** AC6 part (P5, step 2, AC7), and it names a re-add
  point. It says nothing about moving the unit tests out. Its "Test checklist" says the
  opposite: s151's nine pure tests are "expected to pass once this story is in". Those
  tests (`test_ac6_1_the_fix_kind_table_maps_the_case_to_the_step`,
  `test_ac6_2_the_worktree_and_branch_names`,
  `test_ac6_2_the_judging_checks_run_in_the_documented_order`,
  `test_ac6_2_the_first_reason_wins`, `test_ac6_2_the_fix_step_may_write_only_the_worktree`,
  `test_ac6_2_git_is_confined_to_the_worktree_without_an_editor`,
  `test_ac6_4_the_stall_hint_exists`, `test_ac6_4_a_legacy_sync_conflict_hold_still_exists`,
  …) were deleted, so the implementation was never checked against them. That check was
  the point of slice 1.
- s151's design ("Before slice 1 can pass its gate") planned for `test_s151_conflict.py` to
  become an s151 pending id. Deleting it drops that plan without a word.
- No handoff, story or design records the commit that still holds these tests
  (`943330b7^` = `21cb9ae5`). s151's implement step will not know that it has to bring them
  back. The commit message says "Renamed", which hides the deletion.

Fix (unit-tester; the architect if the design has to change):
1. Restore `tests/test_s151_conflict.py` and the deleted `test_s151_end` / `test_boundary_wiring`
   tests from `21cb9ae5`, and restore `test_s59_sync`'s s151 assertions.
2. Keep the pure tests that pass with s153's code running green now. The design requires that.
3. Slice-2 tests that cannot pass before s151's implement step must not be deleted. Either
   make them s151 pending ids, or have the architect amend the s153 and s151 designs to
   sanction moving them, as AC7 does for e2e, naming `21cb9ae5` as the re-add point.

## Minor findings (non-blocking)

- **D1 copy/paste (s153/AC2, REQ-093).** `Upstream.adopt` repeats `rebase_onto`'s last two
  lines (`moved = pair(self.listing(f"{self.target}..{old}"), self._new_listing(target_sha))`
  and `return Rebase(SyncOutcome.REBASED, …, moved=moved)`). A
  `_rebased(old, sha, target_sha)` helper would remove the copy.
- **D2 test copy/paste (no AC).** `stamped`, `NO_RENAMES` and `script_lost` exist in both
  `test_upstream.py` and `test_scratch_rebase.py`. The `_Late` lazy-import class appears in
  both `test_scratch_rebase.py` and `test_s153_pieces.py`. `_Late` existed only to keep the
  red phase per-test; now that the module exists, a plain
  `from agile_team import scratch_rebase as sr` is simpler, and it also drops the top-level
  `sr = _Late()` instance (the checklist only allows constant assignments at top level).
- **D3 weak assertion (s153/AC6, REQ-095).** `test_s153_fix_brief_…` line 103:
  `brief.rstrip().endswith(...) or "the output" in brief` always passes when the second
  clause holds. The ordering the design asks for (commit, subject, files, worktree, branch,
  then output) is only checked for worktree before output.
- **D4 e2e (s153/AC8, REQ-096).** `tests/e2e/test_s153_pieces_e2e.py` does not exist yet.
  That is expected, because the design schedules it after implement (step 4). AC8 is not
  met until that step runs.
- **AC7 (REQ-096).** The e2e move (`21cb9ae5`) matches the design. Its commit does not name
  the last commit with the AC6 part, which the design asks for. That commit is `e7867fe3`.
