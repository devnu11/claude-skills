## Findings

- **F1 (s152/AC1.1, AC3.1; REQ-088, REQ-091), test gap, blocking, unit-tester. Still
  open (fifth round).** No test runs the start `sync` against real git. Every
  `test_ac1_1_*` sets `behind` and `rebase_onto` through the `start_sync` helper
  (`tests/test_s152_start.py:39-48`). Add these tests in `tests/test_s152_start.py`, named
  `test_ac1_1_*`. Build on `tests/e2e/test_s59_rebase_e2e.make_world` or the scratch-repo
  helpers in `test_upstream.py`, and stub neither `behind` nor `rebase_onto`:
  (a) Main has moved by one commit, and a story's `commit` is a team commit. After one start
  `sync` step, HEAD must be on `origin/main` (`merge-base --is-ancestor`) and the story's
  `commit` must be the rebased copy. There must be a `rebased` event with `rewritten >= 1`,
  `sync_from` must be empty, and the stage must be `check`.
  (b) Main has not moved. HEAD keeps its sha, and a `current` event carries `START_CURRENT`.
  (c) The usual start: the previous sprint's commits are already on main as rebase-merged
  copies. HEAD must end on `origin/main` with no conflict and no hold.
