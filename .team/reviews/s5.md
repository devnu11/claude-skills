## Defects

### D1 (blocking): `findEdge` never finds an edge, so no travelling dot is ever drawn
`findEdge` queries `path.LS-${a}.LE-${b}`. Mermaid 11.4.1 no longer puts `LS-`/`LE-` classes on edge
paths (they were a v10 feature). It identifies an edge only by its id, `L_<from>_<to>_<index>`. The
result is that `showEvent` silently does nothing for every event. With reduced motion off, no dot is
drawn. With reduced motion on, no edge highlight is drawn. "Where information is flowing" is not shown
at all.
- Fix: match on the id prefix, for example `svg.querySelector(\`path.flowchart-link[id^="L_${a}_${b}_"]\`)`.
  Keep the reverse lookup. Every node id (`you`, `po`, `rN`, `grpSteering`) is free of `_`, so the
  prefix is unambiguous. The edge to the Steering cluster is emitted as `L_grpSteering_…`, so the STEER
  ends resolve correctly.
- Tests: no test touches the selector, because they are static string checks on the script. Add an
  assertion that pins the `L_` id selector, or a headless check. Either way, the integration-tester
  should confirm the dots in a browser after the fix.

### D2: some snapshot strings reach `innerHTML` unescaped
The rule is that every snapshot string gets `esc()`. Most do, but these do not:
- `renderTimelineFilter`: `value="${s.id}"` (the visible text is escaped, the attribute is not).
- `storyCard`: `<span class="req-chip">${r}</span>` (requirement id).
- `renderMatrix`: `<th class="req">${id}</th>` and `<b>${c.ac.id}</b>`.
- `renderReqList`: `<span class="id">${r.id}</span>`.
- `renderQuestions`: `${q.id}` inside `<code>` and inside the single-quoted `data-copy='…'` attribute.
- `renderBoard`: `class="col ${id}"` (pipeline step name).

These ids come from file names and front matter in the repo, so the risk is low. Still, they break the
stated rule, and a `"` or `'` in a story id or AC id breaks the markup. Wrap each one in `esc()`.

## Nits (no bounce)
- `live.queue` grows without bound while Mermaid is unavailable, because `flushLive` never splices it.
  Cap it when pushing (only the last 6 are ever played).
- `mmdText` does not escape `#`, so a name containing `#lt;` is decoded by Mermaid. This is cosmetic only,
  since strict mode still sanitizes it.
- The backoff applies only after the browser gives up (`CLOSED`). During transient drops the browser's own
  retry interval applies. That is acceptable, but worth a comment.
- Copy/paste: the `tile` lambda is duplicated in `renderTiles` and `renderRequirements`. Hoist it.
- `test_dashboard_ui.py` is all static string or presence checks, so the runtime behaviour of the live
  features (dots, halo, reconnect) has no executable test. Flag this for the integration-tester.
