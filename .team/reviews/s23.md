## Minor notes (not blocking)
1. **A boundary queued *during* a renewal query is lost.** If the PO calls `start_sprint`
   while answering `COMPACT_PROMPT` or `HANDOFF_PROMPT`, `_renewed`'s `clear()` drops the new
   reason. This is unlikely, because the prompt says to write only the file. Clearing
   only the reasons captured at entry would close the gap.
2. **The first renewal comes right after kickoff.** A sprint started in the kickoff turn
   leads to a `/compact` of a one-turn session before the first hand-over. The design
   intends this (checklist item 3), but it costs one extra PO query per run. The Manager
   may want to watch this once real `po-session` events exist.
3. **`e.data.reasons.join(", ")` in the timeline** assumes `reasons` is present.
   The runner always emits it, but ADR-0006 (defensive rendering) would prefer
   `(e.data.reasons ?? []).join(", ")`.
4. An unknown `po_renew_path` in a hand-edited `state.json` raises `ValueError` from
   `RenewPath(...)`. Acceptable.
