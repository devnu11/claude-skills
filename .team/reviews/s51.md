## Defects

### D2 (AC6, still open): ADR-0016 is not amended

`.team/adr/0016-story-priority-in-code.md` still says `Status: Accepted` and has no s51
text. The design (section "ADR-0016 amendment") gives the exact changes. The Architect,
developer and tester cannot write `.team/adr/`, so **the Scribe or the PO must apply it**.
AC6 lists it, so the story cannot be accepted without it. This was raised in round 0 and
not routed.

### D4 (tests): two checklist items have no test, and the `with_move` landing is not checked

1. "`start_sprint` while a started story is held does not move the held story's place in
   `order`." No test. `_begin_sprint` uses `with_first` too, so it is the third path for
   the D1 bug, and only `prioritise` and `move_story` are pinned.
2. "The worked example above, step by step." No test follows the example's sequence
   (hold, prioritise, release, refused move, pulled move, prioritise twice, move s21 to 4
   with the note, hold again and move s38 to 1 with the note `s38 ranks #2, not #1`).
   The steps are tested one at a time from different starting states, so a regression that
   only shows when the steps are chained would get through.
3. The checklist asks each `with_move` rule test to check "that the story lands at
   `position` when its group's block covers it". The rule tests check only the returned
   order and never rank the result with `Priority(new_order, …).queue(...)`.

Also, `test_a_refused_pull_is_returned_once_and_unknown_ids_are_not_pulled_on` tests
neither "returned once" nor unknown ids. It checks only the refusal text. Rename it, or add
the asserts its name promises.

**Fix (unit tester):** add the tests above.

### D5 (DRY, minor): `listed` computed twice

`Priority.key` (line 173) and `Priority._listed` (line 186) hold the same expression,
`self.order.index(story.id) if story.id in self.order else len(self.order)`. The design says
to "share the listed index with key()". `key` can return
`(done, RANK[self.tier(story)], *self._listed(story))`.
**Fix (developer):** a one-line change. It does not block on its own; fix it in the same round.
