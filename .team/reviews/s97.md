## Per changed function

### `system.platform()`
Returns `sys.platform`. **Tests:** `FakeSystem.platform` stands in for it in every test that uses the fake. The design's seam test (`system.platform() == sys.platform`) is **missing** (m2). It's one line and the coverage gate still passes, so this doesn't block.

### `live.Pulse._count_sleep(now)`
Measures the wall gap since the last beat and adds `gap - beat_s` when the gap is over 2 beats. **Tests:** gaps of 1 and 2 beats add 0 (the boundary), 10 beats add 9, sleeps accumulate and the gap restarts, rounding to a tenth, `_beat` counts and then writes. Good corner coverage.
*Note (not a defect):* `_last_beat` starts at construction (`Runtime.__init__`), but beating starts at `cli._po_until_sigterm`. The only work in between is `_load_dependencies` and `asyncio.run` setup, well under 40 s, so this can't add phantom sleep today. If start-up ever does slow work (a boundary, a network call) before `pulse.start()`, Windows would count that wait as sleep. Resetting `_last_beat` in `start()` would make this robust. Optional.

### `live.Pulse.clocks()`
Returns `{"mono": system.monotonic(), "slept": round(slept_s, 1)}` without taking the lock, as the design asks. **Tests:** `test_clocks_are_the_monotonic_reading_and_the_counter` uses `doze`. ✔

### `live.Pulse.heartbeat()`
Adds `slept`. **Tests:** s44's exact key order includes it, and s97 checks its value. ✔

### `live.Meter.interrupted(stop)`
Wraps `Reading.interrupted` and updates `event.data` with the clocks. `Reading.interrupted` is unchanged. **Tests:** `test_an_interrupted_end_carries_both_clocks`. ✔

### `dispatch._take_off`, `_emit_step_end`, `_close_interrupted`
Each changes by one line, as the design specifies. **Tests:** `test_a_step_writes_both_clocks_on_start_and_end`. It is weak: `doze(7)` runs before both events, so start and end have equal `mono` and the test can't tell whether each event read the clock at its own time. The pure tests cover the arithmetic, so this is acceptable (m3).

### `step_times`: `platform_of`, `number`, `Mark.of`, `gap`, `mono_awake`, `slept_awake`, `wall_timing`, `awake_timing`, `Stopwatch.between/so_far`, `killed`
These are pure, small and match the design signatures exactly. **Tests** cover:
- the POSIX sleep span (AC2/AC5)
- the Windows counter (AC3/AC5)
- Windows with `mono` only falling back to wall
- no clocks on both platforms
- the default watch
- `mono` going back (a reboot), and the counter going back on Windows
- bool, string, None and list `mono`
- `number` with int, float, bool and str
- `Mark.of` with a bad `slept`
- killed steps
- running steps on POSIX, on Windows and with no clocks
- `platform_of` with four names
- `AWAKE` keys

The negative-wall corner (`max(0, …)`) is inherited from s96 and tested there.

### `Pairing.start/end/_closed/_timing/_running/result`, `spans(events, watch=WALL_CLOCK)`
`starts` maps each index to its `Mark`. A duplicate start leaves a stale `starts` entry behind for a `None` slot. That is harmless, because `result()` skips `None` and `open` no longer points at the slot. `_closed` is 12 lines, over the 8-line guideline, but it's one `replace(...)` call spread over several lines by the formatter. Acceptable. **Tests:** as above, plus the s96 suite (unchanged apart from the exact-dict addition).

### `snapshot._watch`, `_steps`
`_watch` builds the reader's `Mark` and `Stopwatch` as the design says. **Tests:**
- `test_a_slept_step_counts_wall_minus_sleep_on_every_platform` (darwin, linux, win32)
- a running step on Windows with a heartbeat
- a running step without a heartbeat falls back to wall
- the fixture has awake+slept, wall-finished and running steps
- the heartbeat has `slept`

The s96 fixture contract still holds (the suite is green).

### `index.html`: `stepsAsOf`, `awakeSoFar`, `sleepNote`, `runningLine`, `timeBy`, `timeRow`, `timeLegend`
The code matches the design text exactly. **No tests yet** (P1): the design's `tests/test_s97_awake_page.py` node-harness checklist (4 items: running line awake/wall, `timeBy.wall` + tooltip, legend contains "Awake time", `stepsAsOf` nulls) is not written.
