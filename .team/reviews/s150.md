## Changed functions

### CSS `.story .pill`, `.story .pill .dot` (index.html L268-272)
- **What it does:** a card pill becomes `inline-block`, `nowrap`, `overflow: hidden`,
  `text-overflow: ellipsis` and `max-width: 100%`. The dot gets its own `inline-block` and
  the 5 px gap that the flex `gap` used to give it. The base `.pill` rule is unchanged, so
  other tabs look the same.
- **Correct?** Yes. In `.story .row` (a wrapping flex box) the pill is a flex item.
  `overflow: hidden` drops its automatic min-width, so it can shrink to the row and cut
  with `…`. In `.sid` (the env pills) the `max-width: 100%` caps it at the line. The old
  `white-space: normal` rule is gone, and no other rule brings it back. This meets
  s150/AC3 (REQ-098).
- **Tests:** `test_s150_wait_pill_source.py::test_card_pill_rule_keeps_one_line_and_cuts_with_an_ellipsis`,
  `::test_no_rule_lets_a_card_pill_wrap` and `::test_card_pill_dot_has_its_own_display_and_gap`
  pin the declarations (T6 at source level). The node harness has no layout engine, so the
  real "one line high" can only be checked by hand. That is accepted in the design.

### `cardPill(text, {tone, title, dot})` (index.html ~L508)
- **What it does:** builds `pill`'s markup plus `title="${esc(title)}"`. The title defaults
  to the text. Both title and text are escaped.
- **Correct?** Yes. It is XSS-safe (`esc` on both).
- **Tests:** `::test_card_pill_helper_puts_the_tooltip_on_the_pill` (string check).
- **Note (low, DRY, fits no AC):** the `<span class="pill tone-…">…dot…</span>` template is
  now copied in `pill`, `cardPill` and `envPills`. `pill` could delegate to one builder
  with an optional title. The design chose to leave `pill` alone, so this is not a defect
  in this story. It is a cleanup candidate.
- **Note (low, charter rule "no boolean flags", fits no AC):** `dot: false` is a boolean
  option. It copies the existing `pill(text, tone, dot)` signature and the design names it.
  I accept it here.

### `revertPill(s)` (index.html ~L2031)
- **What it does:** the `reverted (N×)` pill is now a `cardPill` with no dot, and its title
  is its text. This meets s150/AC3 (REQ-098).
- **Tests:** `::test_role_and_revert_pills_are_card_pills`. Its regex uses `.` for `×`
  (the RUF001 fix). That is fine.

### `storyCard(view, s, act)`, the `flags` array (index.html ~L2474-2478)
- **What it does:** the role pill is `cardPill("▶ role")`. The wait pill is
  `cardPill("⏸ " + s.wait.reason, {title: s.wait.title})`.
- **Correct?** Yes:
  - **s150/AC1 (REQ-097):** the visible text is the reason only, and the tooltip is the full
    title.
  - **s150/AC2 (REQ-097):** I checked `waits.py` L76-104. For `cancel requested`,
    `revert requested` and `PO hold`, the detail (`_po_reason`) is appended to `wait.on`.
    So the detail still shows once, visibly, on the `waits on:` line (`waitLine`,
    unchanged, cut at 140 characters, full text in its title), and it is no longer in the
    pill.
  - The snapshot is unchanged (W4).
- **Tests:** `::test_wait_pill_shows_the_reason_and_titles_the_full_title` (string check,
  including that `⏸ ${s.wait.title}` is gone).

### `envPills` and `waitLine`
