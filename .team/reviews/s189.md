# s189 review: `remove_from_sprint`

Diff reviewed: `7830c089^..HEAD` (story commits only). Runner results: coverage 98%, all green.

**Verdict: changes requested.** The code and its tests are sound. The docs the design
lists in its Files section were never written, and the PO's role prompt is one of them.

## Defects

1. **Blocking: the role prompt and the reference docs are missing** (s189/AC1, AC2, AC3;
   REQ-252, REQ-254, REQ-255; repo rule "Docs move with behaviour"; design § "Changes
   per module"). `grep remove_from_sprint` finds nothing in:
   - `agile-team/runner/agile_team/roles/product-owner.md`: the `revert_story` bullet,
     the sprint-end rule and the stuck-backlog action list are unchanged. The PO learns
     of the tool only from the SCHEMAS text, and its prompt still says a sprint ends only
     when its stories are done, cancelled or reverted.
   - `agile-team/reference/protocol.md`: the sprint-membership list (L1–L10, the event,
     the texts), the "A sprint ends only when it is finished" bullet and the stuck-backlog
     list.
   - `agile-team/SKILL.md`: the sentence after `add_to_sprint`.
   - `README.md` agile-team row, if it lists the PO tools (check).
2. **Minor: refusal order differs from L9** (s189/AC3, REQ-256). The design order is
   boundary (2), then unknown (3). `SprintLeave.find_refusal` checks unknown before
   `boundary_refusal`, so an unknown id while a boundary is pending gets `UNKNOWN`, not
   the boundary text. Nothing changes either way, so it does no harm. Either reorder
   it, or have the architect note that unknown comes first (`revert_story` and
   `add_to_sprint` can be the model).
3. **Minor: public methods have no docstrings** (no AC; engineering rule "Every public
   function is documented"): `read_today`, `SprintLeave.find_finished_refusal`,
   `find_sprint_refusal`, `find_running_refusal`, `find_dependents_refusal`. Either
   document them or make the helpers private (`_find_work_refusal` is already private).
4. **Minor test gap: the Board side of AC1 is not checked** (s189/AC1, REQ-252). The
   design checklist asks for "the snapshot's story `sprint` are `None`".
   `test_status_and_snapshot_show_it_in_the_product_backlog` checks only
   `status_report`, although its name says snapshot. Add the dashboard snapshot
   assertion, or rename the test.
