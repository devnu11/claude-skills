## Platform note (not a defect)
R16 assumes the monotonic clock stops during sleep. CPython's `time.monotonic` uses `mach_absolute_time` on macOS and `CLOCK_MONOTONIC` on Linux, and both exclude suspend. If a future Python moved macOS to a clock that keeps running during sleep, `slept` would read about 0 and a sleep would show up as R18 red "heartbeat N old", or amber if busy. The failure would be a softer colour, not a false red.
