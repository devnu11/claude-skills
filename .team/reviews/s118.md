## Blocking

### B1 (integration-tester): FC30 / AC13 has no behaviour tests

Design checklist line 559 lists these. None exist (grep for `fc-t-toolDesc`,
`fc-tooldesc`, `detailTitle`, `title=` in `tests/` finds nothing for tools):

1. The idle `gate.tests+coverage` box under the fixture's developer has a
   `fc-t-toolDesc` line with R12's text (a **built-in** tool).
2. A `runner-stage` event of repo tool `deploy.preview`, with
   `stage_descriptions["deploy.preview"]`, gives a box whose description
   line is that row's own text (a **repo** tool).
3. Tooltip: with two events of one (role, stage), `title` is the newer one's
   `data.detail`. It is the older one's when the newer has `detail: ""`.
   `"` and `<` are escaped. With no detail there is no `title` attribute. A
   detail from an event outside the scope still sets it.
4. A stage missing from `stage_descriptions` gets no description line.
5. The running box has the description line right after its head and the
   same `title`. With `hide-tools`, the idle box's line hides and the
   running box's line does not.
6. `normalize` defaults `stage_descriptions` to `{}` for a missing value, an
   array or a non-object (FC30 static part).

### B2 (integration-tester): FC18 conformance fix is untested

`completePct` changed from "last point when there is no total" to `null`, and
the `% complete` line is now dropped. Nothing pins this (design line 560).
`completePct({passed: 3, …, total: null, points: [], fail_at: null})` must be
`null`, and the running box must then have no `% complete` text and no
`fc-status` SVG. Also cover `total: 0`, since the code checks `t.total > 0`.

### B3 (developer): the fixture misses two required items

The design's Fixture section (lines 431–436) asks for:
- `stage_descriptions` to include the repo tool `"deploy.preview": "Deploy
  the branch to the preview site"`. It is absent.
- at least one **closed** `gate.tests+coverage` `runner-stage` event with a
  non-empty `data.detail`. The only one in the fixture has `detail: null`.
  Without it the `?mock` page and the customer proxy's AC11/AC12 check show
  no tooltip on that box.
