## Defects

None block shipping.

- **m1 (minor, DRY):** `_apply` and `_reorder` each call `View.of(state_mod.load(self.run_dir))`, so a REORDER apply reads `state.json` twice. Pass the view into the applier, or work out the position in `_apply`.
- **m2 (minor, copy/paste):** `opinions._number` repeats the numeric-`at` check in `threads._well_formed`. That check is now in two modules. Also, the three `Opinions.*_file` properties rebuild the paths that `watched()` builds, and those public properties have no docstrings.
- **m3 (minor, page):** `opinionHtml` and `reviewBarHtml` wrap `md(...)` in `<div class="md">`. `md()` already returns its own `<div class="md">` (s15 M2), so the markup nests `.md` inside `.md`. The plain fallback ends up as `.md > .md.plain`. It renders fine because the margins are reset. Use `md(text)` directly.

## Copy/paste search
- **Server:** `_review` and `_opinion` repeat `_reorder`/`_thread`'s `may_write → 403` / `Body("application/json", …, 202)` pattern. That pattern was already there, and it stays two lines per handler.
- **Page:** `postReview` and `postOpinionAct` repeat `postThread`'s fetch, headers and catch shape. That is the s84 precedent, and it's acceptable.
- **Tests:** the two `*_refused_writers_get_403_and_no_read` blocks are parallel parametrizations, one per route, which is fine.
- **Beyond m2:** no other repeated blocks.

## Known limits (accepted by design)
- **Race:** two tabs acting at the same instant can both pass the refusal, because the server holds no lock.
- **Refused reorder:** an applied move whose reorder is later refused still settles its opinion.
