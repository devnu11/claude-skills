Verdict: **approved**. D1 and T1 from round 1 are fixed. No new defects.

Scope of this round: `git diff HEAD~4 -- agile-team/runner/`, the fixups since round 1.

## Round 1 findings

**D1 (fixed): a move that changes nothing showed `#undefined → #undefined`.**
`priorityLabel` now returns `#${e.data.order.indexOf(e.story) + 1} (unchanged)` when no move
matches `e.story`. `e.data.order` is always in the event: `_reorder` writes `order`, `moves`,
`change` and `reason`. A `move` event's story is always in the new order, so the index is never
-1. The `set` and `sprint` cases return before this line. `m.from` and `m.to` no longer need
optional chaining. `"(unchanged)"` was added to the page-source test. That test only checks that
the text is in the page, which matches how every other page check in this repo works.

**T1 (fixed): an answered question must not count as a wait.**
`test_answered_question_is_not_a_wait` has an outbox question `m1` that names s1 and an inbox
answer with the same id. It asserts `wait is None`. s1 has no hold, so without the `answered`
filter the `questions` wait row would match and the test would fail. The test pins the filter.
