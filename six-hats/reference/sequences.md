# Sequences

Blue always opens and closes. Pick the sequence that matches the job, or build
one: a hat may appear more than once.

| Job | Sequence |
|---|---|
| Choose between options | Blue, White, Green, Yellow, Black, Red, Blue |
| Judge one idea or proposal | Blue, Red, Yellow, Black, Green, White, Blue |
| Solve a problem | Blue, White, Black, Green, Yellow, Blue |
| Generate ideas | Blue, White, Green, Blue |
| Quick check (a few minutes) | Blue, Yellow, Black, Red, Blue |

In "Judge one idea", Red goes first to surface existing bias before the
analysis, and a second Red after Black is optional to see whether feelings
changed.

When options exist, run Yellow and Black per option, in a table with one row
per option, so they can be compared side by side.

## Closing summary (Blue)

```
Question: <the one-sentence decision>
Recommendation: <option>, because <the hat or hats it rests on>
Risks carried forward:
- <risk>: <mitigation or "accepted">
Open questions:
- <question>: <who answers it>
Next step: <action, owner>
```
