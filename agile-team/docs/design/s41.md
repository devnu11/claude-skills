# s41: Signal only what you started

Story: `.team/stories/s41.md`. Investigation (AC1): `docs/notes/s41-sigterm-cause.md`.
Decision: `docs/adr/ADR-009-signal-only-own-groups.md`. Developer: `developer-cli`.

## Why

The developer agent killed its own CLI. `ps aux | grep "[p]ytest"` matched the
CLI, because the SDK puts the role's system prompt on the CLI's argv, and the
agent then ran `kill <that pid>`. The fix (AC4) is a guard rule: role Bash may
not signal the runner's process group, and may not choose kill targets by name
or at run time (K1–K5). The sandbox lead (AC2) was not the cause, but it is a
real risk and is closed too: the runner signals only a group it created
(G1–G6). Both live in code.

## Rules

### Runner side: which groups the runner signals (AC2, AC3)

| # | Rule |
|---|---|
| G1 | **One module decides.** Every group signal the runner sends goes through `agile_team/process_groups.py`. That covers `sandbox.Prepared.stop`, `sandbox.stop_stale` and `commands.kill_group`. No other module calls `os.killpg`. |
| G2 | **A child's group.** `signal_child_group(pid, sig)` sends `os.killpg(pid, sig)` only when `may_signal_child_group(pid)` holds: `pid > 1`, `pid != os.getpgrp()` (never the runner's or caller's own group), and either `os.getpgid(pid) == pid` (the child leads its own group, as `start_new_session=True` makes it) or the lookup raises `ProcessLookupError` (the leader exited; while the `Popen` is unreaped no other process can hold that pid). Any other lookup result refuses: a child that shares a parent's group, or the runner's own pid. `ProcessLookupError` and `PermissionError` from `killpg` are suppressed. The pgid is never taken from `os.getpgid(...)` (s43 T4). |
| G3 | **A recorded group (pid file).** A pid read from `<delivery>.pid` is signalled only if `Recorded(pid, written).is_ours()`. `written` is the pid file's `st_mtime`. `is_ours()` requires `leads_own_group(pid)` (alive, `getpgid(pid) == pid`, `pid > 1`, not `os.getpgrp()`) **and** `started_at(pid) <= written + STARTED_SLACK_S`. A pid reused after the file was written belongs to a process that started later, so it is ignored. A process whose start time cannot be read is ignored. A stale pid (no process) is ignored. The pid file format is unchanged (bare pid), so legacy files work. |
| G4 | **Start time from `ps`.** `started_at(pid)` runs `ps -o etime= -p <pid>` (stdlib `subprocess.run`, `timeout=PS_TIMEOUT_S`, `check=False`, `capture_output=True`, `text=True`) and returns `time.time() - parse_etime(out)`. A non-zero exit, empty or unparseable output, `OSError` or `TimeoutExpired` returns `None`. `etime` is `[[dd-]hh:]mm:ss` on macOS and Linux, and elapsed time avoids time zones. |
| G5 | **Re-check before escalating.** `_end_group(recorded)` sends SIGTERM, waits up to `STOP_WAIT_S` for the group to end (`os.killpg(pid, 0)` until `ProcessLookupError`, polling every 0.05 s), then sends SIGKILL only if `recorded.is_ours()` still holds. If the leader died but members of its group remain, they are not chased. The port then stays busy, and `PortBusy` holds as s26 already does. |
| G6 | **`Prepared.stop` and `commands.kill_group` use G2.** `_signal_group(process, sig)` keeps its name and signature (tests patch it) and becomes `signal_child_group(process.pid, sig)`. `commands.kill_group(proc)` becomes `signal_child_group(proc.pid, signal.SIGKILL)`. |

### Role side: what a role's Bash may signal (AC4)

These checks run in the PreToolUse hook, inside the runner's process, for every
role. "The runner's group" is `os.getpgrp()` there. It holds the runner and
the agent CLIs it starts, because the SDK does not start them in a new
session.

| # | Rule |
|---|---|
| K1 | **No kill by name.** A segment with a word whose basename is `pkill` or `killall` is denied with `BY_NAME_DENIED`. They match argv, the agent's argv holds its whole prompt, and Linux `pkill` does not skip ancestors. |
| K2 | **Find the kill.** In each segment (the guard's existing `_SEGMENT_SPLIT` and `_tokens`), the kill command is the first word whose basename is `kill` (`kill`, `/bin/kill`, after `sudo`, `timeout 5` and the like). Its arguments are the words after it. A segment with no such word passes K2–K4. |
| K3 | **Targets.** `kill_targets(args)` drops one leading signal option (`-9`, `-TERM`, `-l`; `-s X` and `-n X` drop two words), then one `--` if present. The rest are targets. |
| K4 | **Denied targets.** A target containing `$(` or a backtick, or a kill word preceded in its segment by `xargs`, is denied with `AT_RUN_TIME_DENIED`: the target is picked at run time and cannot be checked. A numeric target (`-?\d+`) is denied with `RUNNER_DENIED` when it is `0` (the shell's group), `-1` (every process), `-<runner pgid>`, or a pid `n > 0` where `in_runner_group(n)` holds (alive and `os.getpgid(n) == os.getpgrp()`). Other targets pass: `$PID`, `$!`, `%1`, a pid outside the runner's group, a stale pid. |
| K5 | **The prompt says it.** `roles/_shared.md`, section "Never wait without a deadline", gets the bullet in "Exact strings". |

Residual risk, documented in protocol.md: a variable target (`kill $p` in a
loop over `$(pgrep …)`) cannot be resolved by the hook and passes. K1 and K4
block the common forms. The rule is there to stop mistakes, not a hostile
role.

## Exact strings

```python
# process_groups.py
STARTED_SLACK_S = 2.0   # etime has 1 s resolution, and mtime and now are both truncated
PS_TIMEOUT_S = 5.0
ETIME_COMMAND = ("ps", "-o", "etime=", "-p")

# kill_check.py
BY_NAME = frozenset({"pkill", "killall"})

VALUE_OPTIONS = frozenset({"-s", "-n"})
END_OF_OPTIONS = "--"
NUMBER = re.compile(r"-?\d+")
ALWAYS_PROTECTED = frozenset({0, -1})
KILL_FIX = "kill only a process you started, by the pid you saved: `cmd & PID=$!` … `kill $PID`"
BY_NAME_DENIED = (
    "`{word}` picks processes by name, and the agent running you has your whole prompt "
    "on its command line, so it can match itself; " + KILL_FIX
)
RUNNER_DENIED = (
    "`kill {target}` would signal the runner or the agent running you "
    "(the runner's process group); " + KILL_FIX
)
AT_RUN_TIME_DENIED = (
    "`kill` with targets chosen at run time (`$(…)`, backticks or `xargs`) "
    "cannot be checked; " + KILL_FIX
)
```

`roles/_shared.md`: add the third bullet below to "## Never wait without a deadline",
after "Give every wait a deadline…":

```markdown
- Stop only what you started, by the pid you saved (`cmd & PID=$!` … `kill $PID`).
  `pkill`, `killall`, `kill $(…)`, `xargs kill` and a pid in the runner's process
  group are denied: the agent running you has your prompt on its command line, so
  `ps | grep` or `pkill -f` can find, and kill, yourself.
```

## Changes per module

### New `agile_team/process_groups.py` (stdlib only)

Module docstring: "Which process groups the runner may signal (s41): only groups
it created, never its own."

```python
def leads_own_group(pid: int) -> bool: ...
    # pid > 1 and pid != os.getpgrp() and os.getpgid(pid) == pid; any OSError -> False
def may_signal_child_group(pid: int) -> bool: ...          # G2
def signal_child_group(pid: int, sig: int) -> None: ...    # G2; suppress ProcessLookupError, PermissionError
def in_runner_group(pid: int) -> bool: ...                 # K4; os.getpgid(pid) == os.getpgrp(); OSError/OverflowError -> False
def parse_etime(text: str) -> float | None: ...            # G4; "07"->None, "05:07"->307, "1:02:03"->3723, "2-01:00:00"->176400
def started_at(pid: int) -> float | None: ...              # G4; time.time() - elapsed

@dataclass(frozen=True)
class Recorded:
    """A process group named in a pid file, and when that file was written."""
    pid: int
    written: float
    def is_ours(self) -> bool: ...                         # G3: leads_own_group first (no subprocess), then started_at
```

Keep each function under 8 lines. Split `started_at` into a private
`_elapsed(pid) -> str | None` (runs `ps`) plus the arithmetic. `parse_etime`:
`days, _, clock = text.strip().rpartition("-")`, then 2 or 3 all-digit `:`
parts, and days all-digit or empty; otherwise `None`.

### `agile_team/sandbox.py`

- `from .process_groups import Recorded, signal_child_group`
- `_signal_group(process, sig)` → `signal_child_group(process.pid, sig)` (G6).
- Delete `_group_leader`.
- `def _recorded(pid_file: Path) -> Recorded | None`: `Recorded(int(text.strip()), pid_file.stat().st_mtime)`. `OSError` or `ValueError` gives `None`.
- `def _ends_within(pgid: int, seconds: float) -> bool`: polls `os.killpg(pgid, 0)` with a `time.monotonic()` deadline and `time.sleep(0.05)`. Returns `True` on any `OSError` (gone, or not ours to signal) and `False` at the deadline.
- `def _end_group(recorded: Recorded) -> None` (G5): `signal_child_group(recorded.pid, SIGTERM)`; if `not _ends_within(recorded.pid, STOP_WAIT_S) and recorded.is_ours()`, then `signal_child_group(recorded.pid, SIGKILL)`. Read `STOP_WAIT_S` at call time, because tests patch it.
- `stop_stale(root)`: `recorded = _recorded(pid_file)`; if `recorded and recorded.is_ours()`, `_end_group(recorded)`; then `pid_file.unlink(missing_ok=True)`.
- `Prepared.stop` is otherwise unchanged.

### `agile_team/commands.py`

- `kill_group(proc)` → `signal_child_group(proc.pid, signal.SIGKILL)`. Update its docstring ("only if the group is the command's own, s41"). Drop imports that become unused.

## Test checklist

Unit tests never send a real signal to the test process or its group: patch
`os.killpg` with a recorder, or use children started with
`start_new_session=True`. Tests that give `Prepared.stop` a fake process keep
using the `stopped` fixture.

**process_groups (AC2, AC3)**
1. `signal_child_group` with `os.killpg` patched to record calls. Each of these sends **nothing**, and no recorded pgid equals `os.getpgrp()`:
   (a) a real `Popen(["sleep", "30"])` without a new session, which is in the test's group;
   (b) `os.getpid()`;
   (c) `os.getpgrp()`;
   (d) `0`, `1` and `-5`.
   This test fails against the old `_signal_group`, which sent `killpg(getpgid(pid))` for (a) and (b). Run (a) and (b) through `sandbox._signal_group(process, sig)` as well.
2. A real `Popen(["sleep", "30"], start_new_session=True)` is signalled with `killpg(pid, sig)` (recorder), and so is a pid whose `getpgid` raises `ProcessLookupError`, with `getpgid` patched.
3. `leads_own_group`: true for a new-session child; false for a same-group child, for `os.getpid()`, and for a reaped pid.
4. `in_runner_group`: true for `os.getpid()` and for a same-group child; false for a new-session child, a reaped pid and `10**30` (overflow).
5. `parse_etime`: the four examples in the module section, `""`, `"abc"`, `"1:2:3:4"` and `"x-01:00"`.
6. `started_at`: a fresh child gives a value within 3 s of `time.time()`. A reaped pid gives `None`. A `subprocess.run` patched to raise `TimeoutExpired` or `OSError`, or to return a non-zero code, gives `None`.
7. `Recorded.is_ours`: true for a new-session child with `written = time.time()`. False when `written` is an hour before now (a reused pid), for a same-group child, for `os.getpid()`, and when `started_at` is patched to return `None`.

**sandbox (AC2, AC3)**
8. `stop_stale` leaves a new-session `sleep` alive when the pid file's mtime is set an hour back with `os.utime` (a reused pid). The file is deleted. This fails against the old code.
9. `stop_stale` with a pid file holding `os.getpid()`, or `os.getpgrp()`, sends nothing (recorder on `os.killpg`), and the file is deleted.
10. The existing tests keep passing unchanged: the stale leader is killed (`stop_stale`, SIGTERM-ignoring group → SIGKILL), a dead pid only removes the file, a non-leader is never signalled, `prepare` replaces a stale service, and stop escalates to SIGKILL.
11. G5: when `is_ours()` turns false between SIGTERM and the deadline (patch it with a counter), no SIGKILL is sent.

**commands**
12. `kill_group` with a proc whose pid is in the test's group (a same-group `Popen`) sends nothing (recorder). A new-session proc is killed. The existing s43 timeout tests stay green.

**guard / kill_check (AC4)**
13. `check_bash(scope, f"kill {os.getpid()}")` is denied with `RUNNER_DENIED`, which reproduces the incident (fails before the fix). So are `kill -9 <same-group child pid>`, `kill -- -{os.getpgrp()}`, `kill 0`, `kill -- -1`, `/bin/kill -s TERM <os.getpid()>` and `sudo kill <os.getpid()>`.
14. `pkill -f pytest`, `killall python` and `/usr/bin/pkill x` are denied with `BY_NAME_DENIED` (`{word}` filled with the basename). The command is never run.
15. `kill $(pgrep -f pytest)`, ``kill `cat p` ``, `kill "$(cat p)"` and `pgrep x | xargs kill` are denied with `AT_RUN_TIME_DENIED`.
16. These pass: `kill $PID`, `kill $!`, `kill %1`, `kill <new-session child pid>`, `kill <reaped pid>`, `kill -l`, `ps aux | grep "[p]ytest"`, `pgrep -f pytest`, `grep -n kill foo.py` and `git log --grep kill`.
17. `kill_targets`: `["-9", "1", "2"]`→`["1","2"]`, `["-s", "TERM", "3"]`→`["3"]`, `["--", "-4"]`→`["-4"]`, `["-9", "--", "-4"]`→`["-4"]`, `[]`→`[]`.
18. The order of checks: a command that also breaks the git rule reports the git reason first, so `_check_kills` runs last.

**Quality**
19. Coverage stays at or above 95% (currently 100%), and ruff check and ruff format are clean.
