## The rule (ADR-0071)

A Python module or script holds only these statements at its top level:

| Allowed top-level statement | AST node |
|---|---|
| the module docstring (first statement only) | `Expr` whose value is a `str` `Constant`, at index 0 |
| imports | `Import`, `ImportFrom` |
| assignments of constants and tables | `Assign`, `AnnAssign` |
| definitions | `FunctionDef`, `AsyncFunctionDef`, `ClassDef` |
| the entry guard | `If` whose test is exactly `__name__ == "__main__"` |

Anything else is forbidden at the top level: loops, `with`, `try`, bare calls,
any other `if`. The work runs in one entry function, `main` (or
`just_do_it` when `main` doesn't fit), and the guard calls it. The guard's body
calls the entry function and nothing more, e.g. `sys.exit(main(sys.argv[1:]))`.
