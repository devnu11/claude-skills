## Rules

1. The retired-role text check matches **scribe as a whole word**, case
   insensitive. "describe", "prescribe" and "Describes" never match;
   "scribe", "Scribe" and "the Scribe's" do.
2. The fixture test pins every part of the dashboard fixture that names a
   role: `roles[].name`, and `role` on each entry of `events`, `ledger` and
   `steps`. None of them is `"scribe"`. A missing `role` key counts as `None`.
3. The test must not pass vacuously: the same set of names contains
   `"architect"` (the fixture has architect rows in all four places).
4. `product-owner.md` stays the same text apart from the two fixes below; the
   Mission paragraph and item 5 are wrapped at the file's width (lines of at
   most 78 characters, list continuation lines indented three spaces).

Add a helper below `stub_text`:

```python
def fixture_role_names(snapshot: dict) -> set[str | None]:
    """Every role name the dashboard fixture mentions: roles, events, ledger, steps."""
    named = {r["name"] for r in snapshot["roles"]}
    return named | {e.get("role") for key in ROLE_SECTIONS for e in snapshot[key]}
```

### Prose checks for AC3/AC4 (amended at design review, round 1)

The first draft said no test would pin prose. The implementation added two
narrowly scoped tests in `test_s114.py`, and they are kept as the automatic
check for AC3 and AC4:

- `po_body() -> str`: the resolved built-in `product-owner` body
  (`RoleBook.for_repo(Path("/none"), {}).resolve("product-owner").body`),
  shared with `test_product_owner_does_not_run_a_scribe`.
- `test_po_mission_has_the_missing_and`: the body contains
  "sends a story back with\nthe gate's reason, and runs the manager".
- `test_po_item_5_is_a_capitalised_wrapped_sentence`: item 5's continuation
  lines are as above, and every line between `"\n5. A story in your prompt is
  held."` and `"\n6. "` is at most 78 characters. If item 5's opening line
  disappears, the split raises `IndexError`, so the test cannot pass vacuously.

Rule: these checks look only at the two blocks the ACs name. No test may pin
any other passage of `product-owner.md`; the rest of the prose stays free to
change.
