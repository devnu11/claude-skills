# s99 (A6b): the runner's own stages are named, timed and kept as data

Story: `.team/stories/s99.md`. Plan context: `.team/run/liaison/plans/tool-flow.md`
("The names of the tools are data", A6b). Builds on s97 (`Mark`, `Platform`,
`Pulse.mark`, `FakeSystem.doze`) and s98 (`tool_calls.POSITIONS`, `shown`,
`NAMED_SERVERS`). No new dependency (stdlib `contextvars` only), no ADR: it
extends the s44 chore/meter and s98 span patterns.

## What changes, in one paragraph

A new pure module `stages.py` holds the table of every stage the runner runs
(`Name` enum, `STAGES`), the attachment `Place`, and the open-stage record
`Run`. The caller of each stage opens it by name (`StageLog.open(Name.X)`);
the choke points that run commands (`CommandShell.run`, `Git._exec`, the `gh`
runner behind `GhPrs.wait_checks`, `sandbox.run_shell` and the service start in
`Preparer._serve`) only *note* the command and exit code into the stage that is
open, through a context variable. When the stage closes, a new module
`stage_log.py` writes one `runner-stage` event to `events.jsonl` with its name,
`when`, attachment, story, step, command detail, exit code, start clocks and
awake seconds. `.agile-team.toml` gains `[[tool]]` rows (DevOps-owned, refused
on load when malformed, repeated or clashing), and `agile-team tools` prints
the built-in and repo lists as JSON.

## Rules

| # | Rule |
|---|---|
| RS1 | **One table.** `stages.STAGES: dict[Name, Stage]` has one row per `Name` member, in the order of the table below. `Stage` is `(name, description, when, attach)`. A test pins `set(STAGES) == set(Name)` and that every name is unique (the enum guarantees it) and matches `STAGE_NAME`. |
| RS2 | **The caller names the stage.** A stage is opened only with a `Name` member, by the code that decides to do that work. No code derives a stage from command text, a command's argv, or a toolchain command string. `stages.opened` raises `KeyError` for a value not in `STAGES`, so a path that opens an unlisted stage fails every test that runs it. |
| RS3 | **Choke points note, they do not name.** `stages.note(command, code)` adds a command and its exit code to the innermost open `Run` (a `contextvars.ContextVar`); with no stage open it does nothing. So a git query or shell command run outside a stage is never recorded as one. Context variables follow `asyncio.to_thread`, so a runner tool's batch, run in a thread, notes into its stage. |
| RS4 | **One event per stage run.** Closing a stage (normally or by an exception) writes exactly one `runner-stage` event, however many commands it noted. Stages may nest (none do in s99); each writes its own event and notes go to the innermost. |
| RS5 | **Detail and code.** `Run.note` keeps the first noted command whose code is non-zero; until one fails it keeps the latest noted command. The event's `detail` is that command through `tool_calls.shown` (secrets masked, whitespace collapsed, at most 80 characters); `""` when nothing was noted. `code` is that command's exit code; when nothing was noted it is `0` if the stage body returned and `null` if it raised. |
| RS6 | **Raised.** When the stage body raises, the event's `raised` is the exception's class name (`"GitError"`, `"NotUp"`, `"CancelledError"`) and the exception propagates unchanged; otherwise `raised` is `null`. |
| RS7 | **Clocks and awake time.** The stage's start is the clock's `Mark` when it opens (wall `started_at`, `started_mono`, `started_slept`); its end is the `Mark` when it closes. `seconds` = `tool_calls.awake_gap(platform, (start, end))`: `max(0, pos(end) − pos(start))` with `POSITIONS[platform]` (POSIX monotonic, Windows wall less counted sleep), rounded to 3 decimals. |
| RS8 | **Attachment.** The event's `story` and `data.step` come from the `StageLog`'s current `Place`. `Runtime.run_role` sets it to the requested story and its step at request time for the whole step (before-stages, runner tools, gate, after-checks); the PO's `pass_tests` sets it for its green check. Elsewhere (router tick, PO turn, boundary) it is `Place()`, both `null`. `data.attach` is always the table row's, never derived from the place. |
| RS9 | **When.** `data.when` is the row's `when`: `before` (runs before the step it attaches to, or before a sprint), `after` (after the step, or closing a sprint), or `during` (the runner works inside an agent step at the agent's request: the `runner-tool.*` rows). `during` is the one value beyond the AC's two, because a runner tool is neither before nor after its step. |
| RS10 | **A lost line never stops the run.** The event is emitted with `OSError` suppressed (like `turns.jsonl`, s44). |
| RS11 | **Repo tools are data.** `[[tool]]` rows have `name`, `description` and `command`, all non-empty strings after strip. `config.from_raw` refuses the file (`ConfigError`) when any row breaks a rule: name not matching `TOOL_NAME`; name equal to a built-in name or in a built-in namespace (`stages.reserved`); empty description or command; a name repeated. The message lists every problem, `; `-joined, each as `[[tool]] {name!r} {problem}` (repeats: `[[tool]] name {name!r} is repeated`). |
| RS12 | **DevOps owns `[[tool]]`.** `"tool"` joins `dispatch.DEVOPS_SECTIONS`, so a role's config edit that only touches `[toolchain]`, `[[delivery]]` or `[[tool]]` is kept, and any other is quarantined, as today. |
| RS13 | **Repo tools are a format only in s99.** Nothing runs a `[[tool]]` command, and `tool_calls.named` is unchanged: an agent's Bash call is never matched to a repo tool by its text (RS2). The built-in `runner-tool.*` stage names already equal s98's labels for `mcp__runner__*` calls; a test pins it. |
| RS14 | **`agile-team tools`** prints one JSON object: `{"built_in": [...], "repo": [...]}`. `built_in` is `STAGES` in table order, each `{"name", "description", "when", "attach"}`; `repo` is the config's `[[tool]]` rows in file order, each `{"name", "description", "command"}`. A broken `[[tool]]` exits non-zero with the RS11 message (the `CliError` path every command uses). |

## The event (RS4–RS8)

One line in `events.jsonl` (`EventKind.RUNNER_STAGE = "runner-stage"`):

```json
{"kind": "runner-stage", "role": "runner", "story": "s99",
 "data": {"stage": "gate.tests+coverage", "when": "after", "attach": "step",
          "step": "implement", "detail": "uv run pytest --cov -q", "code": 0,
          "raised": null, "started_at": 1760313600.0, "started_mono": 5321.4,
          "started_slept": 0.0, "seconds": 41.253},
 "at": 1760313641.3, "id": "e812"}
```

- `role` is `stages.RUNNER_ROLE = "runner"` (the same value as
  `boundary.BOUNDARY_ROLE`; A6c's `runner` row).
- `data` keys in exactly this order: `stage`, `when`, `attach`, `step`,
  `detail`, `code`, `raised`, `started_at`, `started_mono`, `started_slept`,
  `seconds`.
- `at` is the emit time (the stage's end), as for every event.
- The dashboard's Timeline tab has no `TIMELINE["runner-stage"]` row, so these
  events are in the snapshot's `events` but not drawn (A6c and A6e draw them).
  No snapshot code or fixture change.
- The `tests-run` event (s69) stays; a runner tool writes both.

## Changes per module

### New `agile_team/stages.py` (pure; stdlib only: `contextlib`, `contextvars`, `dataclasses`, `enum`, `re`)

No import from other `agile_team` modules, so `git_ops`, `commands`,
`upstream`, `sandbox`, `gates` and `config` can import it without a cycle.

```python
RUNNER_ROLE = "runner"
NOT_UP = 1                       # the code noted for a service that never answered
STAGE_NAME = re.compile(r"[a-z0-9-]+\.[a-z0-9_+-]+")
PO_NAMESPACE = "po"              # s98's po.* labels

class When(StrEnum): BEFORE = "before"; AFTER = "after"; DURING = "during"
class Attach(StrEnum): STEP = "step"; STORY = "story"; BOUNDARY = "boundary"
class Name(StrEnum): ...         # the 21 members of the table above, values = names

@dataclass(frozen=True)
class Stage:
    """One row: a stage's name, description, when it runs and what it attaches to."""
    name: Name; description: str; when: When; attach: Attach
    def as_dict(self) -> dict[str, str]          # RS14 keys, str values

STAGES: dict[Name, Stage]                         # RS1, table order
NAMESPACES: frozenset[str]                        # {n.split(".")[0] for n in Name} | {PO_NAMESPACE}
QUALITY: dict[str, Name]                          # "lint"/"static"/"coverage" → QUALITY_*
BOUNDARY: dict[str, Name]                         # boundary.Stage values "sync"…"ci" → BOUNDARY_*
RUNNER_TOOL: dict[str, Name]                      # runner_tools.SCHEMAS keys → RUN_TESTS, RUN_NEW_TESTS

def reserved(name: str) -> bool                   # RS11: name in STAGES or its namespace in NAMESPACES

@dataclass(frozen=True)
class Place:
    """The story and step a stage run attaches to; both None outside a step."""
    story: str | None = None
    step: str | None = None

NOWHERE = Place()

@dataclass
class Run:
    """One open stage: its row, place, and the command kept for the event (RS5, RS6)."""
    stage: Stage; place: Place
    detail: str = ""; code: int | None = None; raised: str | None = None
    def note(self, command: str, code: int) -> None   # RS5: if self.code: return; else keep both

Opener = Callable[[Name], AbstractContextManager[Run]]

_OPEN: ContextVar[Run | None]                     # default None

@contextmanager
def opened(name: Name, place: Place) -> Iterator[Run]
    # STAGES[name] (KeyError for an unlisted value, RS2); set _OPEN; yield;
    # on BaseException set run.raised = type(exc).__name__ and re-raise; reset _OPEN in finally

def unlogged(name: Name) -> AbstractContextManager[Run]   # opened(name, NOWHERE); the default Opener

def note(command: str, code: int) -> None         # RS3: _OPEN.get() and its .note(...), else nothing
```

`QUALITY` keys are `gates.ROUTED_COMMANDS` plus `"coverage"`; `BOUNDARY` keys
are the `boundary.Stage` values; `RUNNER_TOOL` keys are `runner_tools.SCHEMAS`'
keys. Tests pin all three (stages.py imports none of those modules).

### New `agile_team/stage_log.py`

Imports: `stages`, `events` (`Event`, `EventKind`, `EventLog`),
`tool_calls` (`shown`, `awake_gap`), `dashboard.step_times` (`Mark`,
`Platform`); `gates.StoryState` under `TYPE_CHECKING` only.

```python
class Marker(Protocol):
    """What a StageLog reads its clocks from; ``live.Pulse`` is one."""
    platform: Platform
    def mark(self) -> Mark: ...

def place_of(story: StoryState | None) -> stages.Place    # Place(story.id, story.step), or NOWHERE

@dataclass(frozen=True)
class Timed:
    """A closed stage run with its start and awake seconds."""
    run: stages.Run; start: Mark; seconds: float
    def data(self) -> dict[str, Any]              # the event's data, keys in order (RS5–RS7)

@dataclass(eq=False)
class StageLog:
    """Opens named stages, times them and writes one runner-stage event each."""
    log: EventLog
    clock: Marker
    place: stages.Place = stages.NOWHERE

    @contextmanager
    def within(self, place: stages.Place) -> Iterator[None]   # set self.place; restore the old one on exit (RS8)

    @contextmanager
    def open(self, name: stages.Name) -> Iterator[stages.Run]
        # start = clock.mark(); with stages.opened(name, self.place) as run: yield run
        # finally: self._emit(run, start)

    def _emit(self, run: stages.Run, start: Mark) -> None
        # end = clock.mark(); seconds = awake_gap(clock.platform, (start, end));
        # with suppress(OSError): log.emit(Event(RUNNER_STAGE, RUNNER_ROLE, run.place.story, Timed(...).data()))
```

`Timed.data()`: `code` is `run.code`, or `0` when `run.code is None and
run.raised is None` (RS5); `detail` is `shown(run.detail)`; `started_mono` is
`start.mono`, `started_slept` is `start.slept`.

The `finally` that emits must sit outside `stages.opened`'s block so the run
already carries `raised` when `_emit` reads it.

## Known limits

- `checkout.guard` runs on every router tick and PO turn, so it is the most
  frequent stage; outside a step its story and step are `null`.
- A killed runner writes no event for the stage it was in (as for open tool
  calls, s98 TC3).
- `boundary.*` rows have one fixed `when`; the sprint edge is on the nearest
  `boundary` event.
- Nothing runs `[[tool]]` commands yet (RS13).
- `StageLog.place` is one shared field, not a context variable. That is right
  while the runner runs one step at a time (it has no `gather`, task group or
  `create_task`); a story that runs steps concurrently must make the place a
  `ContextVar`, as `stages._OPEN` is (review N1).
- A `[[tool]]` row that is not a table (`tool = ["x"]`) fails on load with an
  `AttributeError`, not the RS11 `ConfigError` message (review m2). Left for a
  later config-shape story.

Design review (round 2): code matches RS1–RS14; docs at ship landed in this
step (protocol "Runner stages (s99)", CLI `tools` row, `[[tool]]` keys and
refusals; SKILL.md; README row; `customer/runner-stages.md`; architecture
rows for `stages.py`, `stage_log.py` and the noting modules).
