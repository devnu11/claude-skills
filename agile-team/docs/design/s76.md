## Test infrastructure (unit-tester)

### `tests/fake_system.py` additions

s71's "Commands", "Processes", "Ids and signals", "Clock" (`wait_event`,
`ticks`), "Environment" (`env`) and "Network" bullets apply. What s71 left
open:

```python
FIRST_CHILD_PID = 5000            # the first spawned child's pid; each spawn adds 1

class Hang(NamedTuple):           # a scripted child that runs until its group is signalled
    out: str = ""                 # what it has written (communicate / the log)
```

- **Spawn.** `spawn_piped` / `spawn_logged` take the next pid, register it
  as its own group leader (`groups[pid] = pid`, a new session) and record the
  command. The matching reply decides the child: `Done(code, out)` = already
  exited (`poll()` → `code`, `communicate()` → `(out, None)`); `Hang(out)` =
  running (`poll()` → `None`, `communicate(timeout)` raises
  `system.TimeoutExpired` and advances the clock by `timeout`). No rule:
  `Done()`. `spawn_logged` writes `out` to the log path at spawn.
- **Signals end groups.** `killpg(g, sig)` with `sig != 0` records `("killpg",
  g, sig)`, raises `ProcessLookupError` when no pid in `groups` has group `g`,
  else ends every member except, for `SIGTERM`, the pids in
  `fake.survivors: set[int]` (SIGKILL ends all). `kill(pid, sig)` does the
  same for one pid. Ending a pid removes it from `groups` and from `holds`;
  a spawned `Hang` child then reports `returncode == poll() == -sig` and
  `communicate()` returns `(out, None)`. Signal `0` only checks liveness.
- **Leader gone, group alive** (s82's dash case): a test adds a member,
  `fake.groups[FIRST_CHILD_PID + 100] = FIRST_CHILD_PID`, and may list it in
  `survivors`. `poll()` of the leader follows the leader only.
- **Runner ids.** At construction `groups = {FAKE_IDS[0]: FAKE_IDS[1]}`, so
  `pgid(pid())` is `pgrp()`.
- **Ports.** `listening: set[tuple[str, int]]` answers `connect`;
  `holds: dict[int, tuple[str, int]]` maps a pid to the address it listens
  on. A test calls `fake.listening.add(addr); fake.holds[pid] = addr`; ending
  the pid discards the address from `listening`.
- **`wait_event(event, timeout)`**: as s71 (`True` at once if set; else
  advance the clock by `timeout` and return `False` while `ticks > 0`,
  decrementing; then `True`).

### `tests/kill_words.py` (new, pure; J6)

```python
WORDS: tuple[str, ...] = ("pkill", "killall")
PATTERN = re.compile(r"\b(pkill|killall)\b")
CODE_SUFFIXES = frozenset({".py", ".sh", ".bash", ".zsh", ".yml", ".yaml", ".toml", ".js", ".mjs", ".html"})
ALLOWED: frozenset[str] = frozenset({         # repo-relative posix paths
    "agile-team/runner/agile_team/kill_check.py",                  # BY_NAME, the K1 denylist
    "agile-team/runner/tests/test_kill_check.py",                  # the K1 case table
    "agile-team/runner/tests/e2e/test_signal_own_groups_e2e.py",   # K1 on the real guard
    "agile-team/runner/tests/kill_words.py",                       # this table
})

def is_code(path: str, text: str) -> bool:
    """A code or script file: a CODE_SUFFIXES suffix, or no suffix and a ``#!`` first line."""

def offenders(files: Mapping[str, str]) -> list[str]:
    """``"<path>:<line>: <word>"`` for each use of a WORDS word in a code file not in ALLOWED."""
```

Pure: it receives `{path: text}` and reads nothing. Its unit test builds the
offending text from `WORDS` (`f"{WORDS[0]} -f x"`), so the test file needs no
`ALLOWED` row.

**Ruling on `tests/test_s62_tell.py:137`.** `rt.relay.tell("SECRET-WORDS
pkill -f")` becomes `rt.relay.tell("SECRET-WORDS")`. The test asserts
`"SECRET-WORDS"` is not in the pass lines; the `pkill -f` suffix plays no part
in that, so the test proves the same thing.
