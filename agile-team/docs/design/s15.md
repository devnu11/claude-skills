# s15: Dashboard renders Markdown safely

**Story:** `.team/stories/s15.md` (AC1–AC4). **Developer:** `developer-gui`.
**Decision record:** ADR-0042 (the Scribe writes it from the "Decision" section below).
**Touches:** `agile-team/runner/agile_team/dashboard/index.html` only (code);
tests under `agile-team/runner/tests/`; docs listed at the end.

## Decision (for ADR-0042)

- **Library:** `markdown-it@14.1.0`, file `dist/markdown-it.min.js` (one self-contained
  UMD file, MIT, no dependencies at runtime). Pinned URL:
  `https://cdn.jsdelivr.net/npm/markdown-it@14.1.0/dist/markdown-it.min.js`.
- **Why markdown-it:** it is safe by configuration in one file. `html: false` escapes
  raw HTML; `validateLink` vets every link and autolink; tables, fenced code and
  strikethrough are in the default preset. `marked` has no HTML escaping and would
  need DOMPurify, a second pinned URL. A hand-written renderer would break AC4.
- **Loaded like Mermaid:** a dynamic `import()` of the pinned URL, once, no build
  step. The UMD wrapper runs in module scope, where `this` is undefined, so it sets
  `globalThis.markdownit`. The page reads the factory from there.
- **Plain text until loaded, and for good if it fails.** Rendering stays
  synchronous. `md()` returns escaped plain text until the library arrives. Then the
  page re-renders once.
- **Testable offline:** a byte-for-byte copy of the pinned file lives in
  `agile-team/runner/tests/vendor/` (test data, not shipped), so node tests feed the
  real library. A test ties the copy's version to the pinned URL.
- **Consequence:** the page now has two outside URLs (Mermaid and markdown-it). The
  "only outside URL" rule and its e2e test become "exactly these two pinned
  libraries".

## Rules

| # | Rule | AC |
|---|---|---|
| M1 | **One renderer.** `md(text)` is the only function that turns Markdown into HTML. Every Markdown place calls it. `markdownit(` appears once in the page, inside `safeMarkdown`. No other code calls `.render(` on the library. | AC1, AC3 |
| M2 | **Output shape.** Loaded: `md(text)` returns `<div class="md">` + `markdown.render(String(text ?? ""))` + `</div>`. Not loaded: `<div class="md plain">` + `esc(text)` + `</div>`. `null`/`undefined` give an empty div, never the word "undefined". | AC1, AC4 |
| M3 | **Supported syntax** comes from markdown-it's `default` preset: headings, paragraphs, lists (bulleted and numbered), emphasis/strong, inline code, fenced code, tables, links, blockquotes, strikethrough. Options: `{ html: false, linkify: false, typographer: false, breaks: true }`. `breaks: true` keeps single newlines as `<br>`, as the old `pre-line` text did. | AC1 |
| M4 | **No raw HTML.** `html: false`, so `<script>`, `<img onerror=…>`, `<iframe>` and any other tag show as escaped text. | AC2 |
| M5 | **Links: http(s) only.** `markdown.validateLink = (url) => SAFE_LINK.test(url)` with `const SAFE_LINK = /^https?:\/\//i;`. A refused link (`javascript:`, `data:`, `vbscript:`, `mailto:`, relative, `#frag`) is not a link. markdown-it then shows its source as text. This applies to `[x](…)`, `<…>` autolinks and reference links alike. | AC2 |
| M6 | **Link attributes.** `markdown.renderer.rules.link_open` sets `target="_blank"` and `rel="noopener noreferrer"` on every link token, then returns `self.renderToken(tokens, i, options)`. | AC2 |
| M7 | **No images.** `markdown.disable("image")`. `![a](url)` must never fetch anything, since the page loads only the two pinned libraries. | AC2 |
| M8 | **Load once at boot, re-render on arrival.** `boot()` calls `loadMarkdown()` without awaiting it, before the first data arrives. On success: `useMarkdown(globalThis.markdownit)`, then `render()`. On any failure (network, CSP, a changed wrapper that leaves `globalThis.markdownit` undefined, so `safeMarkdown` throws): `console.warn("markdown unavailable, showing plain text:", err.message)`. `markdown` stays `null` and there is no retry; reloading the page retries. The promise never rejects. | AC4 |
| M9 | **Where it is used** (AC3). Questions tab: open question text (`#q-open`), question text raised in handoffs (`#q-raised`), and answered question and answer text (`#q-done`). Timeline: bodies of `step-end` (handoff summary, or the reason/halt fallback), `message` and `answer` rows. Everything else stays `esc()` plain text. | AC3 |
| M10 | **Timeline picks by data.** `const MARKDOWN_KINDS = new Set(["step-end", "message", "answer"]);` and `const bodyHtml = (kind, text) => (MARKDOWN_KINDS.has(kind) ? md(text) : esc(text));`. `timelineRowHtml` writes `<div class="tl-body">${bodyHtml(e.kind, t.body)}</div>`. The `TIMELINE` table itself does not change. | AC3 |
| M11 | **No literal `http://` or `https://` in new page code** except the pinned `MARKDOWN_URL`. The e2e URL scan would count it. `SAFE_LINK` is written with escaped slashes, as above, and comments say "http(s)". | AC4 |
| M12 | **Styles** (in the `<style>` block, next to `/* questions */`, under a `/* markdown */` comment). They use only existing tokens (`--surface-2`, `--grid`, `--accent`, `--ink-2`). See "CSS" below. `.md` resets `white-space` to `normal`, because the `pre-line` on `.tl-body` would turn the newlines between rendered tags into blank lines. `.md.plain` keeps `pre-line`. | AC1, AC4 |

## Changes in `agile_team/dashboard/index.html`

### New section: `// ----- markdown ---…` (place it just after the helpers block, after `fmt`)

```js
const MARKDOWN_URL = "https://cdn.jsdelivr.net/npm/markdown-it@14.1.0/dist/markdown-it.min.js";
const SAFE_LINK = /^https?:\/\//i;
let markdown = null; // the configured markdown-it instance once loaded; null means plain text

/** A markdown-it instance configured for the dashboard: no raw HTML, http(s) links only, no images. */
function safeMarkdown(markdownit) { … }          // M3–M7; returns the instance

/** Install the library; from now on md() renders Markdown. */
function useMarkdown(markdownit) { markdown = safeMarkdown(markdownit); }

/** Load the pinned library once; redraw when it arrives, keep plain text if it can't load. */
function loadMarkdown() { … }                    // M8; returns the promise (never rejects)

/** The one Markdown renderer: safe HTML for `text`, or escaped plain text until the library loads. */
function md(text) { … }                          // M2
```

`safeMarkdown` body (one job, about 6 lines):

```js
const it = markdownit({ html: false, linkify: false, typographer: false, breaks: true });
it.disable("image");
it.validateLink = (url) => SAFE_LINK.test(url);
it.renderer.rules.link_open = (tokens, i, options, env, self) =>
  (tokens[i].attrSet("target", "_blank"), tokens[i].attrSet("rel", "noopener noreferrer"), self.renderToken(tokens, i, options));
return it;
```

(The developer may split `link_open` into a named `safeLinkOpen` function. The behaviour is fixed.)

`loadMarkdown` body:

```js
return import(MARKDOWN_URL)
  .then(() => { useMarkdown(globalThis.markdownit); render(); })
  .catch((err) => console.warn("markdown unavailable, showing plain text:", err.message));
```

### `boot()`

Add `loadMarkdown();` (not awaited) next to `setInterval(tick, 1000);`, so it runs on
both the live and the mock path.

### `renderQuestions` / `renderAnswered`

- `#q-open`: `<div class="q-text">${esc(q.text)}</div>` → `<div class="q-text">${md(q.text)}</div>`.
- `#q-raised`: same change.
- `#q-done`: the question becomes `<div class="q-text">${md(q.text)}</div>`. The
  answer becomes `<div class="q-answer"><b>You:</b>${md(answers[q.id].text)}</div>`, which
  replaces the `tl-body` div there. `.q-answer` is styled in M12.
- `q.id`, pills and the copy command stay as they are (`esc`).

### Timeline

Add `MARKDOWN_KINDS` and `bodyHtml` (M10) just above `timelineRowHtml`, and use them
for the body line. `tl-meta` stays plain.

## Tests

The node-driven page tests live in `tests/e2e/` (they spawn `node`). Use the existing
`dashboard_node.run_page(driver)` and `@pytest.mark.skipif(shutil.which("node") is None, …)`.
None of them needs the `dash` fixture.

**Vendored copy (tester's job, test data):** download the pinned URL byte for byte to
`agile-team/runner/tests/vendor/markdown-it-14.1.0.min.js`, keeping its license banner.
If no one on the team can reach `cdn.jsdelivr.net`, hand off `blocked` and ask the human
for the file. Don't hand-write a stand-in. In a driver, install the copy with
`useMarkdown(require(<absolute path>))`. The page script runs as CommonJS under node,
so the UMD wrapper returns the factory through `module.exports`.

- [ ] **Pin and copy agree (AC4).** Parse `MARKDOWN_URL` from `dashboard_node.page_script()`.

  `tests/vendor/markdown-it-<v>.min.js` exists, and its first 200 bytes contain `markdown-it <v>`.
  No node needed.
- [ ] **Syntax renders (AC1).** With the copy installed, `md()` of each input contains:
  `# H` → `<h1>`; `a\n\nb` → two `<p>`; `- a\n- b` → `<ul>` + 2 `<li>`;
  `1. a` → `<ol>`; `*e* **s**` → `<em>`, `<strong>`; `` `c` `` → `<code>c</code>`;
  fenced ```` ```py\nx\n``` ```` → `<pre><code class="language-py">`;
  `|a|b|\n|-|-|\n|1|2|` → `<table>`, `<th>`, `<td>`; `line1\nline2` → `<br>`.
  Each result starts with `<div class="md">`.
- [ ] **Links (AC2).** `[x](https://e.com/a)` and `[x](http://e.com)` give `<a href=…>`
  with `target="_blank"` and a `rel` holding `noopener`. `<https://e.com>` (autolink) does too.

  `[x](/relative)`, `[x](#frag)`, `<javascript:alert(1)>`, `<mailto:a@b.c>`,
  `![i](https://e.com/i.png)`, `` ```"><img src=x onerror=alert(1)>\nx\n``` ``,
  `[x](https://e.com "\" onmouseover=\"alert(1)")`.
  Parse every output with `html.parser`. Assert:
  (a) every tag is in `{div, p, br, h1–h6, ul, ol, li, em, strong, s, code, pre, blockquote, hr, table, thead, tbody, tr, th, td, a}`;
  (b) no attribute name starts with `on`;
  (c) every `href` matches `^https?://`;
  (d) every `a` has `rel` containing `noopener`;
  (e) the `<script>` input's output contains `&lt;script&gt;`.
- [ ] **Plain fallback (AC4).** With nothing installed, `md("# t\n<script>x</script>")` equals
  `<div class="md plain"># t\n&lt;script&gt;x&lt;/script&gt;</div>`, and `md(undefined)` and
  `md(null)` equal `<div class="md plain"></div>`.
- [ ] **Load failure keeps plain text (AC4, M8).** In the driver, `await loadMarkdown()`.
  Node refuses `https:` imports, so this is the offline case. The promise resolves,
  `markdown === null`, and `md("*a*")` is still the plain form.
- [ ] **Questions tab uses md (AC3).** The driver replaces `document.querySelector` with

- [ ] **Timeline uses md for handoffs only (AC3, M10).** With the copy installed,
  `timelineRowHtml` of a `step-end` event with `summary: "**done**"` contains
  `<strong>done</strong>`. A `gate` event with `reason: "**x**"` contains `**x**` and no `<strong>`.
- [ ] **One function, no copies (AC3, M1).** In `page_script()`: `markdownit(` occurs
  exactly once; `function md(` occurs exactly once; and the only `.render(` calls on

## Known limits

- Relative links (for example `docs/x.md`) show as text: there is no base to resolve
  them against. The Backlog tab (s83) may add one later. It would be a new rule in `safeMarkdown`.
- Bare URLs are not auto-linked (`linkify: false`). Write `<https://…>` to get a link.
- Briefs (`step-start`) and other timeline bodies stay plain text. Adding a kind is a
  one-word change to `MARKDOWN_KINDS`.
- The success path of `loadMarkdown` (a real browser import) is not tested automatically,
  just as Mermaid's real render isn't (s5 U8).
