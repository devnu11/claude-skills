# s134: One numbered queue instead of three copies

Story: `.team/stories/s134.md`. Requirements: REQ-036 (AC1, AC2).
ADR: ADR-0069 (new module boundary `numbered_queue.py`).
Developer: `developer-cli`.

## Problem

`relay.Relay.tell` (`t<N>.md`), `reorders.Requests.queue` (`r<N>.json`) and
`sharing.Shares.queue` (`f<N>.json`) each copy the same queue: make the
folder, write `.draft-<system.token()>`, `system.hard_link` it to the first
free number (moving on after `FileExistsError`), remove the draft in
`finally`. Each also copies the listing: match `^<prefix>(\d+)<suffix>$`,
sort by number. (s120 review F5.)

## Rules

| # | Rule | AC |
|---|---|---|
| R1 | One module, `agile-team/runner/agile_team/numbered_queue.py`, holds the draft-then-link queue and the numbered listing. It imports only `system` from `agile_team` (plus stdlib `itertools`, `re`, `dataclasses`, `pathlib`). | AC1 |
| R2 | `Relay.tell`/`told`, `Requests.queue`/`all` and `Shares.queue`/`all` go through a `NumberedQueue`. No other module calls `system.hard_link` or builds a `.draft-` name for these folders. `Relay._publish`, `_next_number`, `_told_at`, `relay.TOLD_NAME`, `Requests._numbered`/`_publish`, `Shares._numbered`/`_publish` and both `REQUEST_NAME`s are removed. | AC1 |
| R3 | Behaviour is unchanged: same folders, file names (`t<N>.md`, `r<N>.json`, `f<N>.json`), ids (`t<N>`, `r<N>`, `f<N>`), draft name (`.draft-<system.token()>`), contents, number order and errors. The first number tried is the largest existing number + 1 (1 in an empty folder); a taken number moves on to the next one; the draft is removed whether publishing succeeds or raises; an error other than `FileExistsError` propagates. Listing ignores every name that is not `<prefix><digits><suffix>` and is `[]` when the folder does not exist. | AC2 |
| R4 | Each module keeps what is its own: the file's text, and how a file is read back (`Relay`: a `Told`; `Requests`: `Request` or skipped when unreadable; `Shares`: `Share` or `BadRequest`). | AC1 |
| R5 | `Requests.queue` returns the queued `Request` with its id: `replace(request, id=entry.id)`, the same `at` the file holds. Before, it called `system.now()` a second time for the returned value; its only callers (`dashboard/server.py`, `opinions.py`) read `.id` only, so nothing observable changes. | AC2 |
| R6 | Existing tests keep their assertions. One existing test patches a removed private seam: `tests/test_s71_tell.py::test_a_lost_race_lands_in_the_next_number` patches `Relay._next_number`; it now patches `NumberedQueue._next_number` (import `from agile_team.numbered_queue import NumberedQueue`), assertions unchanged. ## New module: `agile-team/runner/agile_team/numbered_queue.py`

```python
"""A folder of numbered files, each published whole (s134, ADR-0069).

A writer drafts the file, then hard-links the draft to the first free
``<prefix><N><suffix>``. A link never overwrites, so two writers never get the
same number and a reader never sees half a file. Used by ``relay`` (tell),
``reorders`` and ``sharing``.
"""

from __future__ import annotations

import itertools
import re
from dataclasses import dataclass
from pathlib import Path

from . import system

DRAFT = ".draft-{token}"


@dataclass(frozen=True)
class Entry:
    """One numbered file: its id (``<prefix><N>``) and its path."""

    id: str
    path: Path


@dataclass(frozen=True)
class NumberedQueue:
    """Numbered files ``<prefix><N><suffix>`` in ``folder``."""

    folder: Path
    prefix: str
    suffix: str

    def publish(self, text: str) -> Entry:
        """Write ``text`` as the next numbered file: whole, never overwriting, no draft left."""
        system.make_dirs(self.folder)
        draft = self.folder / DRAFT.format(token=system.token())
        try:
            system.write_text(draft, text)
            return self._link(draft)
        finally:
            system.remove(draft)

    def entries(self) -> list[Entry]:
        """Every numbered file in number order; other names are ignored; none without a folder."""
        if not system.is_dir(self.folder):
            return []
        return [Entry(self._id(n), path) for n, path in sorted(self._numbered())]

    def _numbered(self) -> list[tuple[int, Path]]:
        pattern = re.compile(rf"^{re.escape(self.prefix)}(\d+){re.escape(self.suffix)}$")
        matched = ((pattern.match(p.name), p) for p in system.list_dir(self.folder))
        return [(int(m[1]), p) for m, p in matched if m]

    def _next_number(self) -> int:
        return max((n for n, _ in self._numbered()), default=0) + 1

    def _id(self, n: int) -> str:
        return f"{self.prefix}{n}"

    def _at(self, n: int) -> Entry:
        return Entry(self._id(n), self.folder / f"{self._id(n)}{self.suffix}")

    def _link(self, draft: Path) -> Entry:
        for n in itertools.count(self._next_number()):
            entry = self._at(n)
            try:
                system.hard_link(entry.path, draft)
            except FileExistsError:
                continue
            return entry
        raise AssertionError("unreachable")  # pragma: no cover
```

Notes:

- `entries()` keeps the path found on disk (as `Relay.told` did), so a file
  like `t01.md` lists with id `t1` and its own path, exactly as before.
- `_numbered()` is called on the folder `publish` just made, so it never
  needs the `is_dir` check.

```python
    @property
    def _messages(self) -> NumberedQueue:
        return NumberedQueue(self.messages_dir, TOLD_PREFIX, TOLD_SUFFIX)

    def tell(self, text: str) -> Told:
        """Queue ``text`` as the next ``t<N>.md``: written whole, never overwriting (T2)."""
        entry = self._messages.publish(text)
        return Told(entry.id, entry.path)

    def told(self) -> list[Told]:
        """Every queued message, in number order; other files are ignored (T2)."""
        return [Told(e.id, e.path) for e in self._messages.entries()]
```

```python
    def _queue(self) -> NumberedQueue:
        return NumberedQueue(self.folder, REQUEST_PREFIX, REQUEST_SUFFIX)

    def queue(self, ask: Ask) -> Request:
        """Queue ``ask`` as the next ``r<N>.json``, written whole, never overwriting."""
        request = Request("", ask, system.now())
        entry = self._queue.publish(request.to_json())
        return replace(request, id=entry.id)

    def all(self) -> list[Request]:
        """Every readable request, in number order."""
        read = (self._read(entry) for entry in self._queue.entries())
        return [r for r in read if r]

    @staticmethod
    def _read(entry: Entry) -> Request | None:
        try:
            return Request.from_json(entry.id, system.read_text(entry.path))
        except OSError:
            return None
```

```python
    def _queue(self) -> NumberedQueue:
        return NumberedQueue(self.folder, REQUEST_PREFIX, REQUEST_SUFFIX)

    def queue(self, share: Share) -> Share:
        """Queue ``share`` as the next ``f<N>.json``, written whole, never overwriting."""
        queued = replace(share, at=system.now())
        entry = self._queue.publish(queued.to_json())
        return replace(queued, id=entry.id)

    def all(self) -> list[Request]:
        """Every numbered request, in number order; unreadable ones are bad requests."""
        return [self._read(entry) for entry in self._queue.entries()]

    @staticmethod
    def _read(entry: Entry) -> Request:
        try:
            return Share.from_json(entry.id, system.read_text(entry.path))
        except OSError as error:
            problem = shares.UNREADABLE_REQUEST.format(error=error.strerror)
            return shares.bad_request(entry.id, problem)
```

## Test checklist

Unit-tester, new file `agile-team/runner/tests/test_s134_numbered_queue.py`
(fake system; `Q = NumberedQueue(RUN / "q", "t", ".md")` or similar):

1. `publish` writes the text whole at `<prefix>1<suffix>` and returns
   `Entry("t1", folder / "t1.md")`; a second publish returns `t2`.
2. The text is kept byte for byte (no strip): `"  \n x \n\n"`.
3. The first number follows the largest numbered file and ignores other
   names: with `t1.md`, `t5.md`, `.draft-9`, `t7.txt`, `tx.md`, `r9.md`
   present, `publish` returns `t6`.
4. A taken number is skipped: wrap `system.hard_link` so the link to `t2.md`
   raises `FileExistsError`; `publish` returns `t3`, the links tried are
   `["t2.md", "t3.md"]`, and an existing file at the taken number keeps its
   text (also via patching `NumberedQueue._next_number` to 1 with `t1.md`
   present: lands on `t2`, `t1.md` unchanged).
5. No draft is left after a successful publish: the folder holds only the
   numbered files.
6. No draft is left when writing the draft fails (`fake.fill_disk()`):
   `OSError` propagates and nothing is under the folder.
7. No draft is left when linking fails with another error (`hard_link`
   raises `PermissionError`): the error propagates, the folder is empty.
8. `entries()` lists in number order (`t1`, `t9`, `t10`), ignores other
   names, and keeps the path found on disk.
9. `entries()` is `[]` when the folder does not exist; `publish` creates it.
10. Prefix and suffix are literal, not regex: with suffix `.json`, a file
    `f1xjson` is not listed.

Existing tests (R6): only `test_s71_tell.py::test_a_lost_race_lands_in_the_next_number`
