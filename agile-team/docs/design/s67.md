# s67: a first `agile-team watch` takes the current outbox as seen

**Developer:** `developer-cli`. **One module changes:** `agile_team/watch.py`.
No new dependency, no ADR (a narrow change to s62's V3).

## Problem

`Seen.load` turns a missing `watch.json` into `Seen()` (0 messages, no
status). So the first watch in a repo reports the whole outbox (m1 onward)
and any non-quiet status as new. The liaison has already seen that history.

## Rules

| # | Rule | AC |
|---|---|---|
| F1 | **Missing is not unreadable.** `Seen.load(path)` returns `None` when the file does not exist (`FileNotFoundError`). Any other `OSError`, a `ValueError` (bad JSON) or a `TypeError` (wrong keys) still returns `Seen()`, as today. | 1, 3 |
| F2 | **A first watch records before it waits.** When `Seen.load` gives `None`, `Watcher.until` takes the first whole look (F3), turns it into memory with `Look.seen()` (outbox count, status, status_reason, health), **saves it to `watch.json` at once**, and uses it as `seen`. Then it polls exactly as today. | 1 |
| F3 | **Whole look only.** The first-run record is taken from a look that is not `None`. While the outbox has a torn line (`look` returns `None`), sleep `POLL_S` and look again (V2 unchanged). A torn outbox never ends a watch, timed or not, as today. | 1 |
| F4 | **The deadline starts when the watch starts.** `until` computes the deadline *before* the first-run record, so `--timeout S` still counts from the call. | 1 |
| F5 | **Nothing fires against the record itself.** With `seen == now.seen()`, `message`, `status` and `health` cannot fire for that look (the `TRIGGERS` table is unchanged). Only something that changes after the record fires: a new outbox entry, a new non-quiet status, health turning red. The line is today's line (V6); its `was` is the recorded status, not `null`. | 1, 2 |
| F6 | **Existing memory: unchanged.** A readable `watch.json` behaves exactly as today (V3–V7). An unreadable one (F1) is fresh memory `Seen()`, so that watch reports the whole outbox, as today. | 3 |
| F7 | **The heartbeat still tells the status.** A first watch on a halted run ends at `--timeout` with a `heartbeat` line whose `status`, `status_reason` and `health` show where the run stands. Nothing is hidden; it is just not reported as a change. | 1 |

## Changes: `agile_team/watch.py`

No import changes. `TRIGGERS`, `Look`, `look`, `fired`, `Basis`, `line`,
`_ended`, `_next` are unchanged.

### `Seen.load`

```python
@classmethod
def load(cls, path: Path) -> Seen | None:
    """Read the memory: ``None`` when there is none yet (a first watch, F1); fresh memory when unreadable."""
    try:
        return cls(**json.loads(system.read_text(path)))
    except FileNotFoundError:
        return None
    except (OSError, ValueError, TypeError):
        return cls()
```

`FileNotFoundError` is an `OSError`, so its `except` must come first. Both
`system.read_text` (real) and `FakeSystem.read_text` raise it for a missing
file.

### `Watcher.until`

```python
def until(self, timeout_s: float | None) -> dict[str, Any]:
    """Poll until a trigger fires or ``timeout_s`` passes; save memory; return the line."""
    deadline = self._deadline(timeout_s)
    seen = self._baseline()
    while True:
        ...  # the loop body is unchanged
```

The deadline line comes first (F4). Do not write
`seen, deadline = self._baseline(), self._deadline(...)`: a tuple evaluates
left to right, so the deadline would start after the record.

### New private methods on `Watcher`

```python
def _baseline(self) -> Seen:
    """The remembered look; a first watch (no memory file) records the current one first (F2)."""
    remembered = Seen.load(self.memory)
    return remembered if remembered is not None else self._record(self._whole_look())

def _record(self, now: Look) -> Seen:
    """Save ``now`` as watch memory and return it (F2)."""
    seen = now.seen()
    seen.save(self.memory)
    return seen

def _whole_look(self) -> Look:
    """The first look with no torn outbox line, sleeping ``POLL_S`` between tries (F3)."""
    while (now := look(self.run_dir)) is None:
        self._sleep(POLL_S)
    return now
```

Use `is not None`, not `or`: the rule is "missing file", not "falsy".

## Tests

### Unit (`tests/test_s62_watch.py`, a `LEGACY` file; use its helpers `put`, `note`, `remember`, `memory`, `until`, `FakePace`)

These existing tests state the old V3 ("the first watch reports everything")
that this story replaces. Rewrite them to the new rule; this is the
requirement changing, not a test being weakened:

- `test_the_first_watch_reports_every_message` → **a first watch with a
  populated outbox does not report it**: running, one note, no memory,
  `until(run_dir, FakePace(), timeout=4)` gives `triggers == ["heartbeat"]`,
  `messages == []`, `was == {"status": "running", "status_reason": None}`;
  `memory(run_dir) == {"messages": 1, "status": "running", "status_reason": None, "health": "idle"}`.
- `test_the_first_watch_reports_a_non_quiet_status` → **a first watch takes a
  non-quiet status as seen**: `stopped` / `"stop requested"`, no memory,
  `timeout=4` gives `heartbeat`, and the line's `status`/`status_reason` are
  `stopped` / `stop requested` (F7).
- `test_two_messages_between_watches_are_both_reported`: start it with
  `remember(run_dir, 0, "running")` so its first watch still reports m1 (it
  tests two watches in a row, not the first run).
- `test_seen_defaults_and_atomic_save`: `Seen.load` of a missing path is
  `None` (F1); the save/load round trip and the single file stay.

New tests:

- [ ] **F2 record is written before the wait:** no memory, one note; a
      `FakePace` act that reads `memory(run_dir)` at the first sleep finds
      `messages == 1` (the file exists while the watch waits).
- [ ] **F2/AC2 a message after the record is new:** no memory, one note (m1);
      `FakePace(acts=[lambda: note(run_dir, text="two")])` → `triggers ==
      ["message"]`, message ids `["m2"]` only, `memory(run_dir)["messages"] == 2`.
- [ ] **F5 a status change after the record fires:** no memory, running; an
      act puts `stopped` → `triggers == ["status"]`, `was ==
      {"status": "running", "status_reason": None}`.
- [ ] **F5 health:** `test_s44_wiring.py` style: a first watch on a run that
      is already red does not fire `health`.
      (If arranging red is costly in the LEGACY file, assert it on `fired`
      directly: `fired(look.seen(), look) == []` for a red `Look` with
      messages and a non-quiet status. That one needs no OS.)
- [ ] **F3 torn first look:** no memory, outbox holds a torn line; the act
      completes it (m1) → the watch records `messages == 1` after one sleep,
      does **not** report m1, and ends `heartbeat` at `timeout`. Keep
      `test_a_torn_line_never_ends_a_timed_watch` as it is (no memory, torn
      forever, still never ends).
- [ ] **F4 deadline from the call:** no memory, first look torn for one poll
      then whole, `timeout=2` → heartbeat after the second look, total sleeps
      `== [2.0]` (the record's sleep counts toward the timeout).
- [ ] **F6 garbage memory:** `test_garbage_memory_acts_as_fresh` stays as it
      is (unreadable still reports the outbox).
- [ ] **F1 other read errors are fresh memory:** `watch.json` is a directory
      (`IsADirectoryError`) → `Seen.load` returns `Seen()`.
