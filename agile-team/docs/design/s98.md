# s98 (A6a): every agent's tool calls are recorded, the PO's included

Story: `.team/stories/s98.md`. Plan context: `.team/run/liaison/plans/tool-flow.md`.
Builds on s97 (awake time: `Mark`, `Platform`, `platform_of` in
`dashboard/step_times.py`, `Pulse.slept_s`, `FakeSystem.doze`). No new
dependency, no ADR (the s44 meter and the s96/s97 snapshot pattern, extended).

## What changes, in one paragraph

Each open meter's `Reading` gains a `Calls` ledger (new pure module
`tool_calls.py`). A `ToolUseBlock` opens a call at the pulse's current `Mark`
(wall, monotonic, slept); its `ToolResultBlock` closes it as one span, which the
`Pulse` appends to `.team/run/tools.jsonl`. When a meter closes, calls still
open are closed as `unfinished`. The meter's time split (`tool_s`, `model_s`,
`waiting_s`, plus `opened_at`) goes on its `step-end` event, and on a new
`po-turn` event that the PO driver emits after every PO query. The snapshot
gains a `tools` section: the spans grouped by meter, the shortest gathered into
one `misc` entry under `[dashboard] collapse_under_s`.

## Rules

| # | Rule |
|---|---|
| TC1 | **One span per call.** A call opens on its `ToolUseBlock` (`id`, `name`, `input`), keyed by `id`; a repeated id (a re-streamed message) does not reopen it. It closes on the `ToolResultBlock` whose `tool_use_id` matches; a result with no open call is ignored. Parallel calls (several uses in one message) are separate spans. |
| TC2 | **Status.** `ok` when the result's `is_error` is falsy. When it is true: `timeout` if the result text matches `TIMED_OUT` (`(?i)\btimed out\b`, searched in the first 300 characters), else `error`. The result text is `content` when a string, else the `text` of each `{"type": "text"}` item joined by `"\n"`; `None` is `""`. |
| TC3 | **Unfinished.** `Pulse.close(meter)` takes one `Mark` and closes every call still open on that meter at it, status `unfinished`, before the meter leaves the stack. Unfinished spans are written and count in `tool_s`. (A killed runner writes nothing for its open calls: known limit.) |
| TC4 | **Awake axis.** A `Mark`'s position on the awake axis is `POSITIONS[platform](mark)`: POSIX → `mono` (or `at` when `mono` is None); Windows → `at - slept` (`slept` None counts as 0). A span's `seconds` = `max(0, pos(end) - pos(start))`, rounded to 3 decimals. The platform is `step_times.platform_of(system.platform())`, read once in `Pulse.__post_init__`. |
| TC5 | **Who.** A span carries `role`, `story` and `step` from the meter's `Who`; when `who.step` is None the step is `STEP_OF_ROLE.get(role)`, where `STEP_OF_ROLE = {PO_ROLE: "po-session"}`. It also carries `opened_at`: the reading's `started_at`, the same value the meter's `step-end` / `po-turn` event carries. `(role, story, step, opened_at)` identifies the step or PO turn a span belongs to. |
| TC6 | **Named label.** A tool name `mcp__<server>__<tool>` whose `<server>` is a key of `NAMED_SERVERS = {"team": "po", "runner": "runner-tool"}` is labelled `<prefix>.<tool>` (`po.run_role`, `po.open_story`, `runner-tool.run_tests`). A6b adds its built-in stages and repo `[[tool]]` names to this same lookup; s98 adds no other rows. |
| TC7 | **Dev label.** Any other call is labelled `Dev: <reason>`. The reason is `input[REASON_KEYS[tool]]` when that is a non-blank string (`REASON_KEYS = {"Bash": "description"}`), passed through `shown` (TC9); otherwise it is the tool name (`Dev: Read`, `Dev: mcp__other__thing`). The target is not repeated in the label: it is the detail. |
| TC8 | **Detail.** The first value in `input` under `DETAIL_KEYS = ("command", "file_path", "notebook_path", "pattern", "url", "query", "path", "role", "story")` that is a non-blank string, passed through `shown`; `""` when none. (`po.run_role` → the role name.) |
| TC9 | **`shown(text)`** = `masked(text)`, then runs of whitespace collapsed to one space and stripped, then the first `LIMIT = 80` characters. Masking happens before the cut, so a secret is never half shown. |
| TC10 | **Masking.** `masked` replaces the value of every assignment whose variable name contains `TOKEN`, `KEY` or `SECRET` (case-insensitive) with `***`: `SECRET_ASSIGNMENT = re.compile(r"(?i)\b([A-Z0-9_]*(?:TOKEN\|KEY\|SECRET)[A-Z0-9_]*)=(\"[^\"]*\"\|'[^']*'\|[^\s;&\|]+)")` → `\1=***`. So `GH_TOKEN=abc gh pr list` → `GH_TOKEN=*** gh pr list`, `export API_KEY="a b"` → `export API_KEY=***`. A flag value (`--token abc`) is not an environment variable and is not masked (known limit). |
| TC11 | **Span line.** One JSON object per line in `.team/run/tools.jsonl` (`TOOLS = "tools.jsonl"`), keys in this order: `role`, `story`, `step`, `opened_at`, `tool` (the SDK name), `tool_use_id`, `label`, `detail`, `at` (start wall), `mono` (start monotonic), `slept` (start sleep counter), `seconds` (awake, TC4), `ended_at` (end wall), `status`. Written under the pulse lock, appended, `OSError` suppressed (like `turns.jsonl`). |
| TC12 | **Time split.** For a closed reading, with `start` its opening `Mark` and `end` its closing `Mark`: `awake = max(0, pos(end) - pos(start))`; `busy = union(all spans)`; `waiting_s = union(spans whose label is in WAITING)` with `WAITING = frozenset({"po.run_role"})`; `tool_s = busy - waiting_s`; `model_s = max(0, awake - busy)`. All rounded to 3 decimals. `union` measures the union of the spans' `[pos(start), pos(end)]` intervals, so parallel calls count once. So `tool_s + model_s + waiting_s = awake` (up to rounding and the clamp). For a role step `waiting_s` is `0.0`; it is written on every split, not only the PO's (one shape, no branch). |
| TC13 | **Split on events.** `step-end` data (normal and interrupted) gains `opened_at`, `tool_s`, `model_s`, `waiting_s`. A step-end written by `recovery` after a kill gains nothing (no meter). |
| TC14 | **`po-turn` event.** New `EventKind.PO_TURN = "po-turn"`, role `product-owner`, story `None`, emitted once per PO query, after its meter closes (also when the query raised): data `{opened_at, tool_s, model_s, waiting_s, mono, slept}` (`mono`, `slept` = `pulse.clocks()` at the end). The s23 `po-session` event keeps its meaning (a session renewal: `path`, `reasons`, `pre_tokens`) and its tests; see "AC4 and `po-session`" below. The page's `TIMELINE` has no `po-turn` entry, so the Activity timeline does not change. |
| TC15 | **Snapshot `tools`.** A new section after `steps`: the last `TOOLS_TAIL_BYTES = 4_194_304` bytes of `tools.jsonl` (`read_tail`), valid rows only (TC16), grouped by `(role, story, step, opened_at)` in first-seen order. Each group: `{"role", "story", "step", "opened_at", "calls": [...], "misc": {...}}`. `tools.jsonl` joins `RUN_FILES` (watched). |
| TC16 | **Valid row.** A dict whose `seconds` and `at` are numbers (`step_times.number`, so not bools) with `seconds >= 0`, and whose `role` is a string. Others are skipped. |
| TC17 | **Gathering (AC6).** Per group, sort the rows by `(seconds, at)`. Take the longest prefix whose running total of `seconds` stays `< collapse_under_s`: those rows are gathered. Every other row is shipped in `calls`, sorted by `at`, each row as read from the file. `misc = {"count": n, "seconds": round(sum, 3), "tools": {tool: count}}` (`tools` keys in first-gathered order); with nothing gathered, `{"count": 0, "seconds": 0.0, "tools": {}}`. `collapse_under_s = 0` gathers nothing. Misc has no start time. |
| TC18 | **`[dashboard] collapse_under_s`.** A number of seconds, default `0.1`; a bool, a non-number or a negative value is refused on load with `DASHBOARD_COLLAPSE = "[dashboard] collapse_under_s must be a number of seconds, 0 or more"`. |

## AC4 and `po-session` (a reading of the AC, for the PO to confirm)

The AC says "each `step-end` and `po-session` event gains `tool_s` and
`model_s`". Today `po-session` is not a PO turn: it is the s23 renewal event,
emitted only when the PO's session is compacted or handed off, and the page
draws it as "session compact". A PO turn has no event at all. Adding the split
to `po-session` would either leave most PO turns unmeasured, or emit
`po-session` per turn and break s23's meaning, its tests and the timeline. So
the PO's split goes on a new `po-turn` event (TC14), one per PO query. The
verification line "`po-session` has `waiting_s`" reads as "`po-turn` has
`waiting_s`".

## Changes by module

### `agile_team/tool_calls.py` (new, pure, no I/O)

```python
"""Tool calls of one open query as spans (s98): labels, details, masking, the time split."""
from claude_agent_sdk import ToolResultBlock, ToolUseBlock
from .dashboard.step_times import Mark, Platform
from .ledger import PO_ROLE

TOOLS = "tools.jsonl"
LIMIT = 80
DEV = "Dev: "
NAMED_SERVERS: dict[str, str] = {"team": "po", "runner": "runner-tool"}
REASON_KEYS: dict[str, str] = {"Bash": "description"}
DETAIL_KEYS: tuple[str, ...] = (...)            # TC8
WAITING: frozenset[str] = frozenset({"po.run_role"})
STEP_OF_ROLE: dict[str, str] = {PO_ROLE: "po-session"}
SECRET_ASSIGNMENT: re.Pattern[str]              # TC10
TIMED_OUT: re.Pattern[str] = re.compile(r"(?i)\btimed out\b")
TIMEOUT_SCAN = 300
POSITIONS: dict[Platform, Callable[[Mark], float]]  # TC4

class Status(StrEnum): OK = "ok"; ERROR = "error"; TIMEOUT = "timeout"; UNFINISHED = "unfinished"

def masked(text: str) -> str                    # TC10
def shown(text: str) -> str                     # TC9
def named(tool: str) -> str | None              # TC6: "po.run_role", or None
def label(use: ToolUseBlock) -> str             # TC6, TC7
def detail(tool_input: dict[str, Any]) -> str   # TC8
def result_text(block: ToolResultBlock) -> str  # TC2
def status_of(block: ToolResultBlock) -> Status # TC2
def union(intervals: list[tuple[float, float]]) -> float  # TC12: sort, merge, sum

@dataclass(frozen=True)
class Where:
    """Which step or PO turn a span belongs to (TC5)."""
    role: str; story: str | None; step: str | None; opened_at: float

@dataclass(frozen=True)
class Call:
    """One open call: id, SDK tool name, label, detail and its start."""
    tool_use_id: str; tool: str; label: str; detail: str; start: Mark
    @classmethod
    def of(cls, use: ToolUseBlock, start: Mark) -> Call

@dataclass(frozen=True)
class ToolSpan:
    """One finished call (TC11)."""
    where: Where; call: Call; end: Mark; seconds: float; status: Status
    def as_dict(self) -> dict[str, Any]   # TC11 keys, in order
    def line(self) -> str                 # json.dumps(as_dict())

@dataclass(frozen=True)
class Split:
    """A meter's time split (TC12)."""
    tool_s: float; model_s: float; waiting_s: float
    def as_dict(self) -> dict[str, float]

@dataclass(eq=False)
class Calls:
    """The calls of one reading: open ones by id, every closed span, the spans not yet written."""
    where: Where
    platform: Platform = Platform.POSIX
    open: dict[str, Call] = field(default_factory=dict)
    spans: list[ToolSpan] = field(default_factory=list)
    fresh: list[ToolSpan] = field(default_factory=list)

    def start(self, uses: list[ToolUseBlock], mark: Mark) -> None      # TC1 (setdefault)
    def finish(self, results: list[ToolResultBlock], mark: Mark) -> None  # TC1, TC2
    def abandon(self, mark: Mark) -> None                               # TC3; idempotent
    def take_fresh(self) -> list[ToolSpan]                              # returns and clears `fresh`
    def split(self, start: Mark, end: Mark) -> Split                    # TC12
```

Private helpers as needed (`_position`, `_close(call, mark, status)`,
`_interval(span)`); keep each function under 8 lines. `ToolSpan.seconds` is
computed in `Calls._close` from `POSITIONS[self.platform]` (TC4).

## Known limits

- A killed runner loses its open calls (no `unfinished` lines); the step's recovery `step-end` has no split.
- The snapshot reads the last 4 MiB of `tools.jsonl`, so the oldest group in the window may be partial. A6c, which needs a done story's whole history, may index the file instead.
- Only `NAME=value` assignments are masked; a secret passed as a flag value or inline in a URL is shown (cut to 80 characters).
- Detail and label come from the tool's input as the model sent it; a subagent's (`Task`) inner calls are not seen by the meter.
