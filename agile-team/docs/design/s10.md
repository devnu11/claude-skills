# s10 design: a start ledgers the spend a crash cut off, from turns.jsonl

Story: `.team/stories/s10.md`. ADR: [ADR-0078](../../../.team/adr/0078-start-ledgers-cut-off-spend-from-turns.md)
(amends [ADR-004](../adr/ADR-004-po-cost-deltas.md) rule 4).
Requirements: REQ-099 (AC1, AC2), REQ-100 (AC1).
Developer: `developer-cli` (runner only: `ledger.py`, `live.py`, new
`reconcile.py`, `cli.py`; no snapshot, fixture or page change).

## Where things stand

- The live meter writes one `turns.jsonl` line per model turn while a query
  runs (`live.Pulse._log`, written as the turn arrives). Each line has `at`,
  `role`, `story`, `model`, `tokens` (that turn's new tokens) and `cost_usd`
  (that turn's estimate: 0 on a free provider, `null` for an unknown model).
- The ledger gets a row only after a query returns: `PoRun._record` for a PO
  query, `Runtime.record_cost` for a role step. Both write the row after the
  last turn line of their query, so a row's `at` is later than every turn
  line it covers.
- A PO query can run for hours (it runs role steps inside its tool calls). A
  crash before `_record` drops its whole cost. `test_po_cost.py::
  test_crash_before_the_record_leaves_the_ledger_and_baseline_unsaved` pins
  that today nothing is ledgered.
- AC1's test fails today: nothing reads `turns.jsonl` at start. So AC2
  applies and this design adds the reconcile.

## Rules

| # | Rule | AC |
|---|---|---|
| RC1 | **When.** Every `start` (any mode) reconciles once, in `cli._prepared`, after `_require_preflight` and before `make_runtime` (which loads `state.json`). It does nothing while a runner is alive (`state_mod.runner_alive(run_dir)`): that runner's open query is not cut off. | AC1, AC2 |
| RC2 | **Key.** Turn lines and ledger rows are matched by `(role, story)`; `story` is `None` for the PO and for story-less steps. One key never runs two queries at once. | AC1 |
| RC3 | **Uncovered turns.** A key's uncovered turns are its turn lines with `at` strictly greater than the latest `at` of a ledger row with the same key; all its lines when it has no row. | AC1 |
| RC4 | **One row per key.** Each key with uncovered turns gets one ledger row: `role` and `story` from the key, `model` the last uncovered turn's `model`, `cost_usd` the sum of their `cost_usd` (`null` counts 0), `tokens` the sum of their `tokens`, `turns` the number of distinct `message_id`s (each line with a `null` id counts 1), `at` left 0 so `Ledger.record` stamps the time of the start. Rows are written in the order of each key's first uncovered line in `turns.jsonl`. | AC1 |
| RC5 | **No double count in the ledger.** A reconciled row's `at` is later than every turn it covers, so RC3 finds nothing for that key at the next start. A key whose last query was ledgered normally has nothing uncovered. | AC1 |
| RC6 | **Bad lines are skipped.** A blank line, a torn last line (a crash mid-write) or a line that does not parse as a turn is skipped; a missing `turns.jsonl` reconciles nothing. Reconcile never stops a start. | AC1 |
| RC7 | **No double count through the PO's session.** Claude Code's `total_cost_usd` is the session's running total (ADR-004), so the next query that resumes the cut-off PO session may report the cut-off cost again. When RC4 writes a PO row and `state.po_cost` is not `None`, the reconcile adds that row's cost to `state.po_cost.reconciled` and saves `state.json`. `SessionCost.own_cost` for a query resuming the same session subtracts `min(reconciled, delta)` from its delta. Any new `SessionCost` (each recorded PO query) starts with `reconciled = 0`. With `po_cost` `None`, state is left alone (the next query seeds its baseline from the last PO ledger row, which is now the reconciled row: C6 still holds). | AC1 |
| RC8 | **Told on stderr.** Each reconciled row prints one line to stderr: `agile-team start: ledgered $<cost, 2 dp> for <label>, cut off by the last run (estimated from turns.jsonl)`; `<label>` is `salvage.label(role, story)`. | AC2 |
| RC9 | **Scope.** No budget checkpoint fires from a reconciled row (the next PO query's `enforce_ceiling` still applies the ceiling to the new total). Older gaps are not hunted for: only a key's turns after its latest row count. | AC2 |

Under RC7, if Claude Code did not carry the cut-off cost into the resumed
session's total, the next resumed PO query is under-counted by at most the
reconciled amount. Never twice; see ADR-0078.

## Changes per module

### `agile-team/runner/agile_team/ledger.py`

```python
@dataclass
class SessionCost:
    session: str | None = None
    reported: float = 0.0
    reconciled: float = 0.0  # new: estimate already ledgered from turns.jsonl for this session (RC7)

    def own_cost(self, resumed: str | None, reported: float) -> float:
        """... A same-session delta is reduced by what a start already ledgered for it (RC7)."""
        if resumed is None or resumed != self.session or reported < self.reported:
            return reported
        delta = reported - self.reported
        return delta - min(self.reconciled, delta)
```

Behaviour is unchanged when `reconciled == 0` (every existing
`test_own_cost` row still holds). `state.json` loads older `po_cost`
objects without `reconciled` (dataclass default; `state._nested` is
unchanged). Update the module docstring with one line on s10.

### `agile-team/runner/agile_team/live.py`

```python
@dataclass(frozen=True)
class Turn:
    @classmethod
    def from_line(cls, text: str) -> Turn:
        """Parse one turns.jsonl line; raises ValueError, TypeError or KeyError on a bad one."""
```

`data = json.loads(text)`; `cls(**{**data, "tokens": Tokens(**data["tokens"])})`.
A JSON value that is not an object raises `TypeError` from `**`.

### `agile-team/runner/agile_team/reconcile.py` (new)

Module docstring: ledgers, at start, the spend of queries a crash cut off,
estimated from `turns.jsonl` (s10, ADR-0078).

```python
from . import salvage, state as state_mod, system
from .ledger import LEDGER, PO_ROLE, Entry, Ledger, Tokens
from .live import TURNS, Turn

Key = tuple[str, str | None]  # (role, story), RC2
TOLD = (
    "agile-team start: ledgered ${cost:.2f} for {label}, "
    "cut off by the last run (estimated from turns.jsonl)"
)

def reconcile_ledger(run_dir: Path) -> list[Entry]:
    """Ledger each key's uncovered turns (RC1-RC7); the entries written, [] while a runner is alive."""

def read_turns(path: Path) -> list[Turn]:
    """The parseable turn lines of ``path`` in file order; [] when it is missing (RC6)."""

def find_uncovered(turns: list[Turn], entries: list[Entry]) -> dict[Key, list[Turn]]:
    """Per key, its turns after its latest ledger row (RC3), keys in order of first uncovered turn."""

def sum_turns(turns: list[Turn]) -> Entry:
    """One ledger entry for one key's uncovered turns (RC4); ``at`` left 0."""

def told_line(entry: Entry) -> str:
    """The stderr line for a reconciled entry (RC8)."""
```

- `reconcile_ledger`: return `[]` if `state_mod.runner_alive(run_dir)`;
  `ledger = Ledger(run_dir / LEDGER)`; `found = find_uncovered(read_turns(run_dir / TURNS), ledger.entries())`;
  `entries = [sum_turns(t) for t in found.values()]`; record each; then
  `_net_po_spend(run_dir, entries)` (private): sum of PO entries' cost; when
  it is > 0 and the loaded `state.po_cost` is not `None`, add it to
  `po_cost.reconciled` and `state_mod.save`. Keep each function under 8
  lines; split helpers as needed (`_latest(entries) -> dict[Key, float]`,
  `_parsed(line) -> Turn | None`).
- `read_turns`: `system.is_file` / `system.read_text` (the OS seam, ADR-0036);
  skip blank lines and lines where `Turn.from_line` raises
  `(ValueError, TypeError, KeyError)`.
- `find_uncovered`: a turn of key `k` is uncovered when `turn.at > latest[k]`
  (or `k` not in `latest`). Use a plain dict so key order is first-turn
  order.
- `sum_turns`: `Entry(role, model, cost, story, tokens=..., turns=...)`, per
  RC4. Tokens with `sum((t.tokens for t in turns), Tokens())`.

### `agile-team/runner/agile_team/cli.py`

In `_prepared`, after `_require_preflight(config, place.home)`:
`_reconcile(config)`, a new private function that calls
`reconcile.reconcile_ledger(config.run_dir)` and prints
`reconcile.told_line(e)` to `sys.stderr` for each entry (as `_recover` does).

### Not changed

`PoRun`, `dispatch`, the snapshot, the dashboard and its fixture,
`EventKind`. The reconciled row is an ordinary `Entry`, so `budget_status`,
the Cost tab and the Flow chart count it like any row.

## Test checklist

New `agile-team/runner/tests/test_reconcile.py`. Use `make_runtime` /
`po_run` from `test_po_cost.py`'s pattern and the `scratch` fixture. Turns
priced by a real family name (e.g. model `claude-opus-4-1`) so the estimate
is not 0. Times through the clock helpers (REQ-024); costs compared with
`pytest.approx`.

- [ ] AC1 (the story's test): drive `PoRun._turn` with a fake query that
      yields two `AssistantMessage`s (distinct `message_id`s, `usage` with
      tokens, model `claude-opus-4-1`) and then raises (e.g.
      `RuntimeError("crash")`), so no `ResultMessage` and no PO row.
      Assert: `turns.jsonl` has 2 PO lines, the ledger has no PO row. Then
      run the start's reconcile (`reconcile.reconcile_ledger(run_dir)`):
      the ledger has exactly one PO row, `story None`, cost = the sum of the
      two lines' `cost_usd`, tokens = their sum, `turns == 2`.
- [ ] AC1 no double count, again: a second `reconcile_ledger` writes nothing
      and the ledger total is unchanged.
- [ ] AC1 no double count, covered turns: a key whose turns all precede its
      latest ledger row gets no row (e.g. a completed role step's lines and
      its row, alongside the crashed PO lines).
- [ ] AC1/AC2 on the next start: `cli._prepared` (or `cmd_start` with a
      query that ends at once) after the crash ledgers the PO row and prints
      the RC8 line to stderr (`capsys`).
- [ ] RC3: PO lines before and after a PO ledger row: only the later lines
      are summed.
- [ ] RC4: a turn with `cost_usd: null` counts 0; two lines with the same
      `message_id` count 1 turn; a `null` id counts 1 each; `model` is the
      last line's.
- [ ] RC2: a role step's uncovered lines (`developer-cli`, `s7`) get their
      own row with `story "s7"`, separate from the PO's.
- [ ] RC6: a torn last line, a blank line and a non-object JSON line are
      skipped; a missing `turns.jsonl` returns `[]` and writes no ledger.
- [ ] RC1: with `runner_alive` true (a live pid file), nothing is written.
- [ ] RC7: with `state.po_cost == SessionCost("sess", 1.0)` on disk, a
      reconciled PO row of cost C leaves `po_cost.reconciled == C`; then a
      PO query resuming `"sess"` reporting `1.0 + C + x` ledgers `x`
      (approx), and the saved `po_cost` has `reconciled == 0`.
- [ ] RC7: with `po_cost None`, state.json is not rewritten (`po_cost`
      stays `None`).
- [ ] `test_po_cost.py::test_own_cost`: add rows
      `(SessionCost("s", 1.0, 0.3), "s", 1.5, 0.2)`,
      `(SessionCost("s", 1.0, 0.8), "s", 1.5, 0.0)` (capped at the delta),
      `(SessionCost("s", 1.0, 0.3), "u", 0.9, 0.9)` (other session ignores it),
      `(SessionCost("s", 5.0, 0.3), "s", 0.2, 0.2)` (restart ignores it).
      `test_session_cost_defaults` also checks `reconciled == 0.0`.
- [ ] `live.Turn.from_line(turn.line())` round-trips a `Turn`.

Existing tests must pass unchanged, including
`test_crash_before_the_record_leaves_the_ledger_and_baseline_unsaved` (it
checks the state of the crashed run, before any reconcile).
