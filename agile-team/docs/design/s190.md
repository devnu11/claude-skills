# s190 design: a story whose branch name is taken is adopted or held, never crashed

ADR: [0094](../../../.team/adr/0094-a-taken-story-branch-name-is-adopted-or-held.md).
Requirements: REQ-247 (AC1), REQ-248 (AC1, AC2), REQ-249 (AC3). Developer: `developer-cli`.

## Cause

`Workspaces.ensure` forks whenever `story.branch` is empty, and `_fork` runs
`git branch <name> <sprint_head>` without looking (`workspaces.py:66-79`). `revert_story`
on an unlanded story clears `branch`, `base_sha`, `pushed` and `worktree_head` but leaves
the local branch (`reverts.py:284-300`, `Workspaces.remove`). When the story is planned
again, the fork's name (`format_story_branch(prefix, id, replays)`, same `replays`) is taken,
and `git branch` raises `GitError`. The story holds as an error, and `continue_story` only
leads to the same crash.

## Rules

| # | Rule | AC |
|---|------|----|
| T1 | **Look before forking.** For a story with no `branch` record, the runner reads the local branch with the fork's name: `git rev-parse --verify --quiet refs/heads/<name>`. If the exit code is not 0, the name is free and the fork goes on as today (`story-branch` `created`). A story that has a `branch` record is never checked (rebuild and replay are unchanged). | AC1 |
| T2 | **Adopt at the sprint head.** If the branch's tip is the sprint head (full sha, string equality), the runner takes it as the story's branch: `story.branch = <name>`, `story.base_sha = <sprint head>`. It runs no `git branch`, adds the worktree on it as for any branch, and logs `story-branch` with `action: "adopted"`, `why: ADOPTED_WHY`, plus `branch`, `base_sha` and `replays` as usual. | AC1 |
| T3 | **Hold anywhere else.** If the tip is anything else, `prepare_story` changes nothing: no branch, no worktree, no `story.*` field. It logs `story-branch` with `action: "taken"`, `branch`, `tip`, `base_sha` (the sprint head) and `aside` (T5), and returns `refused(reason)` with the step's `role`. The scheduler's usual refused path holds the story (`hold: "refused"`), and the PO's hand-over gets the `refused` line, `"{story}: {role} was refused: {reason}"`. | AC1, AC2 |
| T4 | **The reason.** `BRANCH_TAKEN`, filled in by `TakenBranch.reason`, names the story, the branch, its tip and the expected base (both cut to 12 characters), and the way out with the exact command. | AC2 |
| T5 | **The way out keeps the commits.** The way out is a hand rename in the main checkout, `git branch -m <name> <name>-kept-<tip[:12]>` (`TakenBranch.aside_branch`), by the human or the liaison (the PO has no shell). Afterwards the old tip is on the aside branch, which the event and the reason both name. The checkout guard records only the checked-out branch and `HEAD`, so the rename doesn't halt the run. | AC2, AC3 |
| T6 | **continue_story then starts normally.** `continue_story` clears the hold as it does today. The next step's `prepare_story` runs T1 again: the name is free, so it forks (`created`). If the way out wasn't taken, T3 refuses again, with the same reason and a new `taken` event. | AC2 |
| T7 | **The runner never moves, renames or deletes the leftover.** T1 to T3 only read it. In T2 the adopted branch is the leftover itself, so its tip stays reachable. | AC3 |

Out of scope: replay branches (`-r<k>` with `k = replays + 1`; `replays` never goes down,
so a new replay name is never a leftover); a remote branch with the same name (the story
push's lease refuses it with a text, as before); deleting the branch at revert (m365 item
10).

## Changes per module

### `agile-team/runner/agile_team/story_branches.py` (pure, no new imports beyond stdlib)

```python
from enum import StrEnum

ASIDE_SUFFIX = "-kept-{tip}"
SHORT = 12
BRANCH_TAKEN = (
    "story {story}'s branch {branch} already exists at {tip}, but its fork starts at the "
    "sprint head {base}; the runner changed nothing. Way out: the human or the liaison sets "
    "the old branch aside in the main checkout, which keeps its commits: "
    "git branch -m {branch} {aside}. Then continue_story({story}); its next step forks "
    "{branch} from the sprint head."
)


class BranchAction(StrEnum):
    """s190: how a story's first step came by its branch (the story-branch event's action)."""

    CREATED = "created"
    REBUILT = "rebuilt"
    ADOPTED = "adopted"
    TAKEN = "taken"


@dataclass(frozen=True)
class TakenBranch:
    """s190: a local branch that already has the name a story's fork wants."""

    story_id: str
    branch: str
    tip: str
    base: str  # the sprint head the fork would start from

    @property
    def is_at_base(self) -> bool:
        """T2: the branch sits where a fork would put it."""

    @property
    def aside_branch(self) -> str:
        """T5: ``<branch>-kept-<tip[:12]>``, the name the way out renames it to."""

    @property
    def reason(self) -> str:
        """T4: ``BRANCH_TAKEN`` filled in (tip and base cut to ``SHORT``)."""

    @property
    def event_data(self) -> dict[str, str]:
        """T3: the ``taken`` story-branch event's data: action, branch, tip, base_sha, aside."""
```

`event_data` keys: `action` (`BranchAction.TAKEN`), `branch`, `tip` (full), `base_sha`
(full `base`), `aside` (`aside_branch`).

### `agile-team/runner/agile_team/workspaces.py`

- Import: `from .story_branches import BranchAction, TakenBranch, format_story_branch`.
- Constant: `ADOPTED_WHY = "the branch already existed at the sprint head, where a fork would put it"`.
- New methods on `Workspaces`:

```python
def find_taken_branch(self, story: StoryState, sprint_head: str) -> TakenBranch | None:
    """T1: the local branch that has the name the story's fork wants; None if the name is
    free or the story already has a branch."""

def describe_branch_start(self, story: StoryState, sprint_head: str) -> dict[str, str]:
    """T2: the story-branch event's ``action`` for ``ensure`` (REBUILT with a branch record,
    else ADOPTED with ``why`` when the name is taken, else CREATED); call it before ensure."""

def _get_fork_branch(self, story: StoryState) -> str:
    """The name a fork gives the story: ``format_story_branch(prefix, id, replays)``."""

def _read_tip(self, branch: str) -> str:
    """The local branch's tip sha, or "" when there is no such branch (rev-parse, T1)."""
```

  `describe_branch_start` is only called after `_check_taken` (below) let the step through,
  so a taken name there is always at the base.

- `_fork` adopts a name at the sprint head instead of forking it (T2):

```python
def _fork(self, story: StoryState, sprint_head: str) -> None:
    branch = self._get_fork_branch(story)
    if self._read_tip(branch) != sprint_head:
        self.git.run("branch", branch, sprint_head)
    story.branch, story.base_sha = branch, sprint_head
```

  `ensure` keeps its signature and its `Path` return (`replay.py:205` is unchanged). A
  taken name not at the sprint head still makes `git branch` raise there; `dispatch`
  never reaches it (T3).

### `agile-team/runner/agile_team/dispatch.py` (`Runtime`)

- `run_in_worktree`: a refusal from `prepare_story` is returned as
  `{**refused_report, "role": request.role}`. The drift refusal gets the role too.
- `prepare_story` becomes four lines:

```python
def prepare_story(self, story: StoryState) -> dict[str, Any] | None:
    """B1, B5, s190: give the story its branch and worktree; a refusal report if its worktree
    drifted or its branch name is taken."""
    space = Workspaces(self.git, self.config)
    refusal = self._check_drift(story, space) or self._check_taken(story, space)
    if refusal is None:
        self._make_workspace(story, space)
    return refusal
```

- `_check_drift(self, story: StoryState, space: Workspaces) -> dict[str, Any] | None`: the
  current drift lines moved out of `prepare_story` unchanged (B5).
- `_check_taken(self, story: StoryState, space: Workspaces) -> dict[str, Any] | None` (T3):

```python
    taken = space.find_taken_branch(story, self.sprint_head)
    if taken is None or taken.is_at_base:
        return None
    self.events.emit(Event(EventKind.STORY_BRANCH, None, story.id, taken.event_data))
    return refused(taken.reason)
```

- `_make_workspace` takes its event data from `space.describe_branch_start(story, head)`,
  read before `space.ensure(story, head)`, and adds `branch`, `base_sha` and `replays`
  after ensure. The replay branch at the top is unchanged.

No state field and no hand-over row is added. The hold uses the existing `refused` trigger.
