# s137 design: a role's numbers on the Flow chart include its running step

Story: `.team/stories/s137.md`. ADR: [ADR-0068](../../../.team/adr/0068-flow-box-counts-the-running-step-until-the-ledger-has-it.md).
Requirements: REQ-030 (AC1, AC3), REQ-031 (AC2, AC3).
Developer: `developer-gui` (only `dashboard/index.html` changes; no runner,
snapshot or fixture change).

## Where things stand

`flowModel(view)` builds `ctx.totals` from `scopeTotals(view)`, and
`roleNumbers` reads tokens, cost and seconds from it. `scopeTotals` sums the
ledger (`scopeEntries`), which gets a row only when a step ends, and the
seconds of finished steps only (`scopeSteps` → `addStepTimes`). A running step
adds nothing, so the box of a role on its first step of a story reads
`0 · $0.00 · 0s` in Story scope.

The running step's numbers are already in the snapshot:

- `heartbeat.step` (`live.Reading.view()`): `role`, `story`, `started_at`,
  `tokens` and `cost_usd`. `Reading._line` adds each turn's new tokens to
  `tokens`, its price to `cost_usd`, and the same token count to `rate`. So
  `tokens` and `cost_usd` are the sums of the very turns the box's tokens/min
  rate and sparkline are built from. Do **not** sum `view.turns` instead: the
  snapshot keeps only its last 10 minutes (`TURN_WINDOW_S`), so a long step
  would undercount.
- The open `steps` row of the role (`openStep(view, role)`): its `at` and
  `slept` give the awake time so far (`awakeSoFar`, AW10).

The ordering that matters for counting once (`dispatch._settle`):
`record_cost` writes the ledger row **first**, then `settle_tree` (git, can
take a while), then `_emit_step_end`, which closes the meter (the heartbeat
drops the step) and emits `step-end` (the `steps` row gets `ended_at` and
`seconds`). So for a while the ledger already holds the step while the
heartbeat still shows it and its `steps` row is still open.

## Rules

| # | Rule | AC |
|---|---|---|
| LT1 | **Which step is live.** The live step is `liveStep(view)` (a beating heartbeat, health not idle). It is counted only when it is inside the scope: `inScope(view)({ story: step.story, at: step.started_at })`. With no live step, or one outside the scope, the totals are `scopeTotals(view)` unchanged. | AC1 |
| LT2 | **Live tokens and cost.** The live step adds `sumTok(step.tokens)` tokens and `step.cost_usd ?? 0` dollars to its role's totals, until the ledger holds it (LT4). | AC1, AC2 |
| LT3 | **Live seconds.** The live step adds `Math.max(0, awakeSoFar(view, open))` seconds, where `open = openStep(view, step.role)`, only when `open` exists and `(open.story ?? null) === (step.story ?? null)`. With no matching open row it adds 0 (no wall-clock fallback here: once `step-end` closes the row, `addStepTimes` counts the step's own `seconds`). | AC1, AC2 |
| LT4 | **Counted once.** The ledger holds the live step when some `view.ledger` row has the same `role`, the same story (`(l.story ?? null) === (step.story ?? null)`) and `l.at >= step.started_at`. From then on LT2 adds 0 tokens and 0 dollars; LT3 still adds the seconds while the row is open. The two switches are independent because the ledger row and `step-end` land at different moments. | AC2 |
| LT5 | **Every scope, every snapshot.** The live part is added in Story, Sprint and Run scope alike (LT1 decides membership) and recomputed on each render, so it grows with each snapshot as `step.tokens`, `step.cost_usd` and the clock grow. | AC1 |
| LT6 | **Only the running role changes.** Every other role's totals are exactly `scopeTotals(view)[role]`. The PO keeps its own rules: its `seconds` stay `poSeconds(...)` (PB4) and its tokens and cost stay `—` in Story scope (`blank`). In Sprint and Run scope a running PO turn adds its live tokens and cost like any role. | AC1 |
| LT7 | **The ledger-only total stays.** `scopeTotals(view)` keeps its meaning (ledger plus finished steps; `test_scope_toggle_totals_match_the_ledger`, s44 AC9, pins it). The Flow chart reads the new `flowTotals(view)` instead. | AC2 |

## Changes per module

### `agile-team/runner/agile_team/dashboard/index.html`

Next to `scopeTotals` / `addStepTimes` (the "numbers in scope" helpers):

```js
/** Whether the ledger already holds the live `step`: a row of its role and story written since it started (LT4). */
const inLedger = (view, step) => view.ledger.some((l) => l.role === step.role
  && (l.story ?? null) === (step.story ?? null) && l.at >= step.started_at);

/** The live step's awake seconds so far from its open steps row, 0 without one (LT3). */
function liveSeconds(view, step) { ... }

/** `{tokens, cost, seconds}` of the live step in scope, or null (LT1-LT4). */
function liveTotals(view) { ... }

/** The Flow chart's totals: `scopeTotals` plus the live step's numbers on its role (LT5-LT7). */
function flowTotals(view) { ... }
```

- `liveSeconds`: `open = openStep(view, step.role)`; return
  `Math.max(0, awakeSoFar(view, open))` when `open` matches the step's story
  (LT3), else `0`.
- `liveTotals`: `step = liveStep(view)`; `null` when no step or
  `!inScope(view)({ story: step.story, at: step.started_at })`. Else
  `const owed = !inLedger(view, step);` and return
  `{ tokens: owed ? sumTok(step.tokens) : 0, cost: owed ? step.cost_usd ?? 0 : 0, seconds: liveSeconds(view, step) }`.
  Split into a helper `liveSpend(view, step) -> {tokens, cost}` if it runs
  over 8 lines.
- `flowTotals`: `totals = scopeTotals(view)`, `live = liveTotals(view)`; when
  `live`, `t = (totals[liveStep(view).role] ??= { tokens: 0, cost: 0, seconds: 0 })`
  and add the three numbers; return `totals`.
- `flowModel`: `ctx.totals` is `flowTotals(view)` (was `scopeTotals(view)`).
- `flowContext` (L858) is called nowhere (it predates s118's `flowModel`);
  delete it rather than keep a second copy of the context.
- `roleNumbers`, `roleBox`, `dimmed`: no change. A running role now has a
  `ctx.totals` entry, so it is neither `idle` nor dimmed, which is right.
- Optional tidy, same story: `runningPanel`'s caller (L926-L927) and
  `liveBlock` (L1456-L1457) both compute
  `open ? awakeSoFar(view, open) : now - step.started_at`; they may share one
  helper. Their output must not change.

No CSS, text kind, show key, snapshot field or fixture change.

harness: `dashboard_node.run_page(driver, now)`, start from a copy of
`dashboard_node.fixture()`). The fixture's live step is `developer-cli` on
`s3`, `implement`, `started_at` 1791472960.0, with an open `steps` row at the
same `at`; tokens 2 130 103, cost 1.0767. To make it a **first** step, drop
from the copy every `ledger` row and every finished `steps` row of
`developer-cli` on `s3`. Read the numbers through
`roleNumbers(view, flowModel(view).ctx, role)` with `ui.scope`/`ui.focus` set.

      `tokens` is `sumTok(heartbeat.step.tokens)`, `cost` is `1.0767`,
      `seconds` is `now - 1791472960.0 - slept` (use `about`), all > 0; the
      box HTML has no `f-tokens">0<`.
