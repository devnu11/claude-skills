Drop `from urllib.request import urlopen`. Keep `HTTPError` and `URLError`.

```python
def reachable(url: str) -> bool:
    """True when anything answers at ``url``; an HTTP error status still counts."""
    try:
        system.http_get(url, PROBE_TIMEOUT_S)
    except HTTPError:
        return True
    except (URLError, OSError, ValueError):
        return False
    return True
```

## `tests/fake_system.py` additions (unit-tester, Z10)

```python
class FakeSystem:
    workdir: Path                      # was `cwd` (attribute); see below
    programs: dict[str, str]           # answers which(); empty by default
    opened: list[str]                  # open_browser urls, in order
    handlers: list[tuple[int, Callable[[], object]]]   # on_signal calls
    on_sleep: list[Callable[[], object]]               # work done while the runner sleeps
```

- **`cwd` is a method now.** `install` binds `getattr(self, name)` for every
  name in `system.__all__`, so the `cwd` attribute (`FAKE_REPO`) would be
  swapped in as the function. Rename the attribute to `workdir`, and have
  `cwd()` return `FAKE_REPO`. Tests that read `fake.cwd` (`test_s82.py`,
  `test_process_groups.py`, `test_sandbox.py`) use `FAKE_REPO`.
- `home()` → `FAKE_HOME`. `which(name)` → `self.programs.get(name)`.
  `open_browser(url)` appends to `opened` and returns `True`.
  `on_signal(sig, callback)` appends `(sig, callback)` to `handlers`.
- `async def async_sleep(seconds)` behaves as `sleep`. Both go through one
  helper: record `seconds` in `slept`, advance the clock, then, if `on_sleep`
  is not empty, pop its first callback and call it. That replaces the tests'
  own `sleep=` functions, for example `fake.on_sleep = [lambda: None, lambda:
  rt.relay.answer("m1", "sqlite")]` (the answer lands during the second
  wait).

### Pitfalls

- `which` answers `None` unless `fake.programs` holds the name. A test that
  runs `start` through the preflight sets the config's toolchain executables
  (`fake.programs["uv"] = "/usr/bin/uv"`).
- A pid file holding `FAKE_IDS[0]` reads as a live runner (`fake.groups`).
  Any other pid is dead unless the test adds it to `fake.groups`.
- `stop --now` records `("kill", FAKE_IDS[0], SIGTERM)` in `fake.signals`.
  The fake never ends the runner's own pid.
- A port in use for `dashboard` is `fake.listening.add((host, port))`;
  `listen_http` then raises `EADDRINUSE`.
- Default git replies are success (s71 Pitfalls). The runtime flows in the
  old `LEGACY` files (commits, `merge-base --is-ancestor`, `status`, `diff`)
  must script the answer the test means.
