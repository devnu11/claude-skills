# s181 design: the heartbeat lists every open chore

Developer: `developer-cli` (runner Python, plus a small change to
`dashboard/index.html` and the fixture source).
ADR: ADR-0032, amended by s181 (`.team/adr/0032-live-spend-meter-heartbeat-and-health.md`).
Requirements: REQ-214 (AC1), REQ-215 (AC2), REQ-216 (AC3).

## Cause

`Pulse.doing` (`live.py`) saves the current chore, sets its own and restores
the saved one on exit. Chores from parallel stories don't end
last-in-first-out: A opens, B opens (saved: A), A ends (chore: none), B ends
(chore: A). A finished chore then stays on the heartbeat. Stage rows
(`Pulse.showing`) add their row and remove it by identity, and don't have
this bug. Chores get the same shape.

## Rules

| id | rule |
|---|---|
| CH1 | `Pulse` keeps `_chores: list[dict[str, Any]]` (default empty) in place of `_chore`. `doing` appends its own row on entry and, on exit (also on an exception), removes **that row by identity**. It never saves or restores another row. |
| CH2 | A chore row is `{"what": what, "story": story, "since": system.now()}`, keys in that order. `story` is the story id, or `None` for run-wide work. |
| CH3 | The heartbeat's `"chore"` key is replaced by `"chores"`, at the same position (after `slept`, before `step`): `list(self._chores) if live else []`. Rows are in open order, oldest first. |
| CH4 | `live.HEARTBEAT_VERSION` becomes `3` (a key is removed, not added). |
| CH5 | Every `doing` caller passes its story (table below). |
| CH6 | `health.Vitals` reads `chores`; its `chore` is the **oldest** open chore (`chores[0]`), else `None`. The `RULES` table, `_chore_words` and `quiet_for` are unchanged and keep using `chore`. |
| CH7 | The live panel shows one row per open chore under its second line, in every panel state (a step running, a stage, nothing). The rows are rebuilt from `view.heartbeat.chores` on every render (`renderLivePanel` and the clock tick's `renderPanelText`); the page keeps no chore state, so a row is gone at the first render after the heartbeat drops it. |
| CH8 | `chorePanel` (only reached when no step, event or stage applies) no longer shows one chore: who `⚙ runner`, when `""`, line `1 chore open` / `N chores open`, story `""`. The rows under it name the chores. |
| CH9 | The fixture's heartbeat source carries the list with one row, so the snapshot shows the rows next to the running step. |

### CH5: callers

| file:line (today) | call after |
|---|---|
| `stop_checks.py:170` | `self.runtime.pulse.doing(self._chore(), self.plan.story.id if self.plan.story else None)` |

| `dispatch.py:1277`, `:1280` (`_settle_threaded`) | `doing(what, plan.story.id if plan.story else None)`; compute the id once, next to `what` |
| `dispatch.py:1491` | the same as `_settle_threaded` |
| `dispatch.py:1859` (`_evaluate`) | `doing(chore, plan.story.id)` |
| `po_tools.py:612` (`wait_for_answers`) | unchanged: `doing(WAIT_CHORE.format(…))`, story `None` |
| `boundary_runner.py:252` | unchanged: `doing(f"sprint boundary: {stage}")`, story `None` |

The chore texts (`STOP_CHORE`, `TESTS_CHORE`, `GATE_CHORE`, `QUALITY_CHORE`,
`WAIT_CHORE`, `settling …`, `sprint boundary: …`) stay as they are.

## Changes per module

### `agile_team/live.py`

```python
HEARTBEAT_VERSION = 3

class Pulse:
    _chores: list[dict[str, Any]] = field(init=False, default_factory=list)  # replaces _chore

    @contextmanager
    def doing(self, what: str, story: str | None = None) -> Iterator[None]:
        """Mark runner-side work on ``story`` (``None``: run-wide) in progress (H5, CH1)."""
```

Body, mirroring `showing`: build the row, append it under the lock, `write()`;
`try: yield` / `finally:` under the lock drop the row by identity
(`[r for r in self._chores if r is not row]`) and call `_wake_innermost()`,
then `write()`. `heartbeat()` writes `"chores"` per CH3. The module
docstring is unchanged.

### `agile_team/health.py`

```python
@property
def chores(self) -> list[dict[str, Any]]:
    """The heartbeat's open chores, oldest first; ``[]`` when not beating or not a list."""

@property
def chore(self) -> dict[str, Any] | None:
    """The oldest open chore, else ``None`` (CH6)."""
```

`chores` returns `[]` unless `self.beating` and `beat["chores"]` is a list.
`chore` returns `self.chores[0]` when there is one. Nothing else changes.

### `agile_team/dashboard/index.html`

- HTML: inside `#live-panel`, after `#lp-line` and before `#lp-msg`:
  `<div class="lp-chores" id="lp-chores" hidden></div>`.
- CSS, next to `.lp-line`:
  `.lp-chores[hidden] { display: none; }` and
  `.lp-chore { font-size: 12px; color: var(--ink-2); white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }`.
- JS, next to `openStages`:
  - `openChores(view)`: `beating(view) && Array.isArray(view.heartbeat.chores) ? view.heartbeat.chores : []`.
  - `choreText(view, chore)`: `` `⚙ ${chore.story || "run"} · ${chore.what} · ${fmt.age(clockNow(view) - chore.since)}` ``.
    Example: `⚙ s162 · stop checks for developer-cli on s162 · 2 min`; a
    boundary chore reads `⚙ run · sprint boundary: boundary.check · 45 s`.
  - `choresLine(n)`: `n === 1 ? "1 chore open" : `${n} chores open``.
  - `renderChoreRows(view)`: builds one `div.lp-chore` per open chore with
    `document.createElement` and `textContent` (never `innerHTML`: `what`
    is runner text), puts them in `#lp-chores` with `replaceChildren`, and
    sets `hidden` when there are none.
- `chorePanel(view)`: returns `null` when `openChores(view)` is empty, else
  `{ kind: "stage", who: "⚙ runner", when: "", line: choresLine(n), story: "" }` (CH8).
- `renderLivePanel(view)` and `renderPanelText(view)` each call
  `renderChoreRows(view)` after `fillPanelText`.

because REQ-215 replaces the key and CH4 bumps the version:
`test_s44_live.py` (key list at :234, :241, :298, :320-332, the vitals
helper at :409, :508), `test_s44_round1.py` (:103, :144-157, :278),

`e2e/test_health_false_red_e2e.py` (:60, :103),
`e2e/test_s112_activity_page_e2e.py` (:472-479). Each reads `chores`
(a row's `what` through `["chores"][0]["what"]`, or `== []` for none) and
keeps what it checked.

New tests:

- [ ] AC1/REQ-214 (`test_s44_live.py`): enter `doing("A", "s1")`, then
  `doing("B", "s2")` (explicit `__enter__`/`__exit__` or two `ExitStack`s),
  exit A: `chores` is exactly B's row; exit B: `chores == []`.
- [ ] AC1/REQ-214: nested chores still work: outer, inner, inner exits (outer
  alone), outer exits (`[]`).
- [ ] AC1/REQ-214: a chore that exits with an exception removes only its own
  row; another open chore stays.
- [ ] AC1/REQ-214: two chores entered and exited from two threads in the
  A-B-A-B order (a `threading.Barrier` or events, no sleeps) leave `[]`.
- [ ] AC2/REQ-215: a row is `{"what": "A", "story": "s1", "since": NOW}`;
  `doing("x")` gives `"story": None`; rows are oldest first; an ended pulse
  writes `"chores": []`; `heartbeat()` has no `chore` key and
  `version == 3`.
- [ ] AC2/REQ-215 (callers): the stop checks, named tests, quality checks,
  settling and gate chores carry the plan's story id
  (`pulse.heartbeat()["chores"][0]["story"]` read inside the block, as the
  existing s78 and s44 wiring tests read `what`); the PO wait and the
  boundary chore carry `None`.
- [ ] AC2/REQ-215 (`test_s78_health.py`): `Vitals.chores` is `[]` when not
  beating and when `chores` is not a list; `Vitals.chore` is the first row of
  two; the green rule words name the oldest chore.
- [ ] AC3/REQ-216 (page, node harness): with two open chores and a running
  step, `#lp-chores` has two `.lp-chore` rows with `choreText` for each, and
  the step panel is unchanged; with `chores: []` the element is `hidden` and
  empty; a chore whose `what` holds `<b>` shows it as text.
- [ ] AC3/REQ-216: rendering again after one chore leaves the heartbeat
  leaves one row (no state kept); a heartbeat that is not beating shows no
  rows.
- [ ] AC3/REQ-216: with chores only, `panelState` is `⚙ runner` with
  `2 chores open`.
- [ ] AC3/REQ-216 (fixture): the snapshot's `heartbeat.chores` is the list
  from the source, `version` is 3, and the rebuilt fixture equals the
  committed one.
- [ ] AC1, by hand (the AC says so): two stories whose stop checks or named
  tests overlap; read `heartbeat.json` after each ends.
