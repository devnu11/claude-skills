# s162: unattended status says how long a job has left before its deadline

Story: `.team/stories/s162.md`. Requirements: REQ-186 (AC1), REQ-187 (AC2).
Developer: `developer-cli`. No ADR: this adds one read-only field to an
existing JSON report, with no new boundary, format, dependency or state.

## Rules

1. Every job report (`cli.report`) carries `time_left`, placed right after
   `deadline`. `status NAME`, `status`, `list`, `wait` and `extend` all print
   `report`, so all of them show it.
2. `time_left` is, for a job whose stored `bounds.deadline` is:
   - `None`: `null`;
   - at or before `now` (`deadline <= now`, the same test `cli._future` uses
     for "has already passed"): the string `"overdue"`;
   - after `now`: the whole minutes until it, rounded down
     (`int((deadline - now) // 60)`), written by `limits.span` on those
     minutes in seconds: `23h41m`, `41m`, `1h` (span drops zero parts),
     `1d2h5m` past a day (span's day unit stays). Under a full minute it is
     `"0m"`, never span's `"0s"`. No seconds part ever appears.
3. `now` is the clock when the command runs (`time.time()` in the command
   functions), passed into `report`. Nothing is computed ahead of time.
4. No new state: `report` writes nothing (no `job.update`, no `job.event`).
   `limits_report` is unchanged, so the `extend` event in `events.jsonl`
   keeps exactly `deadline`, `hardstop`, `idle_stop`. Every other field of
   every report keeps its value and its order.

## Changes per module

### `unattended/runner/unattended/limits.py`

Next to `span`, in the "stop phases" section:

```python
def format_time_left(deadline: float | None, now: float) -> str | None:
    """Whole minutes to ``deadline`` as ``span`` writes them; ``overdue``; None without one."""
```

`None` → `None`; `deadline <= now` → the literal `"overdue"` (no module
constant); else `minutes = int((deadline - now) // 60)` and
`span(minutes * 60) if minutes else "0m"`. The name is a verb phrase, per the
naming rule (REQ-073).

### `unattended/runner/unattended/cli.py`

- `report(job: Job, now: float) -> dict[str, Any]`: the second parameter is
  new. Replace `**limits_report(st.bounds)` with
  `**build_status_limits(st.bounds, now)`. Docstring: say `now` is the clock
  `time_left` is measured against.
- New, next to `limits_report`:

  ```python
  def build_status_limits(bounds: Bounds, now: float) -> dict[str, Any]:
      """``limits_report`` with ``time_left`` (at ``now``) right after ``deadline``."""
  ```

  It builds `limits_report(bounds)` and puts
  `"time_left": format_time_left(bounds.deadline, now)` after the `deadline`
  key (e.g. `limits.pop("deadline")` first, then `**limits`).
- Import `format_time_left` from `.limits` with the module's existing
  imports from there.
- Callers pass `time.time()`: `cmd_status`, `cmd_list` (one `now` read
  once for the whole list, so every job is measured against the same
  instant), `_waited`, `cmd_extend`.
- `limits_report` and the `extend` event stay as they are.

## Test checklist

`tests/test_limits.py` (pure, fixed numbers, no clock):

- [ ] `format_time_left(None, 1000.0) is None`.
- [ ] `format_time_left(1000.0, 1000.0) == "overdue"` and
      `format_time_left(1000.0, 1001.0) == "overdue"`.
- [ ] Under a minute: `format_time_left(1059.0, 1000.0) == "0m"`.
- [ ] Rounded down: `format_time_left(1000.0 + 41 * 60 + 59, 1000.0) == "41m"`.
- [ ] Hours and minutes:
      `format_time_left(1000.0 + 23 * 3600 + 41 * 60 + 30, 1000.0) == "23h41m"`.
- [ ] Whole hour: `format_time_left(1000.0 + 3600, 1000.0) == "1h"`.
- [ ] Past a day keeps span's day unit:
      `format_time_left(1000.0 + 86400 + 120, 1000.0) == "1d2m"`.

`tests/test_cli.py`:

- [ ] `cli.report(job, now)` with a stored deadline `now + 3630` gives
      `time_left == "1h"`, with `deadline` unchanged (still `iso(deadline)`),
      and `time_left` is the key right after `deadline`.
- [ ] Same job, `now` past the deadline: `time_left == "overdue"`.
- [ ] A job with no deadline: `time_left is None`.
- [ ] `status NAME`, `list` and `wait` print `time_left` (deadline set
      about an hour and a half out with `time.time()`; assert a value that
      does not depend on seconds of drift, e.g. `"1h30m"` from a deadline of
      `time.time() + 5430`).
- [ ] AC2: the report's keys other than `time_left`, and their values, equal
      what they were before (compare against the existing key list in
      order); `state.json` and `events.jsonl` are byte-for-byte unchanged
      after `status`.
- [ ] `extend`: the logged `extend` event has no `time_left`.
