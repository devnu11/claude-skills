# s150: a Board card's wait pill shows the reason only, and no card pill wraps

Developer: `developer-gui`. Scope: `agile-team/runner/agile_team/dashboard/index.html`
and one new node-harness test file. No runner, snapshot or fixture change. No ADR:
this is presentation only, with no new boundary, format or dependency.

Requirements: REQ-097 (AC1, AC2, AC4), REQ-098 (AC3, AC4).

## Rules

| id | rule | AC |
|----|------|----|
| W1 | The wait pill's text is `⏸ ${s.wait.reason}` and nothing else, e.g. `⏸ cancel requested`, `⏸ held`, `⏸ round cap`. Its `title` attribute is `s.wait.title`, the full title (`<reason>: <detail>` for `cancel requested`, `revert requested` and `PO hold`; the reason alone otherwise). | AC1 |
| W2 | The wait detail is visible once on the card: in the existing `waits on:` line (`waitLine`, unchanged: visible text cut at 140 characters, the whole line in its `title`). The pill's visible text never holds it. | AC2 |
| W3 | Every pill on a story card stays one line. A label too long for the card is cut with an ellipsis (`…`, drawn by CSS), and the pill's `title` holds its full text. This covers the card's role pill (`▶ <role>`), the revert pill, the wait pill and the environment pills (`envPills`). | AC3 |
| W4 | The snapshot is unchanged: `wait` stays `{reason, on, title}` (`waits.py`). Only the page reads it differently. | AC1 |

## Changes

### CSS (`index.html`, the `/* board */` block, now L268)

Replace `.story .pill { white-space: normal; }` with:

```css
.story .pill {
  display: inline-block; max-width: 100%; white-space: nowrap;
  overflow: hidden; text-overflow: ellipsis; vertical-align: middle;
}
.story .pill .dot { display: inline-block; margin-right: 5px; vertical-align: middle; }
```

Why `inline-block`: the base `.pill` is `inline-flex`, and `text-overflow` does not cut the
text of a flex container. A block container does. The dot then needs its own `display` and
the 5 px the flex `gap` gave it. Inside a `.row` (a wrapping flex box) the pill is a flex
item; `overflow: hidden` lets it shrink below its text width, and `max-width: 100%` caps it
at the row. The base `.pill` rule is not changed, so pills on other tabs look the same.

Keep the selector `.story .pill` exactly (the test reads that rule), and leave no other
rule that sets `white-space` on `.story .pill`.

### JS (`index.html`)

1. New helper next to `pill` (about L501):

   ```js
   /** A story card's pill (s150): one line, cut by CSS; its tooltip is `title`, else its text. */
   const cardPill = (text, { tone = "", title = text, dot = true } = {}) =>
     `<span class="pill tone-${tone}" title="${esc(title)}">${dot ? '<span class="dot"></span>' : ""}${esc(text)}</span>`;
   ```

   `pill` itself is unchanged (other tabs use it; adding a title there is out of scope).

2. `storyCard` (about L2451), the `flags` array:

   ```js
   working ? cardPill(`▶ ${act.role}`, { tone: "accent" }) : "",
   revertPill(s),
   s.wait ? cardPill(`⏸ ${s.wait.reason}`, { tone: WAIT_TONE[s.wait.reason] ?? "warning", title: s.wait.title }) : "",
   ```

3. `revertPill` (about L2012) builds with
   `cardPill(\`reverted (${s.reverts}×)\`, { tone: "warning", dot: false })`. It is only
   used on the card.

4. `envPills` (about L509) is unchanged: its pills already carry a `title`
   (`acceptance environment <name>: <state>`), which names the full environment, and the
   new CSS keeps them on one line inside `.story`. On the Backlog tab (`.bmeta`) they are
   not inside `.story` and are untouched.

5. `waitLine` is unchanged.

No other function changes. `WAIT_TONE` keeps its keys.

## Tests

New file `agile-team/runner/tests/e2e/test_s150_wait_pill_e2e.py`, node harness, in the
style of `tests/e2e/test_s100_timeline_e2e.py` (`dashboard_node.run_page`, a `_run(body)`
helper binding `view` from `dashboard_node.fixture()`; skip when `node` is missing). Build
one long reason in Python, `LONG = ("the export spills to disk " * 12)[:300]` (300
characters, no newline), and put it on fixture story `s4`:

```js
const s = view.stories.find((x) => x.id === "s4");
s.wait = { reason: "cancel requested", on: ["m9: Cancel story s4?", LONG], title: "cancel requested: " + LONG };
s.reverts = 2;
s.environments = [{ name: "dashboard", verdict: "" }];
out.card = storyCard(view, s, { story: "s4", role: "developer-gui-with-a-very-long-specialisation-name" });
```

Parse the pills out of `out.card` in Python (regex on `<span class="pill[^"]*"( title="…")?>…</span>`,
the dot span stripped) and unescape the HTML entities before comparing.
