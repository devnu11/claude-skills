# s97: Step time leaves out machine sleep

Developer: `developer-gui` (as s96: the bulk is `dashboard/step_times.py`,
the snapshot and the page; the runner side is about 25 lines in `live.py`,
`dispatch.py` and `system.py`). No ADR: no new dependency, no new event
kind, no new state. Step events gain two `data` keys, the heartbeat gains
one key, and each snapshot step gains two keys.

## Why two clocks

`time.monotonic()` pauses while macOS or Linux sleeps, so a monotonic span
is awake time. On Windows it keeps counting through sleep (AC3), so the
Windows branch subtracts the sleep the runner's heartbeat saw instead. The
heartbeat thread beats every `beat_s` (20 s). A sleep shows up as one gap
between beats much longer than `beat_s`, on every platform. The runner adds
those gaps to a counter, and step events record the counter. The platform
branch is one table, `AWAKE`, on the read side. The runner writes the same
data on every platform.

## Rules

- **AW1. Step events carry two clocks (AC1).** Every `step-start` and
  `step-end` the runner writes while it runs adds `data.mono`
  (`system.monotonic()`) and `data.slept` (the pulse's sleep counter, AW2).
  The writers are `dispatch._take_off`, `dispatch._emit_step_end` and
  `live.Meter.interrupted` (used by `dispatch._close_interrupted`).
  Recovery's killed `step-end` (`recovery.py`, written by the next runner
  process) gets neither. A killed step has no time anyway (ST4).
- **AW2. The heartbeat counts sleep.** `Pulse.slept_s` starts at 0 for each
  runner process. Each `_beat` measures the wall gap since the previous
  `_beat` (the first gap starts at `started_at`). When the gap is more than
  `SLEEP_GAP_BEATS` (2) × `beat_s`, it adds `gap - beat_s`. Writes from other
  threads (`open`, `take`, `doing`) neither count nor move the previous
  beat's time. The heartbeat JSON gains `"slept": round(slept_s, 1)`.
  `HEARTBEAT_VERSION` stays 2 (a key is added; readers ignore unknown keys).
- **AW3. A clock reading (`Mark`).** It takes `at` from the event's
  top-level `at`, and `mono` and `slept` from `data`. A reading counts only
  if it is an `int` or `float` and not a `bool`. Anything else is `None`.
- **AW4. Platform.** `system.platform()` returns `sys.platform`.
  `PLATFORMS = {"win32": Platform.WINDOWS}`, and any other name is
  `Platform.POSIX`. The snapshot reads the platform where it is built. That
  is the runner's machine, because the dashboard serves the local
  `.team/run`.
- **AW5. POSIX awake time (AC2).** `end.mono - start.mono`. It is `None`
  when either reading is missing, or when the end is below the start (a
  different boot).
- **AW6. Windows awake time (AC3).** `(end.at - start.at) - (end.slept -
  start.slept)`. It is `None` when either counter is missing, or when the
  end counter is below the start (a different runner process).
- **AW7. Awake or wall (AC2).** If the platform's awake time (AW5/AW6) is
  `None`, the step falls back to wall time: `seconds = round(max(0, wall),
  1)` (ST3 as before), `clock = "wall"`, `slept = 0.0`. Otherwise
  `seconds = round(max(0, awake), 1)`, `clock = "awake"`, `slept =
  round(max(0, wall - awake), 1)`. Here `wall = end.at - start.at`.
- **AW8. A killed step stays untimed.** ST4 still holds: `seconds`, `clock`
  and `slept` are all `null`.
- **AW9. A running step (AC2).** `seconds` stays `null` (ST5). `clock` and
  `slept` are measured with AW7 from the start to the snapshot's own
  reading: `at = files.now`, `mono = files.mono`, `slept` = the heartbeat's
  `slept` (AW3 rules; `None` without a heartbeat). So `slept` is the sleep so
  far.
- **AW10. Running line (AC2).** The page's running time is `clockNow(view) -
  step.at - (step.slept ?? 0)`. If `step.clock === "wall"`, the line ends
  ` (may include sleep)`. Between snapshots the browser clock counts on. The
  heartbeat rewrites every `beat_s`, which sends a new snapshot, so a sleep
  is taken out within one beat of waking.
- **AW11. Marking old steps (AC2).** `timeBy` also counts `wall`, the steps
  with `clock === "wall"`. A Time bar's tooltip adds ` · N may include
  sleep` when `wall > 0`. The Flow box totals carry no mark (see Known
  limits).
- **AW12. Legend (AC4).** With Time chosen, the legend reads `Awake time
  (agent steps only; runner stages: see A6)`. This replaces ST14's text.
- **AW13. Replay.** `stepsAsOf` also sets `clock` and `slept` to `null` on a
  step it reopens, so in replay a reopened step shows its wall time
  unmarked.

ST1, ST2 and ST4 to ST13 and ST15 of s96 stand. AW7 replaces ST3 and AW12
replaces ST14.

## Snapshot contract

Each `steps` object gains two keys after `seconds`:

```json
{"role": "architect", "story": "s1", "model": "opus", "sprint": 1,
 "at": 1791452316.6, "ended_at": 1791452620.3, "seconds": 183.7,
 "status": "done", "clock": "awake", "slept": 120.0}
```

| key | value |
|---|---|
| `seconds` | awake seconds (AW7), wall seconds for an old step; `null` while running and for a killed step |
| `clock` | `"awake"` or `"wall"` (the "may include sleep" fallback); `null` for a killed step |
| `slept` | wall seconds left out as sleep (finished: the whole step; running: so far); `0.0` for a wall step; `null` for a killed step |

The heartbeat section gains `slept` (AW2).

Fixture `dashboard/fixtures/snapshot.json`:
- Give the `step-start`/`step-end` events of most finished steps
  `data.mono` and `data.slept`. Choose the values so both branches agree:
  `Δmono = Δat - Δslept`. At least one of these steps spans a sleep
  (`Δslept > 0`, e.g. 120 s).
- Leave at least one finished step without them (an old step, `clock:
  "wall"`).
- Leave the running step's start without them. Its `clock` is then `"wall"`
  and its `slept` is `0.0` on every platform and at any build time, so the
  s96 contract test stays deterministic.
- The heartbeat gains `"slept": 0.0`.
- Regenerate `steps` so they equal `_steps` over the fixture's events.

## Changes per module

### `agile_team/system.py`

```python
def platform() -> str:
    """The OS name as ``sys.platform`` gives it (``darwin``, ``linux``, ``win32``)."""

```

Add `"platform"` to `__all__` after `"pid"`. `tests/fake_system.py`'s
`FakeSystem` implements every name in `__all__`, so it gains `platform()`
(attribute `platform_name = "darwin"`). It also gains a way to sleep: an
`asleep` total that `monotonic()` subtracts (`clock - asleep`) and
`doze(seconds)`, which moves `clock` and `asleep` together.

### `agile_team/live.py`

```python
SLEEP_GAP_BEATS = 2  # a beat gap over this many beats is sleep (AW2)

class Pulse:
    slept_s: float = field(init=False, default=0.0)
    _last_beat: float = field(init=False)            # set to started_at in __post_init__

    def _beat(self) -> None:                          # try: self._count_sleep(system.now()); self.write()
    def _count_sleep(self, now: float) -> None:
        """Add a beat gap longer than ``SLEEP_GAP_BEATS`` beats, less one beat, to ``slept_s`` (AW2)."""
    def clocks(self) -> dict[str, float]:
        """``{"mono": …, "slept": …}`` for a step event (AW1)."""
    def heartbeat(self) -> dict[str, Any]:            # gains "slept": round(self.slept_s, 1)

class Meter:
    def interrupted(self, stop: Stop) -> Event:
        """The reading's ``interrupted`` step-end with this pulse's ``clocks()`` added to its data (AW1)."""
```

- `_count_sleep` updates `slept_s` and `_last_beat` under `self._lock`,
  then releases it before `write()` takes the lock again. `threading.Lock`
  is not reentrant.
- `clocks()` reads `slept_s` without the lock: a float read is atomic, and
  `clocks()` must not deadlock if a caller holds the lock.
- `Reading.interrupted` is unchanged (`test_s44_live` calls it).

### `agile_team/dispatch.py`

- `_take_off`: `self.emit(EventKind.STEP_START, plan, brief=brief, **self.pulse.clocks())`.
- `_emit_step_end`: add `**self.pulse.clocks()` to the `emit` keywords.
- `_close_interrupted`: `self.events.emit(meter.interrupted(live.Stop(cause, reason)))`.

### `agile_team/dashboard/step_times.py`

Docstring: `"""Awake time of agent steps, paired from the event log (s96, s97)."""`

```python
class Clock(StrEnum):
    """Which clock timed a step (AW7)."""
    AWAKE = "awake"
    WALL = "wall"

class Platform(StrEnum):
    """Which awake-time rule applies (AW4)."""
    POSIX = "posix"
    WINDOWS = "windows"

PLATFORMS: dict[str, Platform] = {"win32": Platform.WINDOWS}

def platform_of(name: str) -> Platform:
    """``PLATFORMS[name]``, else POSIX (AW4)."""

def number(value: Any) -> float | None:
    """``value`` as a clock reading, or None when missing, a bool or not a number (AW3)."""

@dataclass(frozen=True)
class Mark:
    """One clock reading: wall ``at``, monotonic ``mono``, the heartbeat's ``slept`` counter."""
    at: float
    mono: float | None = None
    slept: float | None = None

    @classmethod
    def of(cls, event: dict) -> Mark:
        """The reading an event carries (``at``, ``data.mono``, ``data.slept``)."""

EPOCH = Mark(0.0)  # a module constant, not a call in a default (ruff B008/RUF009)

def gap(first: float | None, last: float | None) -> float | None:
    """``last - first``, or None when either is missing or the counter went back."""

def mono_awake(start: Mark, end: Mark) -> float | None:
    """AW5: the monotonic span (the clock pauses in sleep on macOS and Linux)."""

def slept_awake(start: Mark, end: Mark) -> float | None:
    """AW6: the wall span less the sleep the heartbeat counted (Windows)."""

AWAKE: dict[Platform, Callable[[Mark, Mark], float | None]] = {
    Platform.POSIX: mono_awake,
    Platform.WINDOWS: slept_awake,
}

@dataclass(frozen=True)
class Timing:
    """A step's ``seconds``, ``clock`` and ``slept``; all None for an untimed step."""
    seconds: float | None = None
    clock: Clock | None = None
    slept: float | None = None

UNTIMED = Timing()

def wall_timing(wall: float) -> Timing:
    """The fallback: wall seconds, ``clock`` WALL, nothing left out (AW7)."""

def awake_timing(wall: float, awake: float) -> Timing:
    """Awake seconds, ``clock`` AWAKE, ``slept = wall - awake`` (AW7)."""

@dataclass(frozen=True)
class Stopwatch:
    """The reader's platform and its reading now; the default times every step by wall clock."""
    platform: Platform = Platform.POSIX
    now: Mark = EPOCH

    def between(self, start: Mark, end: Mark) -> Timing:
        """AW7 over the platform's ``AWAKE`` rule."""

    def so_far(self, start: Mark) -> Timing:
        """AW9: ``between(start, self.now)``."""

def killed(end: dict) -> bool:
    """Whether recovery closed the step (``data.cause == "killed"``, ST4)."""
```

`Span` gains `clock: str | None = None` and `slept: float | None = None` as
its last fields.

`Pairing`:

```python
@dataclass
class Pairing:
    watch: Stopwatch = field(default_factory=Stopwatch)
    found: list[Span | None] = …
    open: dict[Key, int] = …
    starts: dict[int, Mark] = field(default_factory=dict)  # index in found → its start reading
    sprint: int | None = None

    def start(self, event: dict) -> None:       # as s96, plus self.starts[index] = Mark.of(event)
    def end(self, event: dict) -> None:         # self.found[index] = self._closed(index, event)
    def _closed(self, index: int, end: dict) -> Span:
        """ended_at, status and model from ``end``, timed by ``_timing`` (AW7, AW8)."""
    def _timing(self, index: int, end: dict) -> Timing:
        """UNTIMED for a killed end, else ``watch.between`` its start and end."""
    def _running(self, index: int) -> Span:
        """An open step with ``clock`` and ``slept`` so far; ``seconds`` stays None (AW9)."""
    def result(self) -> list[Span]:
        """Every step in start order, open ones through ``_running``."""

WALL_CLOCK = Stopwatch()  # times every step without `mono` by wall clock; the s96 default

def spans(events: list[dict], watch: Stopwatch = WALL_CLOCK) -> list[Span]:
    """Every agent step in start order; open ones are running (ST1 to ST6, AW7 to AW9)."""
```

- Remove `closed` and `wall_seconds`. `_closed` and `_timing` replace them,
  and no test calls them directly.
- Apply a timing with `replace(span, seconds=t.seconds, clock=t.clock,
  slept=t.slept)`. `_running` sets only `clock` and `slept`.
- The default `WALL_CLOCK` keeps the s96 call `spans(events)` working.
  Events without `mono` time as wall on either platform.

### `agile_team/dashboard/snapshot.py`

```python
def _watch(files: RunFiles) -> step_times.Stopwatch:
    """The reader's clocks now (AW4, AW9): platform, wall, monotonic, the heartbeat's ``slept``."""
    beat = _heartbeat(files) or {}
    now = step_times.Mark(files.now, files.mono, step_times.number(beat.get("slept")))
    return step_times.Stopwatch(step_times.platform_of(system.platform()), now)

def _steps(files: RunFiles) -> list[dict]:
    """Every agent step with its awake time (s96, s97)."""
    return [_step(files, span) for span in step_times.spans(files.events, _watch(files))]
```

## Known limits

- On Windows the counter learns of a sleep only at the first beat after
  waking, and may undercount each sleep by up to one `beat_s` (20 s): the
  beat's wait may end during the sleep. Sleeps shorter than about two beats
  are not counted.
- A step whose start and end straddle a reboot or a runner restart falls
  back to wall time (AW5, AW6). In practice such a step is killed and
  untimed.
- The Flow box totals do not mark old wall-clock steps. The Time tooltip
  does.
- A running step's time can include a sleep for up to one beat after waking,
  until the next snapshot arrives.
