title: "The sprint-boundary full check runs the suite once, through the gate's shared single-run rule"
status: active
covers: ["s73/AC1", "s73/AC3", "s73/AC5"]
---
When a `coverage` command is set, the boundary full check runs it once and
does not run the `test` command. That one run proves the suite green and gives
the coverage figure, and a green run with enough coverage passes. The
`boundary.check` stage records one suite run, and its description says so.
The rule that tells a coverage shortfall from a failing suite is one shared
helper (`gates.coverage_shortfall`). The implement gate and the boundary check
both call it; neither keeps a second copy. With no `coverage` command, `test`
runs as before.
