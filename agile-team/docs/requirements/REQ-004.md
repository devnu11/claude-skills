title: The architect writes requirements; reviewers cite them
status: active
covers: ["s1/AC4", "s1/AC8"]
---

The architect writes a new requirement or adds a `covers` entry to an
existing one while designing a story. The code reviewer and the Customer
Proxy name the requirement and AC ids their findings are about. The skill's
guide, its protocol reference and these roles' instructions describe the file
format, the design gate and the command.
