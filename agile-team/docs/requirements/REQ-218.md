---
id: REQ-218
title: A story rebase step's out-of-scope edit is set aside off the branch and named in the report
status: active
covers: ["s182/AC2"]
---

An edit outside a story rebase step's scope never becomes a commit on the
rebase branch. The runner keeps it in a commit that only a ref under
`refs/agile-team/set-aside/` points to, and takes it out of the worktree. The
branch's commits stay as the role left them. The quarantine event and the
step's report name the edited paths and the ref.
