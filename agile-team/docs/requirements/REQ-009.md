---
id: REQ-009
title: Acceptance fails when a shared file changed
status: active
covers: ["s120/AC3", "s120/AC4"]
---

At the acceptance step, the runner compares each shared file's SHA-256 with
the one recorded in the story file. If a file changed or is missing, the
story fails acceptance and goes back to design, with a reason naming each
file. Only a new share from the liaison changes the recorded hash. A broken
list of shared files in the story file holds the story for the PO. Tests pin
both the pass and the fail.
