---
id: REQ-232
title: An acceptance environment's prepare and start commands get no VIRTUAL_ENV and no runner venv bin, with the environment's bin dirs first
status: active
covers: ["s186/AC1"]
---

An acceptance environment's prepare command and its start command run with
the rule REQ-199 gives the runner's own commands: no `VIRTUAL_ENV` variable
at all, and a `PATH` without any directory inside the runner process's own
venv. The environment's `bin` directories (resolved under its sandbox) still
come first on that `PATH`, in their configured order, and are never dropped,
even when one of them sits inside a venv. Every other variable in the
runner's environment reaches both commands unchanged.
