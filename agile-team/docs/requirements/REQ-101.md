id: REQ-101
title: Tests prove the Proxy's OS sandbox refuses every escape form from the original story
status: active
covers: ["s12/AC1"]
---

An end-to-end test runs the real claude CLI with the Customer Proxy's sandbox settings
and tries to read a source file outside the allow list through each escape form: `cd ..`,
`cd` alone, `cd /`, `~`, `$HOME`, a `$VAR` from the environment or set in the command,
`$(…)`, a wildcard path, an option-glued path (`--file=/abs/path`) and, on a
case-insensitive volume, a differently cased path. A control run without the sandbox
shows that each probe does read the file. With the sandbox, every read is refused.
