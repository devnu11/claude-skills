---
id: REQ-071
title: A quality refactor keeps behaviour, tests and docs as they are
status: active
covers: ["s57/AC3", "s57/AC4"]
---
A quality refactor changes no behaviour. The existing tests and the snapshot
fixture pass without being changed, and no test is weakened to let a refactor
pass. A name that a test uses keeps its name. The docs change only where
behaviour or a file name changes, for example a new module's row in the
architecture's component table.
