---
id: REQ-172
title: Boundary stages don't block the run
status: active
covers: ["s163/AC6"]
---

A boundary stage runs its checks, its CI wait and its git work off the event
loop, while its state changes still go through the one writer. A stage that
moves the main checkout (the sync, the replay, a fast-forward) holds the
main-checkout lock while it does. PO turns, story CI polls and the writer
keep going during a boundary.
