---
id: REQ-038
title: The runner onboards a queued story between steps, as a commit recorded against it
status: active
covers: ["s135/AC2", "s135/AC6"]
---

At its next safe point between steps, the runner takes each queued story in
queue order. It gives the story the next free id and writes
`.team/stories/<id>.md`. It commits that file alone in the team's branch and
records the commit against the story. Then it places the story as asked (in
the running sprint, first in the backlog for the next sprint, or in the
backlog, optionally right after a named story), with the same code the PO's
sprint and priority tools use. Last, it logs a `story-opened` event and
tells the PO.

Because the commit is recorded against the story, a history rewrite keeps
it, a story revert leaves the story file in place, and the sprint's review
branch carries it like any other commit. Tests pin the commit, its record,
the placement, and the commit surviving a story revert and a review-stack
rebuild.
