title: The liaison can share a file with the team for a story
status: active
covers: ["s120/AC1", "s120/AC4", "s120/AC5"]
---

The liaison can hand the team a file, such as a mock or a spec, for a named
story with one command. The command works whether the team is running,
waiting or stopped, and it never disturbs a running step. The file is
committed in one runner commit into the design docs under the story's id,
and the story file records its path and SHA-256. The command prints where
the file will land. It refuses an unknown story, an unusable file name, and
an empty, unreadable or oversized file, and then nothing is written. Sharing
the same name again replaces the file and its recorded hash. The skill and the
liaison's template explain the command. Tests pin the copy, the story-file
entry, the single commit and the refusal of an unknown story.
