---
id: REQ-111
title: A done stop runs house-rules on the step's changed Python and refuses only on a new failure
status: active
covers: ["s157/AC1"]
---

When a role hands off `done` and the step changed Python files, the stop's lint
check runs house-rules on those files, in each targeted root
(`agile-team/runner` and `unattended/runner`). A new failing finding refuses
the stop, and the refusal names the file, the line and the rule. Findings in
the baseline, stale baseline entries and warnings let the stop through.
