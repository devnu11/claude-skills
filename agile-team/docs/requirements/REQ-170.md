---
id: REQ-170
title: A sprint start drops the stack entries main already has
status: active
covers: ["s163/AC4"]
---

At every `start_sprint`, before the switch check, the runner drops each
upstream stack entry whose branch head main already contains, or whose
commits main has as patch-equivalent copies (`git cherry` lists no `+`). The
switch's "ahead of the target" check uses the same `git cherry` rule, so a
sprint merged by rebase needs no hand edit of the run state.
