---
id: REQ-224
title: An END boundary whose target holds only part of the sprint still pushes the replay and opens its PR
status: active
covers: ["s183/AC3"]
---

When the target does not contain the replayed HEAD (it holds only part of
the sprint, or holds commits only as patches), `push-replayed` works as it
did before. A changed head is pushed to the next `-r<k>` branch and gets a
ready PR. An unchanged head makes the sprint's draft PR ready.
