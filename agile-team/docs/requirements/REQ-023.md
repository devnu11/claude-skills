---
id: REQ-023
title: An unattended agile-team job records why the run stopped
status: active
covers: ["s128/AC3", "s128/AC4"]
---

When an agile-team run ends, the unattended job records why: the run's status
(done, blocked, idle, …) and its reason, or the halt that stopped it. A bare
`done` is not enough. The runner stores the reason too: the PO's note when it
declares the run done or blocked, or the last hand-over line when nothing more
can move. Tests pin the job's stop reason.
