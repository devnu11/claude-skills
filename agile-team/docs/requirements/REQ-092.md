id: REQ-092
title: Upstream lists the team commits already in the target and judges any head for one-sided paths
status: active
covers: ["s153/AC1"]
---
`Upstream` can say which team commits (between the target and a given old
tip) already have their patch in the target. It can also report the paths
that only one side touched but that changed, for any head it is given, not
only the checked-out HEAD. A clean rebase is judged exactly as before.
