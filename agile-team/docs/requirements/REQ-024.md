---
id: REQ-024
title: Tests read the real clock only through the clock helpers
status: active
covers: ["s129/AC1", "s129/AC2"]
---

No test depends on when it runs. Unit tests use the fake clock. Page tests
under node run with the page's clock frozen: at the fixture's time, at the
served snapshot's time, or at a time the test names. e2e tests that talk to a
real process read the real clock only through the test clock helpers. A test
scans the test tree and fails on any other real-clock read (`Date.now()`,
`time.time()`, `time.monotonic()` and their kin).
