---
id: REQ-200
title: Roles and runner commands hide the runner's venv by one rule and keep the rest of the environment
status: active
covers: ["s174/AC2"]
---

Apart from the runner's venv, a command the runner runs gets the runner's
environment unchanged: `HOME`, the rest of `PATH` in its order, and every
other variable, plus what the runner adds on purpose (`COVERAGE_FILE`, and
the tally plugin's variables inside a stage). The PATH filter is one
function, shared by role steps and runner commands, so a command that passes
in a role's shell finds the same tools at the gate. Roles still get
`VIRTUAL_ENV=""` because their environment is merged into the inherited one.
