---
id: REQ-188
title: The house-rules end-to-end checks build their venv in their scratch repo and leave the checkout's venv as it was
status: active
covers: ["s168/AC1"]
---

The s157 house-rules end-to-end checks run house-rules through uv in a
scratch repo. uv builds that run's venv inside the scratch repo, so the
checkout's (or story worktree's) `house-rules/runner/.venv` is never created
or changed by the suite. Whether or not that venv existed before, every
console script in it afterwards starts its own python, and house-rules' own
suite and `house-rules check` run from it.
