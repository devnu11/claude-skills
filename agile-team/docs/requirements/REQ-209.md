---
id: REQ-209
title: A story rebase step's git that would move another branch is refused before it runs, naming the step's own branch
status: active
covers: ["s176/AC1"]
---

In a story rebase step's worktree, a git command that would move a local
branch other than the step's own rebase branch is refused before it runs.
That includes creating or resetting another branch with `git checkout -B`,
`-b` or `git switch -C`, `-c`, rebasing another branch with `git rebase
<onto> <other>`, and `git reset`, `git rebase`, `git commit` or `git
cherry-pick` while HEAD is on another branch, or on a branch an earlier
checkout in the same command may have moved it to. The refusal names the one
branch the step may move. `branch`, `update-ref` and `symbolic-ref` stay
refused as before.
