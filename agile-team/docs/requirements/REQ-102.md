---
id: REQ-102
title: An escape form that gets through is fixed in the OS sandbox settings
status: active
covers: ["s12/AC2"]
---

If any escape form reads the file inside the Proxy's sandbox, this story fixes it, and
the fix goes in the sandbox settings the runner builds, not in the Bash text check. The
leaking form's test then passes, and a unit test pins the changed settings. A leak that
the settings cannot express goes back to design with the evidence instead of being
patched by guesswork.
