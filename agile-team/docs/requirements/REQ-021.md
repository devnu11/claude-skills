---
id: REQ-021
title: Under until-blocker a sprint end never stops the team
status: active
covers: ["s128/AC1", "s128/AC4"]
---

With cadence `until-blocker`, when a sprint ends and the backlog has ready
stories, the runner hands over to the product owner and asks it to start the
next sprint. It asks again if the PO ends its turn without starting one, up to
a cap, and then stops the run as blocked and tells the human. The PO can't
declare the run done or blocked while ready stories exist. A pull request
waiting for review or merge, or a runner re-pin, never holds the next sprint.
A resume keeps the run's cadence. Tests pin the hand-over.
