---
id: REQ-073
title: Functions are named with verbs, and only accessor properties are nouns
status: active
covers: ["s57/AC6"]
---
Every function and method name is a verb. Only an accessor property has a
noun name. A plain function that only returns a value and has no better verb
is named `get_<noun>`. `boundary_data` becomes `get_boundary_fields`, and
`boundary_event` goes. The follow-up quality stories sweep the rest of the
runner by module.
