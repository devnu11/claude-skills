---
id: REQ-032
title: The full checks judge a check from its test run, with at most two parameters per function
status: active
covers: ["s132/AC1", "s132/AC2"]
---

The full checks turn each command's run into a result through one place that
takes the check and the test run the command produced. How a check is judged
(the coverage it needs, the runner it uses) lives on one object, so no
function on that path takes more than two parameters, as the house rules ask.
Every check is judged exactly as before: the same pass or fail, the same
reason, the same output tail and the same pending-test counts. The existing
full-check tests pass without any change.
