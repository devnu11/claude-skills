---
id: REQ-128
title: agile-team requirements log prints the change history from the git trailers as JSON
status: active
covers: ["s2/AC6"]
---

`agile-team requirements log` reads the `Requirement-Changed` trailers from
git and prints them as one JSON list, oldest first. Each entry gives the
requirement id, the reason, the commit sha and the date. With no trailers
it prints an empty list.
