---
id: REQ-257
title: A gate fix step's brief names the commit the gate ran on, the story's worktree, and the commits since
status: active
covers: ["s187/AC1"]
---

The brief of a gate fix step, as the `step-start` event records it, names
the commit the failing gate ran on (its short sha) and the path of the tree
the step works in: the story's worktree, or the main checkout when the run
has no story branches. It says whether that tree's head is still the gated
commit. When the head has moved, it gives the new head and lists every
commit after the gated one (short sha and subject, oldest first); when the
head no longer contains the gated commit, it says so instead. It tells the
role to run every command in that tree.
