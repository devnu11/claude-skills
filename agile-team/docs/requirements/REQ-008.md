---
id: REQ-008
title: Every role can read a story's shared files, and the design names them
status: active
covers: ["s120/AC2", "s120/AC4"]
---

A story's shared files are readable by every role, the Customer Proxy
included, which gets read access to exactly those files. The architect's and
the Customer Proxy's briefs list them with their hashes. A story with shared
files leaves design only when its design file names each one.
