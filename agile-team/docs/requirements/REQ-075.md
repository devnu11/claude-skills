---
id: REQ-075
title: Names are whole words, and no variable only renames another
status: active
covers: ["s57/AC8", "s57/AC9"]
---
Names are whole words, not single letters or abbreviations. An acronym is
allowed only when it is better known than its expansion. A local that only
renames something else, such as `rt = self.runtime`, goes. The code uses the
original directly. A local is kept only when it makes the code much easier
to read, and then it gets a whole-word name, such as `boundary` and not `b`.
The sites the story names follow this. The follow-up quality stories apply
it to the rest of the runner.
