---
id: REQ-174
title: Closing a pull request GitHub already merged is not an error, and it gets no note
status: active
covers: ["s166/AC1"]
---

Wherever the runner closes a pull request (a landed story's PR, a superseded
story PR, a superseded sprint PR), a PR that GitHub shows as merged counts as
closed. So a landing whose push merged its story PR completes: the story is
recorded as landed and the sprint PR is open. The runner reads the PR's state
to decide, not gh's message text. Any other failure to close is reported as
before. The note is posted only to a PR that was still open; a merged PR gets
none.
