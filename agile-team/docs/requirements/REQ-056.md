id: REQ-056
title: Every role's prompt holds the repo's .claude/CLAUDE.md before the charter, with only in-repo imports inlined
status: active
covers: ["s142/AC1", "s142/AC4"]
---
Every role's system prompt, the PO's included, has a "Repo instructions"
section. It holds the text of the repo's `.claude/CLAUDE.md` and comes right
before the "Repo charter" (`.team/CLAUDE.md`). An `@path` import that points
inside the repo is replaced by that file's text, and each file appears at most
once. An import that points outside the repo, such as `@~/.claude/...`, is
replaced by a one-line note saying it was left out. When the file is missing,
the prompt has no such section. Tests pin the order, an inlined import, a
left-out import with its note, and the missing file.
