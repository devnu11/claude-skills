---
id: REQ-006
title: The dashboard fixture is rebuilt from its source by one command
status: active
covers: ["s116/AC1", "s116/AC2", "s116/AC3"]
---

The dashboard's sample snapshot is built entirely from committed source data
by one command, and the snapshot already in place never affects the result.
The build keeps every curated entry. Running it twice gives the same bytes,
and the test suite fails when the committed snapshot differs from a fresh
build. The script and the dashboard docs tell contributors to change the
source and rebuild, never to edit the snapshot by hand.
