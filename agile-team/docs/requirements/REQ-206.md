id: REQ-206
title: A landing error's hand-over and hold carry its message, and a gh failure with no readable text names its call
status: active
covers: ["s175/AC3"]
---

The PO's hand-over and the story's hold for a landing error both carry the
error's message. A gh call can fail with an empty body or a JSON body, as
GitHub's rate-limit reply `{` did, or it can return output that is not the
JSON the runner expected. Then the message names the command that ran, its
exit code, the HTTP status when gh printed one, and the raw output trimmed to
one line. The reader can tell a rate limit from a refused push.
