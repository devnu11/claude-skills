---
id: REQ-125
title: Each requirement change's reason is a Requirement-Changed trailer on the step's own commit
status: active
covers: ["s2/AC3"]
---

The commit that lands a requirement change ends with one trailer line per
requirement, `Requirement-Changed: REQ-003: <why>`, in the same trailer
block as the co-author line, so git reads them as trailers. Git is the only
record of the reasons. The runner keeps no other store.
