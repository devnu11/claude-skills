---
id: REQ-026
title: No test shares module-level state with another test
status: active
covers: ["s130/AC1", "s130/AC2"]
---

A test gets everything it needs from its own fixtures and arguments. Test
helpers take the config they work on as a parameter. They never read it from a
module-level list or dict that a fixture or an earlier test filled in. A scan of
every Python file under `agile-team/runner/tests/` fails when code inside a
function writes to a module-level mutable value (a list, dict, set and the
like) or rebinds a module-level name with `global`. The failure names the file,
the line and the name.
