title: The escape tests run wherever the Proxy has an OS sandbox, listed in one table
status: active
covers: ["s12/AC3"]
---

The escape tests are skipped, with a reason that names s60, on every platform outside
one table of platforms where the Proxy has an OS sandbox. Today the table holds macOS.
When s60 gives the Proxy a Linux sandbox, adding Linux to that table is the only change
needed for the same tests to run there.
