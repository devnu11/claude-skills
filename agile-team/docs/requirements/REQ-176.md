---
id: REQ-176
title: The page's CSS checks scan the dashboard page once, in time linear in its length
status: active
covers: ["s167/AC1", "s167/AC3"]
---

The flow-page check and the tool-box checks that read a CSS rule scan the
dashboard page so that each brace-free stretch is read once, not once per
position in it. Each finishes in under 0.02 s on an idle machine, and doubling
part of the page does not double its time, so a busy machine does not push it
past the 1 s unit limit.
