---
id: REQ-204
title: A stage that raises records the error's text and the call that raised it, never an earlier command
status: active
covers: ["s175/AC1"]
---

When a runner stage, `story.land` included, closes on an exception, its
`runner-stage` event carries the exception's first line in a new `error`
field, at most 500 characters, beside `raised`. Its `detail` and `code` name
the git or gh call that raised, with its command line and exit code. They
never name an earlier command whose failure the runner tolerated, or any
command that ran before the call that raised. When no command raised the
exception, `detail` is empty and `code` is null.
