---
id: REQ-243
title: The PO is told a sprint PR is ready to merge once, when the END boundary has finished
status: active
covers: ["s188/AC2"]
---

The `ci_green` hand-over ("ready to merge") reaches the PO only when the END
boundary finishes with green CI, and it names the PR the boundary finished
with. A green CI stage partway through the boundary tells the PO nothing, so
no ready message names a PR that the runner then closes.
