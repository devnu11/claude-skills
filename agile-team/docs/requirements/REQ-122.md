---
id: REQ-122
title: The re-pin's config check and the runner that replaces itself get the run's repo and key home before the subcommand
status: active
covers: ["s158/AC2"]
---

The self re-pin runs the new pin's `config check`, and then replaces its own
process with `start --resume`, either on the new pin or, after a rollback, on
the old one. Both commands get the run's `--repo` and, when the run has one,
its `--home`. These options go before the subcommand, where the CLI accepts
them, so the CLI parses both commands and the new process resumes the run.
