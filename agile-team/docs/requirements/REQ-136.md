---
id: REQ-136
title: land is a built-in runner step after acceptance, and a story is done only when land passes
status: active
covers: ["s159/AC2.3"]
---

`land` is a pipeline step after `acceptance` that no config can remove. It is
a checkpoint run by the runner, so no PO `run_role` can target it. A pass at
acceptance, or a Manager `advance` from it, moves the story to `land`, never
straight to done. `land` runs the full checks on the merge. If they are red,
the merge is discarded, the sprint branch never moves, and the story goes
back to its developer with the failures. The story is done only when `land`
passes, and `depends_on` and the PO's renewal key on that.
