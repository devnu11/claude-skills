---
id: REQ-108
title: A unit test that reaches the real OS in fixture setup fails alone
status: active
covers: ["s154/AC1", "s154/AC4"]
---

When a unit test's fixture setup reaches the real OS, even inside one of
pytest's own fixtures such as `tmp_path`, that test fails at setup with the OS
guard's `RealOsCall` message (`unit test reached the real OS: …`). The tests
after it in the same pytest worker, unit and e2e, run and pass as they would
alone; none errors with a bare `AssertionError` at setup. An end-to-end test
runs such a test, then a clean unit test and an e2e test in one worker, and
shows the other two pass.
