---
id: REQ-134
title: The story branch prefix is validated and kept apart from the sprint prefix, and the push guard allows only the two
status: active
covers: ["s159/AC1.5"]
---

`[upstream] story_prefix` (default `team/story-`) must be a safe branch
prefix. It must differ from `prefix`, and neither may start with the other.
The push guard accepts a branch under either prefix. It never pushes main or
the checked-out branch, and its refusal names both prefixes.
