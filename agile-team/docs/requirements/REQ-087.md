title: The DevOps role file says DevOps owns sprint-end rebase conflicts and gives the sprint-end order
status: active
covers: ["s151/AC6.5"]
---
The built-in DevOps role file says DevOps owns sprint-end rebase conflicts
and gives the sprint end's order: push the team branch as it is, open or
reuse the PR, wait for green CI, rebase, push again to the same PR. The
liaison adds the same text to the project's `.team/roles/devops.md`, which
no role can write.
