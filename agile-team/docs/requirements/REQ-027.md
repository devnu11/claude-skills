id: REQ-027
title: The runner's test suite runs in random order and passes in any order
status: active
covers: ["s130/AC3"]
---

The agile-team runner's test suite runs its tests in a random order by default
(pytest-randomly, a dev dependency), and every run prints the seed it used.
`-p no:randomly` turns the shuffle off and `--randomly-seed=N` replays an
order. The suite passes in any order. Evidence is three green full-suite runs
in a row under random order.
