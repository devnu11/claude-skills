Nothing about the sprint end changes for picks. Picked commits and their
reverts are pushed as they are, with the rest of the sprint's history.

There is one test for each pick AC. `SKILL.md`, `reference/protocol.md` (under
"Sprint boundaries") and the README row describe picks. The PO's role file
says when to accept a pick and when to ask for one: for a change the team
needs now, never for whole sprints of work. It also says that a forced pick
is the human's and can't be reverted.
