id: REQ-118
title: The next-sprint hand-over still lists the ready Product Backlog stories
status: active
covers: ["s156/AC4", "s156/AC7"]
---

Under `until-blocker`, when a sprint is complete and its end boundary has
finished, the runner hands the PO `next_sprint` with up to 5 ready Product
Backlog stories (and a count of the rest) and asks it to start the next sprint,
as before. After 3 such hand-overs with no new sprint, the run is set `blocked`.
A test pins this.
