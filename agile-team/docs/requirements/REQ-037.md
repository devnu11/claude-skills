---
id: REQ-037
title: The liaison's story drafts are checked and queued, never committed by the command
status: active
covers: ["s135/AC1", "s135/AC6"]
---

The liaison writes a story as a Markdown file: a frontmatter `title`, the
`acceptance` list (each AC with `id`, `text` and `environment`), an optional
`depends_on`, and the user story as the body. `agile-team story new <file>
--approved-by human|none`, with an optional `--sprint current|next|backlog`
and `--after <story>`, checks the file the same way story files are checked.
That includes that each AC's environment is configured and that `depends_on`
names known stories.

A bad file is refused with every problem it has, one line each, and nothing
is queued. A good file is queued for the runner under
`.team/run/liaison/stories/`, and the command prints the queue id. The
command never writes `.team/stories/` and never commits. Tests pin a good
file queued and a bad file refused with every reason.
