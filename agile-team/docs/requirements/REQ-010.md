id: REQ-010
title: The retired-Scribe tests check whole words and every role in the fixture
status: active
covers: ["s117/AC1", "s117/AC2"]
---

The test that keeps the retired Scribe out of the built-in role files matches
"scribe" only as a whole word, so a role file may say "describe" or
"prescribe". The test that keeps the Scribe out of the dashboard fixture
checks every place the fixture names a role: the roles list and the role on
each event, ledger entry and step. It also checks that it found real roles, so
it cannot pass on an empty list.
