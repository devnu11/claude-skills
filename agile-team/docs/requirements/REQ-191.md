---
id: REQ-191
title: The design gate bounces a new requirement id that other work already holds, naming the holder
status: active
covers: ["s178/AC2"]
---

The design gate bounces a design that adds a requirement file whose id is
already used on the sprint head, used by another open story, or reserved by
another open story. Each reason names the id and where it is held
(`REQ-174 is already used by s166`), and the retry brief offers a free id.
