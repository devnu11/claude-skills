---
id: REQ-033
title: A shared path is resolved before it is checked, and only paths in the design folder are read
status: active
covers: ["s133/AC1", "s133/AC4"]
---

Every path in a story's list of shared files is resolved first. That means
`.` and `..`, symlinks and absolute paths are all worked out before the path
is checked. A path passes only when it already is its own resolved form and
the file sits directly in the design folder. Any other path is refused with
a reason that names where it resolves to, and the story holds at acceptance.
Only the paths that pass reach the Customer Proxy's read access and its
sandbox, its brief and the acceptance hash check. Tests pin a `..` path, an
absolute path and a symlink out of the folder.
