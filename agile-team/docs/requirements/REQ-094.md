---
id: REQ-094
title: A sprint-end rebase can be redone in a scratch worktree that never touches the team checkout, then judged and dropped
status: active
covers: ["s153/AC3", "s153/AC4", "s153/AC5"]
---
`ScratchRebase.prepare` starts the same rebase the sprint end ran, keeping
commits that become empty, in a git worktree under `.team/run/rebase` on the
branch `agile-team/rebase-sprint-<N>`. It replaces any leftover worktree.
The team checkout's HEAD, branch and index never change. `drop` removes the
worktree and its branch. `refusal` gives the first problem with the result,
in the order the s151 design lists (R16), or nothing when the result is
exactly the team's commits rebased.
