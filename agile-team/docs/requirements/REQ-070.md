title: The bootstrap quality pass is split into small stories by module, each checked against the house rules
status: active
covers: ["s57/AC1", "s57/AC2"]
---
The architect lists the runner modules the quality pass covers and splits them
into small follow-up stories, one per module group. Each follow-up checks its
modules against the written rules: SOLID and KISS, DRY but AHA, no boolean
parameters, short functions with at most two parameters (constructors and
factories excepted), no code in the global scope, tables over branching, the
naming rules, the repo's `.claude/CLAUDE.md` and the team charter. The story
that sets the rules applies them to the code it changes.
