---
id: REQ-084
title: DevOps resolves the conflict in a scratch worktree, never merging or squashing, and the full checks run there
status: active
covers: ["s151/AC6.2"]
---
The DevOps step works in a git worktree outside the team's working tree, on
a scratch branch, and may write and run changing git commands only there. It
resolves the conflicting files keeping both sides' intent. The runner refuses
its result when the rebase is unfinished, the worktree is dirty, the branch
has a merge commit, or its commits are not the team branch's commits rebased
(one added, dropped, squashed, reordered or reworded), or a path only one
side touched changed. The full checks run in the worktree, never in the
team's checkout.
