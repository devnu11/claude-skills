---
id: REQ-088
title: The sprint start rebases the team branch onto main with the end's hash remapping, and leaves a current branch alone
status: active
covers: ["s152/AC1.1"]
---
At every sprint start the boundary's `sync` rebases the team branch onto
`<remote>/<branch>` with the same rebase and the same remapping of every
recorded hash as the sprint end's rebase. A team branch already on the
target is left alone: no rebase runs and no hash changes. A conflict is
aborted, leaves the team branch unchanged, holds nothing and is reported to
the liaison.
