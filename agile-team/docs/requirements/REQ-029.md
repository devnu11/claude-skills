---
id: REQ-029
title: A pass record whose commit fails holds the gate and leaves the tree clean
status: active
covers: ["s131/AC2", "s131/AC3"]
---

If the commit of a pass record fails, the gate does not pass. The story stays
at its step (`ops-review`) with no round counted. The story file goes back to
its old text and is not staged, so the working tree is clean. The gate event
and the PO's hand-over give the git error as the reason. A test fakes the
commit failure and checks all of this.
