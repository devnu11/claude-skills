---
id: REQ-113
title: The house-rules baseline only shrinks, in the commit of the step that fixed a finding
status: active
covers: ["s157/AC4"]
---

When a step that changes Python fixes a baselined finding, the finding's entry
leaves `.house-rules-baseline.json` in that step's commit. Every role that
changes Python may write the file. Any edit a step makes to the baseline is
replaced by the committed baseline shrunk by what is fixed, so a step that
changes Python cannot add or raise an entry.
