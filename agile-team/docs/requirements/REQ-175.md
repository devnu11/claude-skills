---
id: REQ-175
title: A running landing or boundary stage holds no budget reserve
status: active
covers: ["s166/AC2"]
---

When the scheduler checks the budget before it starts a step, it reserves
only for running work that has a role and a model. A landing or a boundary
stage, which the runner runs itself, adds nothing. So any step the scheduler
starts beside a landing or a boundary stage (a story's role step, the
Manager's review) starts or waits on the budget as usual, and the run never
halts with an unknown-role error.
