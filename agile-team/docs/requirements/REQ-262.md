---
id: REQ-262
title: A config change committed on the main checkout is used from the next intake, PO tool call, gate and role step, without a restart
status: active
covers: ["s173/AC1"]
---

The runner follows the `.agile-team.toml` committed at the main checkout's
`HEAD`. After a commit changes it (a storyless DevOps step, a landing, or a
commit the human made and `accept-checkout` kept), the runner takes the new
config at its next safe point, between steps. It needs no stop and no
`start --resume`.

From then on:

- a story `new` or `amend` the runner onboards checks environment names
  against the new config, so an amendment naming an acceptance environment
  the commit added is accepted;
- every PO tool call reads the new config;
- every gate and stop check runs the new config's commands;
- every role step starts with the new config's roles, providers and
  command timeout.

`[team] auth`, `key_file`, `cadence` and `[health] beat_s` still take effect
only at the next start.
