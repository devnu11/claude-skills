---
id: REQ-185
title: An idle run writes few checkout-guard events and uses little CPU
status: active
covers: ["s164/AC2"]
---

Over ten minutes of a run with one step running, `events.jsonl` gains no
more `checkout.guard` events than 120 (ten minutes / `POLL_S`) plus the
other events written in that window, and the runner process averages under
10% of one CPU over its life. Checked by hand on a run started after the
fix, with `ps -o pcpu -p $(cat .team/run/runner.pid)` and a count of events
by `at` in `events.jsonl`.
