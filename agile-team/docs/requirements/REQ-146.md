id: REQ-146
title: Each story's state records its branch, base, replays, last pushed head, PR and landing
status: active
covers: ["s159/AC2.15"]
---

Each story's state records its branch, its base sha and its replay count. It
also records its last pushed head (absent before the first push, and saved
only once a push succeeds), its draft PR and, for a landing, the merge, the
pushed sha and the sprint PR. An older `state.json` without these fields
loads.
