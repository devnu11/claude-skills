---
id: REQ-072
title: Events are built by one pure constructor per kind, and the caller emits them
status: active
covers: ["s57/AC5"]
---
The runner builds an event through `event_factory`, which has one constructor
per event kind. A constructor only returns the event and never writes it, so
it can be tested without an event log. The caller then emits the event
itself. No helper both builds and emits an event. The boundary events and the
PO tool and recovery events are built this way, and the event data stays the
same as before.
