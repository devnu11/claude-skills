id: REQ-046
title: "The boundary's bounce texts for a failing suite and a coverage shortfall stay the same"
status: active
covers: ["s73/AC2"]
---
At the sprint boundary, a failing suite bounces as `coverage failed (exit N):
<coverage command>` with the output's tail. A coverage shortfall bounces with
`coverage X% is below Y%`, both when the run exited 0 and when the coverage
tool stopped it with no failing test. A non-zero exit never passes. A test
pins each text.
