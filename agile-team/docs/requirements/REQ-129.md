title: The architect's and the PO's role files and protocol.md describe requirement change tracking
status: active
covers: ["s2/AC7"]
---

The architect's role file says to give a reason for each changed or retired
requirement in the handoff's `requirement_changes`. The PO's role file says
that `affected_done_stories` calls for a follow-up story, which the PO asks
the liaison for. `reference/protocol.md` documents the handoff field, the
trailer format, the `requirement-changed` event and the `requirements log`
command.
