The built-in code-reviewer role file's checklist and the implementation
guidelines state the verb rule, the whole-words rule, the no-alias-variables
rule and the build-then-emit rule for events. The reviewer applies them as a
judgement call; no automatic check enforces them. The repo's
`.claude/CLAUDE.md` gets the same naming rules. That directory is the
human's, so the liaison makes that edit, not the team.
