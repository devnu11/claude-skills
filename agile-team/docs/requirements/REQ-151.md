These are gone: `.team/pending-tests.json`, its CI step and path filter, the
`pending-tests` command, and the gitignore line onboarding wrote for it. A
story's red tests live only on its branch. The tests gate no longer requires
new tests to fail, and its red-test stages are gone. A tests step whose new
tests already pass hands off `done` like any other, with no claim. Tests
still have to pass at implement and at `land`.
