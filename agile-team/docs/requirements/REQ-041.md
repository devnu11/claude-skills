id: REQ-041
title: The PO schedules stories and asks the liaison for new ones; only the runner writes story files
status: active
covers: ["s135/AC5", "s135/AC6"]
---

The PO can't write or edit story files: the guard refuses them, and a change
there is quarantined, whatever its role files say. The PO's `open_story` tool
is gone. When the team finds a bug it couldn't fix in its own turns, the PO
calls `request_story(summary, evidence)`. The liaison gets a `story-request`
message with the evidence: the story and step, the failing output and the
files. Tests pin the guard refusing a story file and `request_story`
reaching the liaison.
