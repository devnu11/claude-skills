---
id: REQ-165
title: Unattended posts one waiting notice and never idle-stops a waiting run, and reads the reset from status limit
status: active
covers: ["s159/AC11.6"]
---

When a run's heartbeat has `waiting`, unattended posts one `waiting` notice
with the reason. It posts it again only after the run has made progress. A
waiting heartbeat doesn't start the idle stop, and `--idle-stop` still
applies to a heartbeat without `waiting`. Unattended reads the reset time
from agile-team's status `limit`, and still from `blocked`, which older
runners send.
