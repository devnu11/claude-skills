---
id: REQ-034
title: A bad share request file is refused once, with its reason, and never crashes the router
status: active
covers: ["s133/AC2", "s133/AC4"]
---

When the runner loads a queued share request, it checks that the file is a
JSON object with every field present and of the right type: the story, the
name, the hash and the data as text, and the time as a number. It also checks
that the data is valid base64 and matches its hash. A request that fails is
recorded as settled and refused, with the reason that names the file and the
problem. One `share` event is recorded, and nothing is written or committed.
The request is never tried again, and nothing on this path raises. Tests pin
each bad field type.
