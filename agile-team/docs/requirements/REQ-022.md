---
id: REQ-022
title: The runner re-pins itself to the checked head at a sprint end and rolls back on failure
status: active
covers: ["s128/AC2", "s128/AC4"]
---

When a pinned runner's end-of-sprint full check passes, the runner pins the
head it checked and keeps the old pin as `runner-pin.prev`. It checks the
config under the new pin and replaces its own process with the new pin's
`start --resume`, so an unattended job never sees an exit. If the pin, the
check, the exec or the new runner's first start fails, it restores the old pin,
carries on and tells the human. Each re-pin is logged as a `runner-repin` event
with the old and new commit, and the dashboard header shows the pinned commit.
A failing check never re-pins. Tests pin the re-pin, the rollback and the
event.
