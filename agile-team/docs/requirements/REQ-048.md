title: The dashboard fixture script runs no code at import and rebuilds the same fixture
status: active
covers: ["s56/AC1"]
---
`agile-team/runner/scripts/make_dashboard_fixture.py` holds only its docstring,
imports, constants, definitions and an `if __name__ == "__main__":` guard that
calls `main`. Importing it runs nothing. The fixture it writes stays
byte-identical to the committed `snapshot.json`, and a test checks both.
