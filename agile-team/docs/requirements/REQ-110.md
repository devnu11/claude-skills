id: REQ-110
title: A gate's kept result records each failing test's first error lines, shown in the brief and on the dashboard
status: active
covers: ["s154/AC3", "s154/AC4"]
---

Each test run a gate keeps in `.team/run/results/<story>/<name>.json` records,
for every failing or erroring test in its JUnit report, the test id and its
first error lines. The brief's `## Runner results` section lists the first ten
failing tests with those lines and counts the rest. A gate event that does not
pass carries the same list, capped at ten, and the dashboard shows it under the
gate's reason. Tests pin the parsing, the kept result, the brief, the event and
the dashboard entry.
