The built-in code-reviewer role file has a checklist item: no code at a
module's top level, only the docstring, imports, constants, definitions and a
`__main__` guard calling one entry function. The implementation guidelines
say the same. The repo's `.claude/CLAUDE.md` "Python runners" section gets the
same rule. That directory is the human's, so the liaison makes that edit, not
the team.
