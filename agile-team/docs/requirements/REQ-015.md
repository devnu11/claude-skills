---
id: REQ-015
title: Only a green CI run the runner read on the pushed head makes a sprint done
status: active
covers: ["s111/AC1", "s111/AC6"]
---

A sprint boundary ends as done only when every required check on the review
PR's head commit has a green run, and the runner itself read it from GitHub.
When the repo marks no check as required, every check counts. A run on another
commit is ignored, and a re-run counts only when it is green and on the same
commit. No tool argument, note or answer can mark a sprint done. Tests pin a
green re-run on the same commit (accepted) and a run on another commit
(ignored).
