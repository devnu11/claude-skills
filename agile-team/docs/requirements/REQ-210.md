---
id: REQ-210
title: The git a story rebase needs still runs in its step
status: active
covers: ["s176/AC2"]
---

A story rebase step can still run `git rebase --continue`, `--abort` and
`--skip`, `git add`, `git checkout -- <file>`, and the read-only git
commands. It can also run `git reset` while HEAD is on its rebase branch or
detached, and `git checkout -B` on its own rebase branch.
