---
id: REQ-222
title: An END boundary whose replayed head the target already contains closes the sprint as shipped
status: active
covers: ["s183/AC1"]
---

At the END boundary's `push-replayed` stage, the runner fetches the remote
and checks whether the target branch already contains the replayed HEAD.
If it does, the runner pushes no `-r<k>` branch, creates no pull request
and marks none ready. It closes the sprint's recorded PR only when that PR
is still open, and records it as closed. The boundary then finishes. Its
`done` event and the PO's sprint-end hand-over both say that the sprint is
already on the target at that sha. The event carries no CI verdict, so the
PO is not told to have the PR merged.
