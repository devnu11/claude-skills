---
id: REQ-233
title: A prepare command that builds its own venv builds and uses that venv, not the runner's
status: active
covers: ["s186/AC2"]
---

A prepare command that makes its own venv (`uv venv` then `uv pip install`)
installs into that venv, and `uv` prints no "VIRTUAL_ENV does not match"
warning while doing so. A start command whose environment lists that venv's
`bin` directory runs that venv's `python`: `sys.prefix` is the environment's
venv, never the runner's.
