---
id: REQ-259
title: The Manager's repeated-setback context lists each gate fix round with the gated commit, each fix's commit and the worktree head
status: active
covers: ["s187/AC3"]
---

When a story escalates to the Manager for a repeated setback, the
`repeated_setback` entry of the Manager's runner context lists the story's
gate fix rounds. Each round gives the commit the gate ran on and, for each
fix step in it, the role, the fix's commit (or "none") and the head of the
story's tree after that step. Every gate, route and escalation event the
runner writes for a story step also carries the head of the tree it judged,
and the context's events include the story's `gate-fix` events. So a ruling
that the gate ran on a stale commit can be checked against them.
