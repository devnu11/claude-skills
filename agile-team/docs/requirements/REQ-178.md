id: REQ-178
title: No runner function waives a naming rule because tests or a design chose its name
status: active
covers: ["s161/AC1"]
---

No function in `agile-team/runner` carries a `# house-rules: allow` comment
whose reason is that tests or a design fixed its name. Each such function is
renamed to pass the house rules. Its first word is a verb, and a
no-argument query is a property. A real verb that house-rules' table lacks
goes into the repo's `.house-rules.toml` `verbs` instead. Callers follow the
rename and behaviour is unchanged. A query that became a property is read
without `()`.
