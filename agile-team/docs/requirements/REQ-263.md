---
id: REQ-263
title: A running step keeps the config it started with, and one config event records each new committed config with its sha and changed sections
status: active
covers: ["s173/AC2"]
---

A role step that is running when a config change is taken keeps the config
it started with until it ends. This holds for its stop checks and its gate
too. The new config applies from the next step, gate or tool call. The
runner never takes a change while a step runs on the main checkout, while
git moves the main checkout, or while a boundary stage runs.

Each new committed config is recorded once, in one `config` event. The event
gives the commit that last changed the file (`sha`), the blob id, and the
names of the sections whose values changed. A commit that leaves the file's
content as it was records nothing.
