---
id: REQ-104
title: A story-file hold tells the PO which action it may take, never to edit the file
status: active
covers: ["s138/AC1", "s138/AC3"]
---

When the runner holds a story because its file has problems, the text the PO gets
says that only the runner writes story files. It names the fixes the PO may make:
if the config lost the environment, route the fix to devops and continue the
story once it is in; if the ACs are wrong, ask the human, and the liaison sends
new ACs with `story amend`. Any other hold text that reaches a role about a story
file follows the same rule. A test checks that none of these texts tells a role
to edit a story file by hand.
