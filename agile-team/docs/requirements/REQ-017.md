---
id: REQ-017
title: A failure that main also has doesn't stop the team, and the sprint isn't done
status: active
covers: ["s111/AC3", "s111/AC6"]
---

When a check fails where our code ran, the runner looks at the same check on
main's head. If it fails there on the same job and step, the failure is
classed `main_broken`. A bug story for it is recorded with `record_ci_bug` and
goes first in the next sprint. The sprint ends as "ended, CI blocked by main":
not done, with its PR unmerged, and the team may start the next sprint. At the
next sprint end the PR's CI is read again as usual. Tests pin that
`main_broken` lets the next sprint start and leaves the sprint not done.
