---
id: REQ-199
title: A command the runner runs itself gets no VIRTUAL_ENV and no runner venv bin on its PATH
status: active
covers: ["s174/AC1"]
---

Every configured command the runner runs itself (the gate's test, coverage
and named-test commands, the stop checks' fixers and lint, the house-rules
gate and the sprint boundary's full check) starts with no `VIRTUAL_ENV`
variable at all, and with a `PATH` that has none of the directories inside
the runner process's own venv. This holds with and without the tally plugin,
and for the retry without it. So `uv run` in such a command prints no
"VIRTUAL_ENV does not match" warning, and a bare tool name finds the repo's
tool, not the runner's.
