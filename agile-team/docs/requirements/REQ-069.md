---
id: REQ-069
title: A requirement can trace an AC whose id contains dots
status: active
covers: ["s143/AC1", "s143/AC2", "s143/AC3"]
---

A requirement's `covers` reference is a story id (`s` and digits), a slash and
an AC id. The AC id starts with a letter and goes on with letters, digits,
underscores, hyphens and dots, so `s141/AC1.1` is a valid reference and the
design gate does not report it as a bad reference. Every reference that was
valid before stays valid and names the same story and AC. A reference with no
story id, no AC id, or any other character is still refused as a bad
reference. A test pins the dotted form accepted and each malformed form
refused.
