---
id: REQ-114
title: House-rules reaches the team only through the repo's toolchain config
status: active
covers: ["s157/AC5"]
---

The house-rules commands live in the repo's `[toolchain]` (and
`[toolchain.files]`) in `.agile-team.toml`. The runner holds nothing specific
to house-rules, so a repo whose config does not name it runs none of this.
