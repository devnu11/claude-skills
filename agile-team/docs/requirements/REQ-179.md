---
id: REQ-179
title: The query-property check sees tuple assignments and changes made through the class's own methods
status: active
covers: ["s161/AC1"]
---

house-rules' query-property check counts a tuple or list assignment to an
attribute of `self` as a change. It also counts a call on `self` to a method
of the same class that changes `self`, however many calls deep. A method
that changes state this way is no longer reported as a query. A method that
only reads is reported as before.
