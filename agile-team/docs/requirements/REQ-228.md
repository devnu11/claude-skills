id: REQ-228
title: The next-sprint hand-over says how a run is ended on purpose
status: active
covers: ["s184/AC2"]
---

Under cadence `until-blocker`, the hand-over that asks the PO to start the next
sprint still tells it to start one. It also says that ready Product Backlog
stories alone are no reason to notify `done` or `blocked`. A run ends on purpose
only when the human or the liaison says so. The PO then notifies `done`, quoting
them. Otherwise the liaison resumes the run with `--cadence sprint`. The rule that
an `until-blocker` run keeps going while something can move does not change.
