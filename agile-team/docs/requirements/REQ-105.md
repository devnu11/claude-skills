---
id: REQ-105
title: A start refused for a bad depends_on names who changes it and the commands to use
status: active
covers: ["s138/AC2", "s138/AC3"]
---

When `agile-team start` is refused because a story's `depends_on` is bad, the
message says that `story amend` can't change `depends_on` and that the human
fixes it. It gives the human's steps and commands: edit the list in the story's
file, `git commit` it, then `agile-team start` again, running
`agile-team accept-checkout` first if the start halts on the moved checkout. It
no longer tells the reader to "fix depends_on in .team/stories", and a test
checks it.
