---
id: REQ-077
title: The sprint end pushes the team branch as built to the sprint's branch and opens or reuses its PR onto main
status: active
covers: ["s151/AC1.1", "s151/AC1.2"]
---
At a sprint end, the first push sends the team branch's own history, as it
is (no cherry-pick, no rebase), to the sprint's branch `<prefix><N>` with
`--force-with-lease`. The runner then opens the sprint's pull request from
`<prefix><N>` to `[upstream] branch`, or reuses the one that exists. The PR
is based on main, not on an earlier sprint's PR.
