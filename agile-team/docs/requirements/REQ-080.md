---
id: REQ-080
title: Code refuses the rebase before the as-built push's green CI, and the cherry-pick review stage is gone
status: active
covers: ["s151/AC4.1", "s151/AC4.2"]
---
The end stages run in the order push, ci, rebase, push-rebased, ci-rebased.
The rebase stage itself refuses to run unless the sprint's branch has a
green CI read on the sha it pushed, and the refusal leaves the team branch
unchanged. The `review` stage, which cherry-picked the sprint's commits onto
main in a scratch worktree, is removed, and so is the `restack` stage that
depended on it.
