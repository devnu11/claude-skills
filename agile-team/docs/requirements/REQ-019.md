---
id: REQ-019
title: The Board's sprint card shows the sprint's CI state
status: active
covers: ["s111/AC5"]
---

Each sprint's row in the Board's Review stack shows its CI state as one pill:
`CI green` (done), `CI failed: <job>, <step>` (blocked), `CI blocked by main:
<job>` (the team carries on), or `re-running <job>`. While checks run it shows
`CI running`, and with no CI result it shows `no CI result`. The snapshot
carries it as `upstream.stack[].ci` (`state`, `text`).
